# PC2 Autoware Universe v2.0.0

Branch:

```text
IONIQ_EV/PC2/autoware_universe/v2.0.0
```

This is a parentless source snapshot for the PC2 sensing/perception role. It contains Autoware
source packages plus the guarded launch, flattened topic-tools source, validation scripts, and
operator documentation required by the dual-camera pipeline.

Build, install, log, raw test-log, backup, nested Git, and generated TensorRT artifacts are not
included. See `src/migration_work/reports/PC2_V2.0.0_RELEASE_NOTES.md` for validation evidence and
known integration limits.
