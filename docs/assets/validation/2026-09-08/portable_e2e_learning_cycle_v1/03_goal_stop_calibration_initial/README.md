# 03 · 초기 목표 정지 보정: 도착 성공과 학습 데이터 품질을 분리

Town07 직선 경로에서 **CARLA BasicAgent 전문가 주행**으로 수집한 초기 실험 두 건입니다. 학습 모델이 제어한 주행이 아닙니다. 두 실험을 모두 분모에 포함했으며, **학습용 데이터 품질 후보는 0/2개**입니다. 원본을 고치거나 실패 구간을 제외하지 않았습니다.

| 실험 | 설정 | 실제 최고 속도 | 목표 정지·2초 유지 | 목표 평면 거리 | 20Hz / 10Hz 가감속 초과 | 원시 데이터 품질 |
|---|---|---:|---|---:|---:|---|
| run_001 | comfortable_v1 | 30.032 km/h | 실패 | 1.843 m | 6 / 2 구간 | 실패 |
| run_002 | comfortable_v2 | 16.685 km/h | 성공 | 0.970 m | 5 / 4 구간 | 실패 |

두 실험의 명목 목표 속도는 30km/h입니다. run_002의 실제 속도는 약 16.7km/h까지만 올라갔으므로 **30km/h 검증 성공이 아닙니다**. 위 초과 횟수는 미래 라벨 창이 아니라, 각 측정 간격의 속도 차이에서 계산한 구간 수입니다.

## 1차 실험: 정지 완료 전에 경로 종료 판정

![run_001 실제 속도·가감속·목표 거리](run_001_measured_timeline.png)

run_001은 목표까지 약 1.843m, 속도 약 3.0m/s인 상태에서 BasicAgent가 종료를 보고해 실패했습니다. 목표 도착 판정에 필요한 1m 이내 정지·2초 유지를 충족하지 못했고, 정지 후 꼬리 구간도 수집되지 않았습니다. 따라서 tail 위반 0건은 tail 품질 통과가 아니라 **tail 자체가 없었음**을 뜻합니다. 출발 중 20Hz 최대 가속도는 약 +5.531m/s²였습니다.

## 2차 실험: 목표 정지는 성공했지만 저속 제동 전환에 급격한 속도 변화

![run_002 실제 속도·가감속·목표 거리](run_002_measured_timeline.png)

run_002는 목표 평면 거리 0.969651m에서 정지 상태를 약 2.000000초 유지했고, 그 뒤 6.500000초 꼬리 구간도 정지 상태로 수집했습니다. 그러나 주행 단계에 20Hz 5구간·카메라 정렬 10Hz 4구간의 한계 초과가 남았습니다. **모든 초과는 driving 단계이며, 이미 정지한 stationary_tail 단계에서는 0건**입니다.

20Hz에서 최대 +4.073m/s², 최소 −22.492m/s²가 관측됐고, 10Hz 최소값도 −10.243m/s²였습니다. 최악의 20Hz 감속 구간에서 적용된 정규화 brake는 약 0.129865였고, 다음 명령은 throttle 0.2 / brake 0으로 바뀌었습니다. 저속 제동·가속 전환이 관측되지만, 이것만으로 PID·변속기·물리엔진 중 어느 하나가 원인이라고 확정하지 않습니다. 별도의 고정 페달 응답 계측으로 구분할 대상입니다.

v2에서는 계획 감속량 1.5→1.0m/s², 일반 제동 상한 0.10→0.15, throttle 상한 0.20과 관련 종료 로직이 함께 바뀌었습니다. 따라서 두 실행은 **단일 변수만 바꾼 엄밀한 A/B 실험이 아닙니다**. 실행별 수집기·보조 코드 해시는 JSON에 구분해 보존했습니다.

## 판정 범위와 출처

- 가감속 한계는 기존 모델의 **±2.9m/s²**입니다. 별개 runtime 속도 변화 gate의 **가속 +3 / 감속 −6m/s²**도 JSON에 따로 계산했습니다. 한계를 완화하지 않았습니다.
- 20Hz 원시 상태와 실제 camera JSONL에 대응하는 10Hz 상태를 사용했습니다. phase 경계의 앞쪽 상태도 유지해 시작·정지 충격을 숨기지 않았습니다.
- 목표 거리·경로 진행은 실제 XY와 경로에서 다시 계산했고, 정지·연속 유지 시간은 저장된 `complete` 값을 믿지 않고 재계산했습니다. 두 실행 모두 기록된 충돌·차선 침범은 0건입니다. 이는 일반 도로 안전성이나 장애물 회피 성능 증명이 아닙니다.
- 두 실행 모두 owner 종료 기록과 같은 소유 PID/PGID·generation의 stopped PASS를 확인했습니다. **run_001에는 사전 owner_plan이 없으며**, 더 약한 owner_started·stopped 기록만 있습니다. 나중의 강화된 기록을 과거 실행에 소급 적용하지 않았습니다. run_002는 owner_plan의 수집기·보조 코드·경로 해시를 수집 결과와 대조했습니다.
- PNG는 **측정 JSON을 그린 그래프**입니다. CARLA/Autoware 화면 캡처나 GIF가 아니며, 이 요약기는 카메라 JPEG 픽셀·전체 센서 보정·완전한 XY 디코더 적합성·학습 모델 주행을 검증하지 않았습니다. 새 테스트 데이터 사용·학습 편입·자동 승격도 없습니다.
