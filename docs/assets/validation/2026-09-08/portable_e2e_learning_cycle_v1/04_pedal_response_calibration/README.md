# 04 — 일정한 페달에서도 남는 출발·저속 정지 응답

<!-- HH_260906 - Publish all twelve fixed-pedal measurements without promoting a controller or training dataset. -->

Town07 직선, Prius, ClearNoon의 고정된 조건에서 **가속 6개 + 제동 6개, 총 12개 실험을 모두 완료**했습니다. 별도 PID나 학습 모델 대신 미리 정한 페달을 직접 일정하게 적용했습니다. 독립 요약기가 실행 소스 원본, 4,176개 상태, 12개 보고서, 소유한 서버의 시작·종료 증명을 대조했습니다. 이것은 원인 분리를 위한 계측 완료이며, 자율주행·30 kph·학습 데이터 품질 통과가 아닙니다.

가속 페달을 일정하게 유지해도 출발 지연 이후 순간 가속과 속도 진동이 관측됐습니다. 제동은 여섯 단계 모두 저속에서 급격하게 정지했습니다. 따라서 이전 제어기의 페달 전환만을 원인으로 단정할 수 없습니다. 엔진/바퀴 RPM, 내부 필터 입력, 타이어의 저속 고착 상태는 계측하지 않았으므로 특정 물리 내부 로직이 원인이라고 확정하지 않습니다.

## 실제 결과

다음 극값은 hold 구간과 바로 앞 측정 상태를 포함한 실제 20 Hz 속도 차분입니다. 출발·정지나 0 m/s 부근의 표본을 제거하지 않았습니다. 모델의 속도 변화 한계는 기존 **±2.9 m/s²**, 런타임 검사 한계는 별도로 **+3 / −6 m/s²**이며 완화하지 않았습니다.

| 일정 throttle | 8초 hold 중 최고 속도 (m/s) | 최대 가속 (m/s²) | 일정 brake | 최소 가속 (m/s²) |
|---:|---:|---:|---:|---:|
| 0.05 | 약 0 | +0.000002 | 0.02 | −19.796215 |
| 0.10 | 1.027866 | +3.799619 | 0.04 | −19.822786 |
| 0.15 | 1.819842 | +2.893276 | 0.06 | −24.626103 |
| 0.20 | 2.670943 | +4.072728 | 0.08 | −19.701212 |
| 0.30 | 4.461758 | +3.654260 | 0.10 | −16.318412 |
| 0.40 | 5.971896 | +3.185865 | 0.12 | −16.377731 |

각 제동은 throttle 0.30으로 측정 속도가 처음 3 m/s 이상이 된 다음 시작했습니다. 실제 진입 속도는 여섯 실험 모두 **3.0396464855 m/s**였고 관측된 실험 간 차이는 0입니다. 정확히 3 m/s로 강제 설정한 것이 아닙니다. 제동 강도가 작아도 순간 감속이 작다고 보장되지 않았습니다.

throttle 0.15의 단 한 번 기록은 스칼라 한계 안이지만, 최대 가속은 한계에 약 0.0067 m/s²만 못 미칩니다. 이를 일반적으로 안전한 값으로 선정하지 않았습니다. throttle 0.05는 사실상 움직이지 않았습니다. 전체 12개 중 10개는 준비 구간까지 포함한 실제 20 Hz 분석에서 ±2.9 한계 초과가 있으며, 나머지 2개도 주행 품질이나 전체 XY 궤적 실현 가능성을 증명하지 않습니다.

**10 Hz는 카메라가 아닙니다.** 원래 20 Hz 상태열을 짝수 시작/홀수 시작으로 각각 두 칸 간격 추출하고 실제 시간 차로 계산했습니다. 어느 시작 위치를 고르느냐에 따라 짧은 변화의 크기가 달라지므로 둘 다 공개했습니다. 이 실험에는 카메라 이미지, GIF, 화면 촬영, 학습 모델 주행이 없습니다. 위 PNG는 실제 수치로 그린 그래프입니다.

hold 그래프는 첫 hold 명령 직전 상태부터 전체 hold를 보여 줍니다. JSON에는 settle·prepare·hold 전체의 개수, 극값, 경계 및 위반 구간이 남아 있습니다. 원시 상태열 전체를 이 공개 폴더에 중복 복사하지는 않았습니다.

## 통제 조건과 증거

- 각 실험은 새 차량으로 시작하고, settle 3.5초를 기록했습니다. 가속 hold는 8초, 제동 준비는 최대 15초(실제 4.8초), 제동 hold는 15초였습니다. 페달·위치·속도를 시험 중 강제 재설정하지 않았습니다.
- 실제 동기식 20 Hz, `fixed_delta_seconds=0.05`, substep `0.01 × 10` 조건을 검증했습니다. CARLA 클라이언트·서버의 실제 문자열은 모두 `0.9.15-dev-dirty`입니다.
- 12개 **시작 시점** 차량 물리 스냅샷이 동일했습니다. 질량 1,375 kg, 바퀴 4개의 기록된 radius 37, max_brake_torque 800, tire_friction 3.5 등 원래 수치를 JSON에 유지했습니다. CARLA 원시 필드의 단위/좌표를 임의로 바꾸지 않았으며, 전체 실행 동안 내부 물리 상태가 변하지 않았다는 뜻은 아닙니다.
- 모든 case의 정리 완료·충돌 없음, case 사이 공개된 빈 월드 1 tick, 서로 다른 차량 ID, 소유한 PID/프로세스 그룹과 포트의 종료를 검증했습니다. 차선 센서는 없으며 경로 횡오차 제한 3 m를 원시 상태로 검사했습니다.
- 이 실행은 당시 미커밋 변경을 포함했습니다. 기록된 base HEAD가 실행 파일 전부를 포함했다고 주장하지 않습니다. `provenance/`에 보존된 정확한 실행 바이트 9개와 시작 전·종료 후 SHA가 기준입니다. 이후의 다른 실험용 코드가 바뀌어도 이 과거 기록의 기준은 바꾸지 않습니다.

[독립 요약 JSON](summary.json), [출처·제작 기록](provenance.json), [파일 검증 목록](SHA256SUMS)을 함께 보관합니다. 원본 로그·owner 정보의 계정 절대 경로는 공개하지 않고, 상대 이름·원본 바이트 크기·SHA256으로 추적합니다. 원래 trial 42개 증거 파일의 해시는 요약 JSON에 있습니다.

## 재현

원래 완료된 계측 폴더가 있는 작업공간에서 다음 명령으로 새 폴더를 생성합니다. 패키지 설치·시뮬레이터 기동·GPU 사용은 하지 않습니다. PNG에는 이미 설치된 Matplotlib이 필요합니다.

```bash
python3 scripts/e2e/summarize_carla_low_speed_response.py \
  artifacts/training/2026-09-08/low_speed_response_v1/run_001 \
  --output-dir artifacts/training/2026-09-08/low_speed_response_summary_recheck_01
python3 -m pytest -q tests/test_summarize_carla_low_speed_response.py
```

출력 폴더가 이미 있으면 실패합니다. 부족한 case·미종료 실행·일치하지 않는 소스/상태 해시·위조된 저장 통계는 통과하지 않습니다. 재실행 시 생성 시각과 요약기 소스 SHA는 달라질 수 있습니다. 모델/데이터 승격과 테스트셋 평가는 수행하지 않았습니다.
