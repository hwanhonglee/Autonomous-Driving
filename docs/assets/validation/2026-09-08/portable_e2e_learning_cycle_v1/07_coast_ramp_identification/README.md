# 07 — 무페달 감속·반복 출발·점진 가속: 두 번째 9개 계측

<!-- HH_260906 - Keep the complete second measurement matrix separate from accepted training data and future experiments. -->

미리 선언한 `low_speed_v2` **9개를 모두 완료**했습니다. 무페달(coast) 2회, 고정 throttle 0.15 출발 3회, 가속 페달을 서서히 올리는 ramp 4회입니다. 독립 요약기는 **2,742개 상태·37개 증거 파일·실행 소스 원본 10개**를 검증했습니다. 원래 [첫 번째 12개 계측](../04_pedal_response_calibration/README.md)은 변경하지 않았습니다.

핵심은 **무페달로 20초 감속해도 완전히 멈추지는 않았고, 점진 가속도 출발 순간의 큰 가속을 없애지 못했다**는 것입니다. 이는 원인 분리를 위한 계측이며, 학습 데이터·자율주행·30 kph 통과가 아닙니다. 이후 계획/실험은 이 9개 결과에 섞지 않았습니다.

## 사전 고정 조건과 결과

Town07 직선, Prius, ClearNoon, 동기식 물리 20 Hz입니다. 매번 새 차량을 생성하고 3.5초 settle을 기록했습니다. 수동 기어·물리 파라미터·차량 속도를 강제로 바꾸지 않았습니다. 모든 시작·정지·0 m/s 부근 기록을 보존했습니다.

최대 가속 열은 해당 coast/hold/ramp와 직전 측정 상태를 포함합니다. 마지막 열은 settle·prepare·coast/hold/ramp **전체**를 계산하므로 준비 구간을 뺀 통과율이 아닙니다. 9개 중 5개에서 실제 20 Hz 스칼라 한계 초과가 확인됐습니다. 나머지 4개도 완성된 경로 주행이나 전체 XY 궤적 실현 가능성을 증명하지 않습니다.

### 1. 무페달은 부드럽지만, 20초 안에 완전 정지하지 않았다

throttle 0.30으로 실제 속도가 처음 3 m/s 이상이 된 상태에서 두 페달을 0으로 바꿨습니다. 두 실험 모두 측정 진입 속도는 **3.0396464855 m/s**, 실험 간 차이는 0입니다. 3 m/s로 강제 속도를 설정한 것이 아닙니다.

무페달 구간 최소 가속은 **−1.217907 m/s²**로 기존 ±2.9 한계 안입니다. 하지만 20초 뒤에도 **0.186413 m/s ≈ 0.671 kph**가 남습니다. 이 결과를 목표 위치 정지 성공으로 해석하지 않습니다. 준비 구간의 출발 가속 **+3.654260 m/s²**는 초과 기록으로 그대로 남겨 두었습니다.

![두 번의 실제 무페달 감속과 속도 차분](01_zero_pedal_coast_repeats.png)

### 2. throttle 0.15 반복은 겹치지만 안전 여유가 작다

같은 초기 조건의 세 번 모두 같은 속도 응답과 **+2.893276 m/s²** 최대 가속을 보였습니다. ±2.9 한계까지 여유는 약 **0.0067 m/s²**뿐입니다. 새 차량으로 반복했지만 같은 경로·차량·날씨 조건이므로 독립적인 도로 상황 세 가지를 검증한 것이 아닙니다. 일반적으로 안전한 페달 값으로 승격하지 않았습니다.

![동일 조건 세 번의 고정 throttle 출발](02_constant_throttle_repeats.png)

### 3. 페달을 천천히 올려도 출발 가속이 남았다

각 50 ms 명령은 `min(0.40, 증가율 × (0부터 센 tick + 1) / 20)`으로 고정했습니다. 8초 뒤 페달은 순서대로 **0.08 / 0.20 / 0.40 / 0.40**이며 모두 0.40에 도달한 실험이 아닙니다. 제동은 0입니다. 원시 requested/applied 페달이 모든 구간에서 이 수식과 일치하는지 확인했습니다.

0.010/초 조건은 사실상 출발하지 않았습니다. 나머지 세 ramp는 출발했지만 실제 20 Hz 가속에서 +2.9를 초과했습니다. 최고 마지막 속도는 약 **18.21 kph**로, 30 kph 검증이 아닙니다. 내부 엔진·바퀴 RPM, 필터 입력, 타이어 저속 고착 상태는 관측하지 않았으므로 특정 내부 물리 로직으로 원인을 단정하지 않습니다.

![실제 페달 명령과 네 가지 점진 가속 응답](03_gradual_throttle_ramps.png)

## 10 Hz도 두 시작 위치를 모두 남겼다

여기서 10 Hz는 **카메라가 아니라** 원래 20 Hz 상태를 두 칸 간격으로 추출한 파생 계산입니다. 짝수 시작(offset 0)과 홀수 시작(offset 1)을 모두 계산했습니다. 속도와 실제 timestamp의 차분이며 저속 필터나 가속 극값 잘라내기는 하지 않았습니다.

| 구간 | 실제 20 Hz 최소 / 최대 (m/s²) | 파생 10 Hz offset 0 최소 / 최대 | 파생 10 Hz offset 1 최소 / 최대 |
|---|---:|---:|---:|
| coast (각 2회 동일) | −1.217907 / +0.883241 | −0.417715 / +0.557204 | −0.417994 / +0.221274 |
| throttle 0.15 (각 3회 동일) | −1.636015 / +2.893276 | 약 0 / +2.428545 | 약 0 / +2.232240 |
| ramp 0.010/초 | 약 0 / 약 0 | 약 0 / 약 0 | 약 0 / 약 0 |
| ramp 0.025/초 | −1.674918 / +4.017690 | −0.021058 / +2.016769 | 약 0 / +3.244993 |
| ramp 0.050/초 | −1.556281 / +3.964609 | 약 0 / +2.684685 | 약 0 / +2.402798 |
| ramp 0.100/초 | −1.168688 / +3.180464 | 약 0 / +3.177801 | 약 0 / +1.782291 |

위 표는 제어 구간 비교이며, 생략된 것이 아니라 별도 분리된 settle·prepare 통계와 경계·위반 상세는 [summary.json](summary.json)에 있습니다. 특히 10 Hz 한 시작 위치에서 초과가 보이지 않는다고 원래 20 Hz 응답이 개선된 것은 아닙니다.

## 출처·범위·재현

- 모델 스칼라 한계 ±2.9 m/s²와 런타임 검사 +3 / −6 m/s²를 구분해 기존 그대로 검사했습니다. 스칼라 검사만으로 전체 decoder·실차 안전성을 판단하지 않습니다.
- 9개 시작 시점의 차량 물리 스냅샷이 동일했습니다. 이 값의 정규화 JSON 해시는 `ddfa2bb333142cb0f9e2dcbe6b4b19358b603e12b0a9748e3e661423654742d5`입니다. 전체 시간 동안의 내부 물리 상태가 같다는 주장은 아닙니다.
- 실제 CARLA client/server 문자열은 `0.9.15-dev-dirty`, fixed step 0.05초, substep 0.01 × 10입니다. 전체 case 정리, 서로 다른 차량 ID, 공개된 빈 월드 tick, 충돌 없음, 횡오차 제한 및 소유한 서버·포트 종료를 검증했습니다. 카메라·차선 센서·학습 모델은 없습니다.
- 당시 base HEAD는 `c52a9c9ccc42b4cb3118589d9f233dc1ada65199`이며 작업 트리는 dirty로 기록됐습니다. 실제 실행을 증명하는 기준은 보존된 소스 바이트 10개와 종료 후 해시 일치입니다. 나중에 수정된 live worker를 이 기록에 소급 적용하지 않습니다.
- 공개 폴더에는 실제 데이터로 만든 PNG 3장, 원본 요약 JSON의 동일 바이트 사본, [provenance.json](provenance.json), [SHA256SUMS](SHA256SUMS)가 있습니다. 원시 상태·로그는 중복 복사하지 않고 상대 이름·원본 크기·SHA로 연결합니다. 계정 절대 경로는 공개하지 않습니다.
- PNG는 화면/영상/GIF가 아니라 실제 계측 그래프입니다. 가속/감속 한계 초과 여부와 무관하게 전체 9개를 유지했으며, 자동 학습 데이터 승인·모델 승격·테스트셋 사용은 없습니다.

원래 완료된 원본 폴더가 있는 작업공간에서 실행합니다. 설치·GPU·시뮬레이터 접속 없이 검사하며, 그래프에는 이미 설치된 Matplotlib을 사용합니다.

```bash
python3 scripts/e2e/summarize_carla_low_speed_response.py \
  artifacts/training/2026-09-08/low_speed_response_v2/run_001 \
  --output-dir artifacts/training/2026-09-08/low_speed_response_v2_summary_recheck_01
python3 -m pytest -q tests/test_summarize_carla_low_speed_response.py \
  tests/test_summarize_carla_goal_stop_trials.py
```

기존 출력 폴더는 덮어쓰지 않습니다. 요약기는 이름이 알려진 v1 12개/v2 9개 계획만 허용하며, case 누락·잘못된 ramp 수식·미종료 실행·불일치한 소스/상태 SHA·서로 다른 물리 스냅샷을 거부합니다. 관련 54개 테스트가 통과했고, v1의 이전 공개 요약 수치가 생성 시각/요약기 소스 SHA를 제외하고 그대로인 회귀 검사도 통과했습니다. 원본 자료가 없는 clone에서는 실제 원본 복사 기반 테스트가 명시적으로 skip됩니다.
