# 데이터 기준점과 남아 있는 저속 궤적 문제

<!-- HH_260906 - Keep scalar collection improvement separate from raw trajectory representability and physical frame calibration. -->

[V4 두 주행](../14_brake_free_goal_stop/README.md)은 속도·가감속·목표 정지와 제어 기록
검사를 충족했지만, **아직 학습 데이터로 채택하지 않았습니다.** 원본 영상과 모든 미래
궤적을 추가 검사한 결과입니다. 새 주행·학습·모델 배포나 TF 변경은 하지 않았습니다.

모든 8,802장 영상과 85,568개 유효 미래 점을 포함했습니다. 겹치는 미래 창의 수는
독립적인 운전 사건의 수가 아닙니다. 곡률 기준을 넓히거나 정지·warmup 점을 제외하지
않았습니다. 원본 Low의 체크무늬 노면도 그대로입니다. [전체 진단 JSON](raw_v4_pre_admission.json)에
원본·실행 코드 해시와 상태별 증거가 있습니다.

새로 저장한 동일 프레임 actor pose·세계 속도·가속도·각속도에서 기존 base 좌표와
운동량 2,934개를 다시 계산하면 모든 잔차가 0입니다. 이는 **기존 변환을 그대로
기록했다는 증명**이지, 선언한 기준점이 실제 뒷바퀴 축 또는 속도 센서 기준점이라는
증명은 아닙니다. pitch=0 근사의 최대 평면 위치 차이는 약 0.00000020 m였습니다.
따라서 이 실행의 저속 XY 문제 전체를 pitch 누락으로 설명하지 않습니다.

## 선언한 base와 바퀴 위치 대조

기존 고정 페달 계측 12건의 실제 physics 기록을 모두 검증했습니다. 아래는 첫 tick 전
조회한 바퀴 위치를 **선언한 spawn** 기준으로 변환한 값이며, 정차 후 같은 프레임에서
관측한 정밀 캘리브레이션은 아닙니다. 12건은 같은 조건의 반복이지 독립 차량 12대가 아닙니다.

| 기준 | actor spawn 기준 x 또는 길이 |
|---|---:|
| 선언한 virtual base 위치 | −1.425000 m |
| 기록된 뒤 바퀴 쌍의 중점 | −1.399239 m |
| 기록된 앞 바퀴 쌍의 중점 | +1.419947 m |
| 앞뒤 중점의 종방향 간격 | 2.819186 m |
| 선언한 wheelbase | 2.850000 m |

이 계산에서 virtual base는 뒤 바퀴 중점보다 약 **25.76 mm 뒤**입니다. 좌표 기준점을
그곳에 두는 것 자체가 오류라는 뜻은 아닙니다. 다만 정확한 물리 뒷축이라고 가정해서
속도·곡률·센서 변환을 해석해서는 안 됩니다.

검토한 로컬 CARLA/Unreal 소스에서 wheel position은 세계 좌표 **cm**이고, actor location은
**m**입니다. 서로 다른 단위를 그대로 빼거나 wheel position을 이미 차량 로컬 좌표로
해석하면 안 됩니다. `center_of_mass` 설정값은 이 소스의 `COMNudge` 경로이며, 그 값
하나만으로 실제 세계 좌표 질량중심을 측정했다고 볼 수 없습니다. 실행 바이너리가 이
소스에서 빌드됐는지까지 입증한 것은 아니므로 소스·단위 해석의 범위를 함께 남겼습니다.

[12건 전체 기준점 진단](summary.json)에 7개 기본 소스 SHA와 원본 보고서 SHA가 있습니다.
독립 검토에서 찾은 spawn 동일성 검사 누락은 별도 검사로 고쳤고, 실제 12건의 spawn과
physics가 각각 동일함을 재확인했습니다. 관련 단위 테스트 14개가 통과했습니다.

## 다음 연구의 목적

원본의 아주 작은 위치 변화에 대한 정확한 곡률 한계와 모델이 허용 오차 안에서 표현할 수
있는 궤적은 구분해야 합니다. 다음 진단은 원본을 고치지 않고, 현재 그대로인 bounded
decoder의 출력이 원본 XY·속도에 얼마나 가까워질 수 있는지 수치 최적화로 측정합니다.
이는 미래 정답을 사용한 표현력 분석이며 인과적인 모델 성능·새 학습·데이터 승인 기준이
아닙니다. 실행 전에는 설계·예산만 고정하며, 결과가 나오기 전에 개선됐다고 표시하지 않습니다.
