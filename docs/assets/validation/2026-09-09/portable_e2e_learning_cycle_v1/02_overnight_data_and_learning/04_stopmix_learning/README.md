2026-09-09 **학습 6회·평가 6회·기존 v8 감사 6회와 별도 행동 분석 6회가 모두 완료**됐습니다.
전체 판정은 `COMPLETE_NOT_PROMOTED`입니다. 세 seed 중 상대 기준을 만족한 것은 1개이고,
절대 품질 기준은 모두 FAIL이므로 새 모델을 배포하거나 기존 모델을 교체하지 않았습니다.

학습은 원격 개인 venv·GPU 0에서 03:09:29 KST에 시작했고, 정상 18단계는 03:32:06 KST에 끝났습니다.
별도 행동 분석은 03:34:11–03:36:15 KST에 실행됐습니다. 아래 PNG는 실제 학습 수치와
저장된 검증 입력으로 계산한 모델 예측입니다. **CARLA/Autoware 자율주행 촬영이나 실제 차량 주행 결과가 아닙니다.**

공개 JSON은 계정별 경로와 불필요한 GPU UUID를 치환한 metadata 보기입니다.
각 파일의 `raw_source_sha256`과 [공개 변환 명세](results/publication_manifest.json)에 비공개 원본 SHA를 보존했습니다.
기존 [실행 계획](plan.json)은 SHA를 유지하기 위해 원래 바이트 그대로 보존합니다.

| 파라미터 | 954,590개 | 1,056,362개 |

각 모델은 새로 학습했으며 이전 checkpoint를 baseline 대신 재사용하지 않았습니다.
직전 candidate-regret 실험의 추가 손실은 켜지 않았습니다. 완전한 epoch 5회와
다음 epoch의 105개 batch를 사용했고, 마지막 불완전 batch까지 실제 노출 수에 포함합니다.

B는 후보 수와 모델 용량이 함께 커집니다. 따라서 이 비교는 **STOP 구조 하나만 바꾼 동일 용량 실험이 아닙니다**.
새로 거부된 수집 데이터는 넣지 않았고, 기존 v3의 warmup·미래 라벨 품질 한계도 그대로 남아 있습니다.
전체 corpus 무결성 검사에서 test 파일을 읽을 수 있지만, test를 모델 추론·최적화·선택에 쓰지는 않았습니다.

## 3. 정지 경로를 만들 수 있는가, 필요한 때 고르는가?

여섯 모델이 본 동일한 val 337개를 정답 미래 움직임으로 사후 구분하면 다음과 같습니다.

| 사후 그룹 | 개수 | 해석 |
| --- | ---: | --- |
| continuing_motion | 208 | 미래에도 계속 움직이는 창 |
| moving_to_stop | 51 | 움직이다 정지로 향하는 창 |
| other_motion | 78 | 위 조건에 들지 않는 나머지 움직임 |
| stationary_hold | 0 | 정지 유지 능력을 판단할 표본 없음 |
| unavailable_masks | 0 | 이 분석의 분류에 필요한 마스크가 없는 표본 없음 |

겹치는 미래 시간창이므로 337개의 독립적인 실제 사건이 아닙니다.
정답 미래는 그룹 분석에만 쓰며 모델 입력에 전달하지 않았습니다.

| Seed | A: 정지 접근 51개 중 선택 최종속도 정확히 0 | B: 정지 접근 51개 중 STOP 선택/최종 0 | B: 계속 이동 208개 중 STOP 선택 |
| --- | ---: | ---: | ---: |
| 20260903 | 22/51 | 6/51 | 39/208 |
| 20260904 | 45/51 | 0/51 | 31/208 |
| 20260905 | 0/51 | 0/51 | 8/208 |

B의 STOP 후보 자체는 각 seed에서 337×6=2,022개, 합계 6,066개 모두 최종속도가 정확히 0이고,
속도가 증가하지 않으며, 미래에 0이 된 후 재가속도 0개였습니다. 이것은 STOP 구조에 넣은 수학적 성질입니다.
하지만 정지로 향하는 구간에서 선택기가 STOP을 적절히 고르는 능력은 확보되지 않았습니다.
B의 moving_to_stop 선택 ADE는 각각 12.2004 / 10.4594 / 10.5605 m입니다.

전체 선택 경로에서 미래에 0이 된 후 재가속한 수는 A가 0 / 0 / 4개, B가 68 / 67 / 0개입니다.
B의 해당 사례는 STOP이 아니라 DRIVE 후보를 선택한 경우입니다. 현재 출발 anchor 자체가 0인 것은 이 집계의
"미래에서 정지 후 재가속"으로 간주하지 않습니다. 수학적으로 정지하는 경로를 생성하는 것과
신호·장애물 때문에 언제 멈춰야 하는지 판단하는 것은 다른 문제이며, 이번 결과로 후자를 주장할 수 없습니다.
