## 왜 이 비교를 하나요?

[앞선 생성기 고정 선택기 실험](../10_frozen_stopmix_selector/README.md)의 후보 인지 선택기는
전체 경로 오차를 줄였지만 TRAIN 정지 유지 118개에서 STOP 후보를 한 번도 선택하지 않았습니다.
또한 앞선 두 선택기는 크기가 달랐고, 원래 모델의 점수를 보존하지 않는 새 초기값으로 시작했습니다.

이번에는 원래 모델의 후보 점수에 작은 학습 가능한 보정값을 더합니다. 마지막 층의 초기값이 0이라
학습 시작 전의 점수는 원래 점수와 바이트 단위로 같아야 합니다. 이것은 **초기 동작 보존**이며,
학습 후에도 정지 성능이 보존된다는 보장은 아닙니다.

| 조건 | A: 원래 점수·문맥 | B: 원래 점수·문맥·후보 경로 |
| --- | --- | --- |
| 원래 점수에 더하는 선택기 | 449 → 256 → 1 공유 MLP | 동일 |
| 할당 파라미터 | 115,457 | 115,457 |
| 초기값·표본 순서 | 같은 seed, 마지막 층 0 | 동일 |
| 입력 | 문맥 256 + 원래 후보 점수 1 + 0 값 192 | 문맥 256 + 원래 후보 점수 1 + 후보 XY·속도 192 |
| 학습량 | 1,540 step / 표본 노출 6,155회 | 동일 |

세 개의 기존 부모 모델마다 A/B를 실행해 총 6개의 선택기를 학습합니다.
같은 수의 파라미터를 할당해도 A의 0 값 입력 연결은 동작에 기여하지 않으므로,
두 조건의 실제 정보량·기능적 표현력이 같다는 의미는 아닙니다.
원래 후보 점수는 모델의 인과적 출력이며 미래 정답을 입력으로 넣지 않습니다.

## 유지하는 조건과 결과 범위

- 기존 후보 12개·미래 64점·생성기·학습 데이터·라벨·안전 기준은 바꾸지 않습니다.
- 고정된 캐시 6개만 안전한 CPU 로딩으로 읽습니다. 원래 체크포인트를 로딩하거나 영상 인코더를 다시 실행하지 않습니다.
- TRAIN 1,147개 / VAL 337개, 원래 hard composite-oracle cross entropy, batch 4, 학습률·weight decay 각 0.0001을 유지합니다.
- 원본·A·B 각각의 TRAIN/VAL 전체 진단과 고정 VAL 인덱스 그림 108개를 남깁니다. 일부 성공 사례만 고르지 않습니다.
- TRAIN의 정지 유지 118개를 따로 보고합니다. VAL의 해당 그룹은 0개이므로 정지 기능의 독립 검증이 아닙니다.
- 반복 관찰한 VAL은 개발용 비교입니다. TEST 신경망 추론·최적화·모델 선택에는 사용하지 않습니다.
- 원래 캐시 실행의 205개 파일·18개 PT를 전후 해시 확인하고, 새 결과는 별도의 개인 진단 폴더에만 씁니다.
