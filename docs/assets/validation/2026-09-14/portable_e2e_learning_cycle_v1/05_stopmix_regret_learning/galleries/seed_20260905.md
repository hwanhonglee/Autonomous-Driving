# Seed 20260905 — 동일 VAL 장면의 A/B 후보 경로

<!-- HH_260906 - Present every prospectively fixed validation render without cherry-picking or claiming vehicle control. -->

실행일은 2026-09-14이며 제목의 seed는 난수 초기화 번호입니다.
A는 기존 손실, B는 후보 비용 보조 손실을 더한 **동일 구조 전체 모델**입니다.
아래는 예정한 VAL 12개 인덱스 전부이며, 실제 주행 화면이 아닌 저장 입력의 open-loop 예측입니다.

차량은 각 그림 중앙입니다. 위쪽은 전방, 왼쪽은 차량 좌측이며 회색은 예정 경로,
초록은 expert 정답, 굵은 색 선은 모델이 선택한 후보입니다. 얇은 색 선은 나머지 후보입니다.
모든 후보를 담기 위해 그림마다 자동 축척을 사용하므로 화면상 길이만 비교하지 말고
[전체 오차·정지 지표](../README.md)를 함께 확인하세요.
