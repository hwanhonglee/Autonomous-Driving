## 실제로 변경한 제어

새로 선언한 `comfortable_v5_brake_hold`는 v4의 경로·속도·제어 한계를 상속합니다. 목표점 이전의 허용 범위 안에서 무페달 타력 주행 속도가 실제로 0.1 m/s 이하가 된 것을 관측한 뒤, **다음 정상 제어 명령부터 서비스 브레이크 1을 유지**합니다. 완료 판정에는 기존과 동일한 40개 측정 시간 간격, 즉 2초가 필요합니다.

관측 프레임 3173, 시뮬레이터 시각 68.856117132초에서 속도는 0.099580618 m/s, 실제 보고된 브레이크는 0이었습니다. 다음 명령은 브레이크 1을 요청했고, 프레임 3174의 68.906117133초 관측에서 브레이크 1과 ACK/프레임 일치를 확인했습니다. 목표 완료는 프레임 3213, 70.856117162초이며, 이후 정지 상태 130개 틱을 끝까지 기록했습니다. 기존 정지 브레이크 조향 억제와 긴급 제어 권한은 유지했습니다. 상태 초기화, 시간 이동, 인공 틱, 라벨 보정, 검사 한계 변경은 하지 않았습니다.

조건은 Town07 직선 고정 경로 SHA `8285e70a790d5e8ae75803db1aa538122b56e6fcfc3586e60eaa947d330417c9`, Prius 축거 2.85 m, 생성 Z +0.5 m, ClearNoon/seed 0, Epic 화질, 월드 20 Hz, 저장 카메라 10 Hz, 승인 응답 기반 제어, bootstrap 이후 BasicAgent 초기화입니다. 기록된 기존 물리 설정은 substepping 활성, 최대 substep 0.01초, 최대 10회입니다. 이 구형 수집기는 설정 6개와 정리 호출 성공을 기록합니다. 후속 진단기의 11개 설정 복원 재조회 수준이나 물리 substep 토크 적용 시각까지 증명하지는 않습니다.

과거 Town07 v4는 Low 화질과 bootstrap 이전 초기화를 사용했습니다. 따라서 과거 결과와의 단일 변수 A/B나 일반적인 인과관계로 해석하면 안 됩니다. 별도의 C-track 타력/브레이크 ABBA가 이번 실제 제어 변경의 참고 근거였지만, 그 진단 데이터도 학습에는 포함하지 않았습니다.

## 실제 카메라·ego 중심 경로 화면

각 대시보드는 **이름을 표시한 원본 6개 FOV** 아래에 선택된 카메라와 정확히 같은 원본 프레임 기준의 **ego 중심 고정 경로·실제 이동 궤적·속도/브레이크 기록**을 보여 줍니다. 카메라 픽셀은 JPEG 디코딩 후 자르거나 크기를 바꾸지 않았습니다. 로컬 경로와 전체 경로 패널 모두 ego를 (0,0)에 놓습니다. 경로는 사전 고정 참조이며 예측 결과가 아닙니다.

카메라 배치는 저장 순서로, 파노라마가 아닙니다. 윗줄은 FRONT / BACK / FRONT_LEFT, 아랫줄은 BACK_LEFT / FRONT_RIGHT / BACK_RIGHT입니다. 화면 선택 기준은 수집 전에 선언했습니다. 브레이크 진입 화면은 기준 관측 3173 다음에 저장된 프레임 3174(+50 ms)이며, 마지막 저장 화면 3342는 최종 원본 상태 3343보다 한 틱 앞(−50 ms)입니다. 이 차이를 각 화면 하단에도 표시합니다.
