## 실제 완료: 두 모델의 TRAIN 전수 추론 진단

K0 TRAIN 1,475개, K1 TRAIN 2,787개를 고정된 최종 checkpoint로 재생했다. optimizer를 만들지
않았고 가중치는 전후 동일했다. DEV는 이 진단에서 추론하지 않았다. 데이터 loader의 기존
전체 manifest validation과 TRAIN-only 모델 추론은 구분한다.

| K1 TRAIN 구간 | 표본 | 선택 후보=최소 ADE 후보 | 선택 후보 ADE | 복합 비용 정답 후보 ADE | 최소 ADE |
| --- | ---: | ---: | ---: | ---: | ---: |
| 직진 | 1,949 | 1,889 | 0.143702 | 0.091891 | 0.090857 |

우회전 TRAIN에서는 최소 ADE 후보 선택 비율이 428/534 ≈ 80.1%였지만, 이미 완료된 DEV
진단에서는 116/337 ≈ 34.4%였다. TRAIN의 복합 비용 정답과 최소 ADE 후보의 평균 ADE 차이는
약 0.013 m다. 따라서 **정답 비용 정의 차이만으로 큰 선택 퇴행을 설명할 근거가 부족**하고,
새 경로에서의 선택 일반화 문제가 우선 확인 대상이다. 원인을 완전히 확정했다는 뜻은 아니다.

현재 모델 코드는 융합 문맥에서 후보 번호별 점수를 출력한다. 생성된 후보의 실제 XY/속도는
기존 점수층의 직접 입력이 아니다. 이를 보완하면 후보 번호에 대한 문맥 의존을 줄일 수 있다는
가설을 다음 L에서 검증한다. 과거 후보 인지 실험이 모두 성공한 것은 아니므로 개선을 보장하지 않는다.

## L 사전 선언: 하나의 구조 변경

- 기존 6 DRIVE + 6 STOP 후보와 물리 decoder를 유지한다.
- 기존 점수에 **후보 간 공유된 형상·속도 잔차 점수**만 추가한다.
- 입력은 기존 현재/과거 센서·navigation 문맥과 모델이 예측한 XY/속도다. 미래 정답, episode ID,
  실제 미래 영상은 추론 입력에 넣지 않는다.
- 잔차 출력층을 0으로 초기화해 초기 출력과 기존 기본 가중치를 K1과 정확히 일치시킨다.
- 후보 XY/속도는 점수용 입력에서 detach한다. 다만 공유 문맥을 통해 생성기에도 간접 영향이
  갈 수 있으므로 **전체 모델을 학습**하며 생성기가 고정됐다고 주장하지 않는다.
- 후보 순서를 바꾸면 잔차 점수도 같은 순서로 바뀌는 성질과 초기 forward 일치 등을 검사했다.
- 전체 파라미터 1,056,362 → **1,113,963**. 용량도 증가하므로 결과가 좋아져도 이 실험 하나로
  형상 입력 효과와 용량 효과를 완전히 분리했다고 주장하지 않는다.

새 자율주행 기능 head가 아니라 기존 후보 선택 경로를 보완하는 연구 구조다. 새 checkpoint
schema를 사용하며 기존 runtime/export 대상에 넣지 않는다.
