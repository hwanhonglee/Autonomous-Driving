## 전체 진행 상태와 해석

전체 목표는 9영역·30기능이다. 부분 데이터/계측 근거는 10/30이며 완료율이 아니다.
자체 모델 폐루프 승인 0/30, 실차 승인 0/30이다. 우선 행동은 직진·좌회전·우회전·종점 정지·
속도 추종 5가지이며 이번 검증은 이동 경로/속도의 오프라인 평가에 한정된다.

TRAIN 선택 진단에서는 우회전 최소 오차 후보 선택률이 약 80.1%인 반면 기존 DEV에서는
34.4%였다. 후보 형상을 점수 입력에 추가하는 것만으로 이번 조건의 우회전 성능은 복구되지
않았다. 데이터 범위·표현·선택 일반화를 추가로 구분해야 하며, 학습량만 부족하다고 단정하거나
새로운 기능 head를 늘리는 근거로 삼지 않는다. 다른 공개 모델과 동등한 성능이라는 근거도 없다.

## 다음 작업과 예상 자원

1. 기존 우회전 TRAIN의 독립 episode·물리 경로·곡률·속도 범위와 신규 수집 가능 경로를 점검한다.
   현재 DEV 경로를 TRAIN으로 옮기지 않는다. 로컬 점검 예상 20–40분.
2. CARLA 전문가로 다양한 우회전 경로를 수집하고 성공/충돌/경로 이탈·동기화·중복을 검증한다.
   1차 소규모 수집·변환 예상 1–3시간. 이는 전문가 데이터이지 자체 모델 성공 주행이 아니다.
3. 유효 데이터가 확보되면 기존 K1 구조를 기준으로 데이터 변경만 비교한다. 동일 15,000 step
   학습 1회는 이번 실측상 약 32분이고, 두 조건 비교는 평가 포함 약 65–80분을 예상한다.
   실행 전 데이터 분리·샘플 노출·판정 조건을 고정한다. 현재 예약하거나 시작한 작업은 아니다.
4. 개선 후 독립 정지 보존·신규 경로·여러 seed를 확인하고, 그 다음 10 Hz 런타임 및 CARLA
   폐루프를 검증한다. ACC·회피·차선변경과 실차 전환은 기본 성능 확보 이후다.

위 시간은 환경·수집 실패에 따라 달라지는 작업 추정치다. 다음 점검/수집 준비의 대화·코드 작업은
대략 5천–1만5천 토큰을 계획 범위로 잡되, 실제 과금·잔여 한도 또는 총 학습 완료 비용을 보장하지
