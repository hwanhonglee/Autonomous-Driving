## 목표와 범위

L 구조 실험 실패 후 기본 우회전의 데이터 다양성을 확보한다. 전체 9영역·30기능 중 기본 이동
경로와 속도 복구 단계이며, 부분 근거 10/30·자체 모델 폐루프 승인 0/30은 그대로다.
새 기능 head·실차·TEST 평가는 포함하지 않는다.

기존 G 수집 계획의 TRAIN 전용 카탈로그에는 우회전 후보 22개가 있다. 기존 Town01 학습 경로를
제외한 21개 파일은 실제 회전 구간으로 묶으면 11개다. Town01 6개, Town07 3개, C-track 2개이며
유효 회전 반경 범위는 각각 9.07–10.45 m, 7.27–7.99 m, 9.83–10.80 m다.
이는 카탈로그 형상 범위이며 실제 성공 데이터 수나 관측 곡률 분포를 뜻하지 않는다.

## 다음 우선 작업

반경 약 10m 우회전에서 30km/h를 그대로 유지하는 전문가 목표와 현재 횡가속도 제한의 양립
가능성을 먼저 확인한다. `v²/R` 기준 속도 계획과 신호/종점의 급제동 완화가 수집기 개선 대상이다.
15km/h만 설정해도 감속 품질은 실패했으므로 속도 숫자 변경만으로 해결됐다고 하지 않는다.

1. 실패 구간을 시작/신호/우회전/종점으로 구분하고 현재 가속도·횡가속도 한계를 읽어 제어 목표를 설계.
2. 지면 생성·검증된 lookahead 유지, 곡률 기반 감속 및 종점 제어를 한 단계씩 수집 A/B로 확인.
3. 타깃 전수 검사 통과와 유효 우회전 범위를 확인한 후 개인 dataset으로 전송, 고정 K1 구조 학습.

다음 제어 수정·단위 테스트·소규모 수집은 약 1–2시간, 학습 1회는 추가 약 32분을 예상한다.
정확한 성공 시점은 보장하지 않는다. 현재 새 학습 프로세스는 없다.
