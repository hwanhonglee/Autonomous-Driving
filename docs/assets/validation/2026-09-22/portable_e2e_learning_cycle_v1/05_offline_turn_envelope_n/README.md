## 실행 범위

사용자가 다른 테스트 진행 중임을 알렸으므로 이번 작업은 저장된 TRAIN 카탈로그를 읽는
CPU 오프라인 분석과 새 파일의 단위 테스트에 한정했다. 조회 시 CARLA 관련 프로세스/포트
2000·2100–2102 점유는 보이지 않았지만 다른 작업의 부재를 보장하지 않으므로 시뮬레이터를
시작하지 않았다. 원격 SSH·GPU 학습·맵 변경·공용 제어 코드 수정·설치는 하지 않았다.
공용 runtime lock 파일도 변경하지 않았다.

## 구현과 검증

- 신규 도구: `scripts/e2e/offline_turn_speed_envelope.py`.
- 신규 테스트: `tests/test_offline_turn_speed_envelope.py`, 15개 통과.
- 현재 런타임 한계: 횡가속도 3m/s², 가속도 3m/s², 감속도 6m/s², 속도 30km/h.
- 오프라인 연구 목표: 횡가속도 2m/s², 가속/감속 각각 1m/s², 순항 상한 28.8km/h.
- 경로 heading 변화/arc distance로 곡률을 계산하고 `sqrt(a_lat / |curvature|)`로 국소 속도 상한 계산.
- 후방 전파로 회전/종점 이전의 감속을 계획하고 전방 전파로 출발 가속을 제한한다.
- 동일 XYZ·동일 거리이며 heading 차이가 1e-6rad 이하인 명령 전환 중복점만 메모리상 통합한다.
  원본 수정 없이 원본 index 대응을 남긴다. 유의미한 heading 충돌은 거부한다.
- 지면 생성 Town01 p02: 가속·감속·횡가속 수식 검사 모두 통과. 최소 국소 속도 상한
  **12.4606km/h**, 계획 최고 속도 **26.9399km/h**.
- 최종 산출물: `artifacts/training/2026-09-22/offline_turn_envelope_n_v1/town01_proposal_v2.json`,
  같은 폴더 `town07_proposal.json`. 초기 Town01 v1 제안도 보존했다.

Town07 p03의 초기 거부를 조사하니 index 44/45가 동일 XYZ·동일 거리이고 heading 차이만
약 3.99e-7rad였다. 명령 전환 중복점의 미세 수치 차이를 위 허용오차로 명시하고 방어 테스트를
추가했다. 이후 가속·감속·횡가속 수식 검사 모두 통과했으며 국소 상한 최소 13.6234km/h,
계획 최고 28.8km/h다. 원본 경로·학습 라벨·런타임 기준은 변경하지 않았다.

## 의미와 한계

이는 실제 차량 응답이나 학습 데이터가 아닌 **공간상의 속도 참조 제안**이다. 기존 487개 label을
교체하지 않았고 새 제어기에 연결하지도 않았다. 신호·장애물·조향 추종·지연·jerk를 모델링하지
않으므로 실제 10Hz 가감속 한계 또는 무충돌을 증명하지 않는다. 경로 heading 곡률은 실제
주행 궤적의 곡률과 다를 수 있다. 시작 속도도 측정 초기조건을 보장하는 값이 아닌 상한이다.

전체 9영역·30기능, 부분 근거 10/30, 자체 모델 폐루프 승인 0/30은 변함없다.
현재는 기본 우회전 수집 품질 개선 단계이며 신규 학습은 하지 않았다.

## 다음 작업

1. 오프라인에서 신호/종점 급제동 실패 시점을 분리 분석한다.
2. 이 참조 계획을 적용할 별도 연구 제어 경로를 만들되 다른 테스트의 공용 설정을 바꾸지 않는다.
3. 실제 수집 재개 직전에 작업 소유권·runtime lock·포트·GPU 사용을 재확인한다. 잠금이 잡혀
   있으면 종료시키지 않고 오프라인 작업을 계속한다. 공유 시뮬레이터의 맵은 변경하지 않는다.
4. 독립 수집이 가능할 때만 소규모 A/B를 실행하고, 유효 라벨 확인 후 원격 GPU 0 학습으로 넘어간다.

다음 오프라인 분석/제어 단위 테스트는 약 30–60분 예상이며, 실제 수집 시간은 다른 테스트와의
자원 분리 확인 후 별도 산정한다. 현재 백그라운드 학습/시뮬레이터 작업은 제출하지 않았다.
