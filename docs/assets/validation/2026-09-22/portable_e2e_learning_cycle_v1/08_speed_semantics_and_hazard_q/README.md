## 결론

P05의 위치·속도 불일치 첫 실패 120개는 **카메라 간격 2개**가 중첩된 6.4초 미래 창에서 반복 집계된 것이다. 별도로 실제 감속 제한을 위반하는 구간은 5개 존재한다. 검사 의미의 문제와 실제 급제동 문제를 모두 해결해야 한다. 기준 완화나 라벨 수정은 하지 않았다.

## 1. 검사 의미 재현

현재 runtime gate는 구간 변위 / 0.1초를 구간 끝 순간 속도와 비교한다. 일정한 감속 중에도 둘은 다르다.

| P05 카메라 끝 frame | 중복 첫 실패 창 | 시작 속도 | 끝 속도 | 변위 속도 | 끝 속도 오차 | 양 끝 평균 대비 오차 |
|---|---:|---:|---:|---:|---:|---:|
| 2017 | 56 | 5.4554 | 4.9405 | 5.2638 | 0.3233 | 0.0659 |
| 2871 | 64 | 5.4292 | 4.9170 | 5.2188 | 0.3018 | 0.0458 |

단위는 m/s. 전체 587개 카메라 간격 중 끝 속도 오차 >0.25는 6개, 양 끝 평균 대비 >0.25는 1개다. 이는 대안 계산의 진단값이지 새 통과 기준이 아니다. 회전 중 chord와 실제 arc 길이도 다르므로 평균 속도만 대입하는 것을 완성된 해결책으로 보지 않는다.

수학적 재현 테스트도 추가했다. 8 m/s에서 -5.5 m/s²로 일정하게 감속하는 정확한 궤적은 첫 0.1초의 끝 속도 오차가 0.275 m/s로, 현재 gate가 거부한다. 감속 자체는 -6 기준 이내다. 이 테스트는 **현재 거부 동작을 그대로 확인**하며 runtime gate를 변경하지 않는다.

## 2. 로컬 실제 재실행으로 급제동 판단 확인

기존 worker에 관측 전용 hook을 추가했다. BasicAgent가 원래 수행하는 신호등/차량 검사의 반환값과 add_emergency_stop 호출만 기록한다. 별도 위험 검사 호출, 신호등 cache 변경, 제동 완화는 없다.

로컬 자원 확인 후 owned CARLA 2100에서 P05와 동일한 Town01/seed/28.8 km/h 설정으로 재실행했다.

- 목적지 도달, 충돌 0, 차선 침범 0, 58.7초 시뮬레이션.
- 전체 미래 구간 통과 342/524: P05와 동일.
- 두 기록 모두 native 상태 1,175개. 상대 행 기준 x/y/vx/vy 최대 차이가 모두 0이었다. 절대 frame 번호와 시뮬레이터 시작 시간은 다르다.
- owner_result: 실행 중 소스 변경 없음, 소스 보존 확인, 소유 프로세스 정리 완료.

| Q 카메라 구간 | 실제 감속 m/s² | 관측된 제어 경로 |
|---|---:|---|
| 1889→1891 | -19.63 | 신호등 actor 17 위험, 긴급 제동 호출 |
| 1891→1893 | -20.71 | 신호등 actor 17 위험, 긴급 제동 호출 |
| 1893→1895 | -9.06 | 신호등 actor 17 위험, 긴급 제동 호출 |
| 2743→2745 | -24.01 | stationary_tail 전환, 이 구간의 agent 긴급 제동 호출 없음 |
| 2745→2747 | -24.17 | stationary_tail 유지, 이 구간의 agent 긴급 제동 호출 없음 |

tail 직전에는 신호등 actor 32에 대한 긴급 제동도 기록됐다. 차량 장애물 위험은 해당 관측 구간에서 기록되지 않았다. 시간상 제어 경로는 확인했지만 브레이크 물리 응답을 독립적으로 분리한 인과 실험은 아니다. ACK도 명령/frame 결합 확인이지 물리 응답의 증명은 아니다.

## 진행 현황과 다음 실행 단위

전체 로드맵 9영역/30기능 중 이번 작업은 기본 주행의 **속도 추종·신호등 정지·목표 정지에 필요한 데이터 품질**이다. 자체 학습 모델의 승인된 closed-loop 기능은 여전히 0/30이다. 이번에 기능 완료 수나 모델 성능이 늘었다고 계산하지 않는다.

1. 수집 종료 시 이동 중 바로 full-brake tail로 전환하는 경로를 분리한다. 목표 도달과 정지 완료를 구분하고, 기존 엄격한 정지 QA를 만족하는 종료 절차를 별도 연구 프로파일에서 검증한다.
2. 신호등 긴급 제동을 약하게 만드는 대신, 경로상 관련 정지선과 거리·신호 상태를 사용해 더 일찍 정상 감속하도록 설계한다. 원래 긴급 제동은 그대로 남긴다. 다른 차선 신호를 잘못 선택하거나 BasicAgent의 cache를 오염시키지 않는 테스트가 선행돼야 한다.
3. 속도 tensor의 순간값/구간값 의미를 학습 라벨, decoder, runtime 적분/가속도 검사 전체에서 맞춘다. 현재 gate에 맞추려고 순간 속도를 평균값으로 바꾸거나 threshold만 늘리지 않는다. 물리적으로 타당한 궤적과 잘못된 속도 신고를 각각 검증하는 fixture를 확장한다.
4. 새 수집 데이터가 전체 물리·카메라·시간·경로 검증을 통과한 뒤에만 원격 개인 venv/GPU0에서 재학습한다. 고정 DEV/TEST 유지, 동등 학습 노출량 비교, 로컬 learned closed-loop 평가 순서다.

다음 구현+단일 경로 실험은 대략 30~60분 작업 범위이며 실패 여부에 따라 늘어난다. 실제 학습 시간은 데이터 승인 후 산정한다. 현재 원격 학습은 시작하지 않았으며 GPU1·전역 설치·기존 테스트·공용 수집기·runtime gate는 변경하지 않았다. 정확한 청구 토큰 수/잔액은 확인할 수 없다.
