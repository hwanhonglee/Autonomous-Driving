## 한눈에 보는 결론

**큰 우회전 두 장면에서, 회전 전에 감속하고 회전 뒤까지 진행하는 기준 경로를 만들었습니다. 기존 안전 검사도 통과했습니다. 다만 아직 모델이나 차량이 그렇게 주행한 것은 아닙니다.**

지난 U에서는 검사에 통과한 느린 경로가 회전을 일부만 진행했습니다. 이번 V에서는 회전 이후까지 계산을 이어갔습니다. 정해진 경로를 완벽하게 따라간다는 가정 아래 얻은 결과이며, 실제 조향 제어·차량 동역학·카메라 인식은 포함하지 않습니다.

## 이번에 바꾼 것

1. 경로를 부드럽게 만든 **뒤에 실제 길이를 다시 계산**했습니다. 위치는 멈췄는데 출력 속도는 남는 문제를 피하도록 끝점 정지도 포함했습니다.
2. 앞쪽 커브의 곡률에서 허용 속도를 계산하고, 그곳에 도착하기 **전부터 감속**하도록 속도 계획을 역방향으로 계산했습니다.
3. 입력에 있는 경로 끝까지 계산한 뒤, 매 0.1초마다 다음 6.4초 경로를 차량 기준 좌표로 바꾸어 기존 검사에 넣었습니다. 검사 기준은 완화하지 않았습니다.
4. 측정된 현재 속도에서 시작할 수 없는 장면은 속도를 임의로 낮추지 않고 거부했습니다.

이 코드는 연구용 별도 스크립트입니다. 운영 모델, 데이터 라벨, Autoware 제어 코드는 변경하지 않았습니다.

총 **6개 장면 중 4개에서 기준 경로 계산 및 모든 구간 검사 통과**, 2개는 초기 속도 조건으로 거부됐습니다. 624개 검사 구간은 서로 겹치는 구간이지 독립 주행 624회가 아닙니다. 거부된 장면이 물리적으로 어떤 방식으로도 주행 불가능하다는 뜻도 아닙니다.

회전 범위 판정은 시작 방향 대비 **85도 이상 변화한 지점에서 추가로 3 m 진행**하는 조건입니다. 정확한 교차로 출구나 차선 경계를 확인한 판정은 아닙니다. 두 주요 우회전은 그림에서 회전 뒤 직선까지 이어지며, 커브 구간의 계획 속도는 대략 10–13 km/h입니다. **30 km/h로 회전 성공했다는 결과가 아닙니다.**

![회전 경로와 사전 감속 속도 계획](evidence/right_turn_reference.png)

왼쪽은 계산된 경로, 오른쪽은 진행 거리에 따른 속도입니다. 보라색 점선은 위의 회전 범위 판정 지점입니다. 이 그림은 CARLA 화면이나 주행 촬영이 아닙니다.

## 무엇이 아직 안 됐나

- 새 모델 학습, 미학습 지도 평가, CARLA 폐루프 주행은 이번에 하지 않았습니다. 모델 성능이 개선됐다는 증거는 아직 없습니다.
- U의 6.4초 결과와 달리 이번에는 제공된 경로 전체를 사용했습니다. 같은 시간 범위의 학습 성능 A/B 비교가 아닙니다.
- 경로 평활화가 차선 안에 머무는지, 장애물과 충돌하지 않는지 확인하지 않았습니다. 도로 경계와 충돌 검증이 필요합니다.
- 속도 계획은 곡률에 민감해 작은 출렁임이 남습니다. jerk, 실제 조향 응답, 지연, 마찰, 횡미끄러짐은 검증하지 않았습니다.
- 기존 모델의 내부 곡률 제약을 복원한 것이 아닙니다. 별도 기준 경로를 기존 외부 검사로 검증한 것입니다.

## 전체 작업에서 현재 위치와 다음 순서

현재는 **기본 주행 중 곡선·우회전 경로 및 속도 조절**을 회복하는 단계입니다. 이번 실험으로 전체 9개 영역·30개 기능의 완료 수가 증가한 것은 아닙니다. 자체 모델 폐루프 승인 완료 0/30이라는 기존 상태를 바꾸지 않습니다.

다음은 이 기준 경로가 실제 학습 목표로 적합한지 확인하는 단계입니다. 차선·도로 경계 이탈을 확인하고, 빠른 진입으로 거부된 장면은 앞선 시점부터 감속하는 데이터가 필요한지 조사해야 합니다. 검증되지 않은 6개 장면을 그대로 정답 라벨로 덮어쓰거나, 이것만 반복 학습해 전체 주행 성능을 기대하지 않습니다.

그다음 검증된 목표를 학습용 데이터로 구성하고 원격 GPU 0에서 기존 모델과 동일 조건으로 학습·평가합니다. 고정 미학습 평가를 통과한 후보만 로컬 CARLA 주행 대상으로 삼습니다. 추가 기능 헤드보다 기본 회전 성능 회복을 우선합니다.

## 실행 환경·비용·재현

- 이번 작업: 로컬 CPU만 사용. SSH 접속, GPU 사용, 설치, 다른 테스트 중단 없음.
- 원격 학습을 시작하지 않았으며, 이번 작업 때문에 백그라운드 학습이 돌아가는 것도 아닙니다.
- 테스트 9개 통과. 수치 실험 자체는 수 초 이내이며 10.7초·13.4초 등은 계산된 주행 시간이지 GPU 학습 시간이 아닙니다.
- 계정 잔량과 실제 과금 토큰은 확인할 수 없어 보고하지 않습니다. 이후 학습 시간은 실제 데이터 수·학습 속도 확인 후 산정해야 합니다.
- 최종 결과: `artifacts/training/2026-09-22/curvature_preview_v_v2/{results,traces}.json`. `results.json`에 입력·스크립트 SHA256과 실패 원인을 보존했습니다.
- `curvature_preview_v_v1`은 정지 구간 시간 보간 수정 전 결과이며 비교용으로 보존했습니다. 위 표는 v2만 사용합니다.

저장소 루트에서 재현합니다. 출력 폴더는 새 이름을 사용해야 합니다.

```bash
python3 -m pytest -q tests/test_curvature_preview_v.py tests/test_arc_retiming_u.py tests/test_decoder_turn_probe_t.py
PYTHONPATH=. python3 scripts/e2e/probe_curvature_preview_v.py \
  --metadata artifacts/training/2026-09-22/arc_progress_u_v1/input_metadata.json \
  --output artifacts/training/2026-09-22/curvature_preview_v_recheck
```

위 입력 원자료와 기존 프로젝트 의존성이 필요합니다. 이 문서만으로 새 PC에서 곧바로 실행 가능한 것은 아닙니다.
