## 이번 결과

## 무엇을 확인했나

- 약 2 cm 간격의 평활 경로 점을 원래 경로의 모든 선분에 투영해 가장 가까운 거리를 계산했습니다. 10 Hz 점만 확인하지 않았습니다.
- 로컬 계산과 원격 데이터 파일의 읽기 전용 확인만 수행했습니다. GPU, 시뮬레이터, 학습, 패키지 설치, 다른 프로세스 변경은 없습니다.
- 원격의 두 해당 에피소드 `route_geometry.json`은 `route_id`, `frame_id`, `polyline_m`만 포함합니다. 이 파일 자체에는 차선 폭이나 경계 폴리곤이 없습니다.
- 로컬에는 `/home/a/carla/Import/C_track_1_0_7.xodr`가 있으나, 수집 당시 지도와 동일한지 아직 연결하지 않았습니다. 확인한 `/home/a/carla`, `/home/a/autoware_data` 파일 검색에서는 Town01 XODR를 확보하지 못했습니다. 모든 위치에 지도 파일이 없다는 뜻은 아닙니다.
- 근접도 검사 및 앞선 V 관련 테스트: **8 passed**.

## 다음에 필요한 것

1. 두 에피소드의 원본 수집 기록에서 지도 버전·해시와 각 샘플의 map→ego 변환을 연결합니다.
2. 일치하는 지도에서 주행 차선 경계와 교차로 연결 관계를 확보합니다. 다른 테스트가 실행 중인 CARLA의 맵을 바꾸지 않습니다.
3. 차량 크기를 포함해 회전하는 차체가 경계 안에 들어가는지 확인합니다. 점 하나의 근접도만으로 통과시키지 않습니다.
4. 이를 통과한 경로·속도만 별도의 연구용 학습 후보로 구성합니다. 기존 라벨은 덮어쓰지 않습니다.

현재 진행 부분은 기본 주행의 회전 경로·속도 검증입니다. 추가 기능을 완료한 것은 아니며, 모델 가중치와 전체 기능 완료 수는 이번에 달라지지 않았습니다. 차선 검증에 필요한 자료가 확보되지 않았으므로 이번에는 모델 학습을 시작하지 않았습니다.
