## 이번에 확인한 것

**지도와 샘플 차량 위치를 연결했습니다. V에서 계산한 4개 경로의 12,666개 기준점은 현재 로컬 지도에서 모두 주행 차선 안으로 조회됐습니다.** 이전 W의 “원래 경로와 가깝다”보다 한 단계 더 확인한 결과입니다. 차량 전체가 안전하게 통과한다는 판정은 아직 아닙니다.

| 대상 | 검사한 기준점 | 주행 차선 밖으로 조회된 점 | 참고: 가장 가까운 차선의 횡방향 반폭 잔여량 최솟값 |
|---|---:|---:|---:|
| C_track 좌회전 000031 | 6,000 | 0 | 1.57 m |
| Town01 우회전 000440 | 2,363 | 0 | 1.72 m |
| Town01 우회전 000464 | 2,352 | 0 | 1.72 m |

마지막 열은 **차체를 뺀 여유 폭이 아닙니다.** 가까운 차선 중심에서 기준점까지의 횡방향 거리를 차선 반폭에서 뺀 값입니다. 교차로에서 가장 가까운 차선이 원래 의도한 차선과 같다는 보장도 없습니다. 초기 속도로 거부된 다른 2장면은 그대로 유지했습니다.

## 어떻게 연결했나

- 수집 기록에 남은 설치 경로의 `CarlaUE4/Content/Carla/Maps/OpenDrive/`에서 Town01과 C_track_1_0_7 XODR를 찾았습니다.
- 원격 개인 데이터에서 선택된 6개 TRAIN 샘플의 `map → base_link` 위치·자세를 읽었습니다. 샘플 파일, 경로 파일, 출처 파일, 수집 설정 파일을 에피소드에 기록된 SHA256과 대조했습니다.
- ROS의 y축과 CARLA의 y축 방향 차이를 반영해 경로를 지도 좌표로 옮겼습니다. 변환 단위 테스트를 포함해 관련 테스트 10개가 통과했습니다.
- 두 에피소드의 수집 당시 `route.json` 원본을 로컬에서 SHA256으로 찾았습니다. 단순히 이름이 비슷한 파일을 선택하지 않았습니다.
- `carla.Map`으로 XODR만 읽었습니다. CARLA 서버에 접속하거나 맵 로딩, tick, 차량 생성, 제어 명령을 실행하지 않았습니다. 설치나 GPU 사용도 없습니다.

## 아직 남은 두 가지

### 1. 수집 당시 지도와 완전히 같은지

원본 경로를 현재 지도에 투영하면 Town01 233점 중 6점, C_track 216점 중 7점에서 도로·차선 ID가 다르게 조회됩니다. Town01의 6점은 교차로 또는 그 연결 지점에 있고, 위치 차이는 약 0–0.00041 m입니다. 겹치는 교차로 연결 차선의 최근접 선택 때문일 가능성이 있지만 **아직 원인 확정은 아닙니다.** C_track도 개별 불일치를 원자료에 보존했습니다.

현재 지도 해시는 기록했지만, 수집 당시 XODR 해시를 대조한 것은 아닙니다. 따라서 `historical_map_identity_verified=false`를 유지합니다. 원본 route 파일이 일치한다는 사실과 전체 지도 버전이 일치한다는 사실은 다릅니다.

### 2. 차체 전체와 회전 중 모서리

현재 검사는 경로의 base_link 기준점입니다. 수집 차량은 Prius이고, 수집 기록에는 휠베이스 2.85 m가 있지만 이것만으로 차체 길이·폭·기준점 오프셋을 확정할 수 없습니다. 주변 Autoware sample 차량 설정을 확인했으나 휠베이스가 3.0 m여서 그대로 대입하지 않았습니다.

다음은 해당 Prius의 실제 bounding box 또는 일치하는 차량 치수·기준점을 확보하고, 의도한 차선 연결 관계를 따라 차량 외곽을 검사하는 것입니다. 고정 초기 높이를 전체 경로에 사용한 현재 조회는 입체 교차 구간 검증에도 충분하지 않습니다.

## 학습과 전체 진행 상황

이번 진전은 **지도 위 경로 기준점 검증**입니다. 모델 본학습·CARLA 폐루프 성능 향상·추가 자율주행 기능 완료를 뜻하지 않습니다. 검증되지 않은 라벨은 추가하지 않았고 학습 승인 수는 아직 0입니다. 기본 회전 성능 회복 작업을 진행 중이며, 차량 외곽 검증을 마친 기준 경로를 연구용 학습 목표로 구성하는 순서입니다.

로컬에서는 지도 계산, 원격에서는 개인 데이터 읽기만 했습니다. 다른 테스트, GPU 0/1, 기존 모델 가중치는 변경하지 않았습니다. 계정 사용량·토큰 잔액은 확인할 수 없습니다.
