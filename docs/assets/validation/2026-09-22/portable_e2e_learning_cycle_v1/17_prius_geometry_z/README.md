# Prius 실측 완료 — 네 경로의 차체 외곽 표본에서 주행 차선 밖 점 없음

## 이번 결과

별도 소유 CARLA 세션에서 `vehicle.toyota.prius`를 생성해 bounding box를 측정했습니다. 주행 명령은 내리지 않았고 측정 시 물리를 비활성화했습니다. 측정용 차량과 서버는 종료했습니다.

| 항목 | 측정값 |
|---|---:|
| bounding box 길이 | 4.513523 m |
| bounding box 폭 | 2.006814 m |
| bounding box 높이 | 1.524833 m |
| actor 기준 box 중심 x | 0.001992 m |
| actor 기준 box 중심 y | -0.000391 m |
| box 회전 | roll/pitch/yaw 모두 0 |

기존 수집기의 좌표 변환은 actor 중심에서 뒤로 휠베이스/2를 옮긴 base_link입니다. 해당 수집값 2.85 m를 사용해 실제 box를 같은 기준으로 옮겼습니다. 휠베이스를 새로 실측한 것은 아닙니다.

## 차량 외곽 검사

차체 외곽을 최대 약 0.2 m 간격의 72개 점으로 표현하고, V의 약 0.02 m 간격 경로 위치마다 경로 접선 방향으로 회전시켜 검사했습니다.

| 경로 | 차량 위치 표본 | 외곽 점 중 주행 차선 밖으로 조회된 점 |
|---|---:|---:|
| C_track 좌회전 000031 | 6,000 | 0 |
| Town01 우회전 000440 | 2,363 | 0 |
| Town01 우회전 000464 | 2,352 | 0 |
| Town01 우회전 000487 | 1,951 | 0 |

총 **911,952회 점 조회에서 주행 차선 밖으로 조회된 점은 없었습니다.** 경로 기준점만 확인하던 X에서 차체 크기를 반영한 외곽 표본 검사까지 진행한 것입니다.

하지만 다음은 아직 증명하지 않았습니다.

- 조회는 **어느 주행 차선이든 안에 있는지** 검사합니다. 인접 차선이나 다른 교차로 연결 차선으로 넘어가지 않는다는 엄격한 의도 차선 검사가 아닙니다.
- 유한한 외곽 점 검사이며 연속 차체 이동 영역 전체의 포함 증명은 아닙니다.
- 차량 방향은 경로 접선으로 가정했습니다. 실제 조향 지연·미끄러짐·추종 오차와 차체 기울기는 포함하지 않습니다.
- 현재 Prius 자산을 측정한 것이며 수집 당시 차량 자산의 해시 동일성은 미확인입니다.
- 초기 높이를 사용한 평면 검사이므로 고저차가 있는 입체 교차 검증에는 부족합니다.

따라서 **차체가 도로 밖으로 크게 벗어나는 경로라는 증거는 이번 검사에서 없지만, 실제 주행 성공이나 학습 정답 승인으로 세지 않습니다.** `full_containment_proven=false`, `training_admitted=false`를 유지했습니다.

## 실패와 종료 상태

첫 Low 품질 시도에서는 물리 비활성화 후 `get_physics_control()` 조회 중 서버 Signal 11과 RPC timeout이 발생했습니다. 순서 또는 품질 중 어떤 요인이 원인인지는 분리 실험하지 않았습니다. 실패 자료를 삭제하지 않았습니다.

두 번째 시도는 필요 없는 물리 제어 정보 조회를 제거하고 Epic 품질·포트 2310으로 실행했습니다. 측정 완료 후 ready/after_capture/stopped 상태 확인이 모두 통과했습니다. 포트 2300 재사용은 소유 래퍼가 거부해 다른 포트를 사용했으며 기존 프로세스를 강제 종료하지 않았습니다.
