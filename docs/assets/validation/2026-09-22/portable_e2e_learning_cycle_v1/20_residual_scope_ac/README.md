## 이 정도까지 해야 하는가

실차 투입이나 검증된 정답 경로 채택에는 차체·차선 검증이 필요합니다. 그러나 기본 주행 모델을 연구하고 기존 데이터로 학습하는 단계에서, 이번 연구용 경로의 모든 미세 초과를 먼저 해결해야 하는 것은 아닙니다. 이 검사를 연속해서 학습의 선행 조건처럼 다룬 것은 과했습니다.

큰 모서리 이탈을 찾아 종단 목표가 약 27.6 cm 틀어진 부분을 확인한 작업은 유용했습니다. 이후 남은 미세량 분석은 별도 항목으로 관리하고, 기존 모델 학습·미학습 데이터 평가를 막는 조건으로 삼지 않습니다. 이는 안전 검사를 통과했다고 바꾸는 조치가 아닙니다.

## 이번에 확인한 잔여 형상

AB에서 저장한 최대 초과 자세의 차집합을 분석했습니다.

| 대상 | 초과 형상을 감싸는 최소 회전 직사각형 | 해석 |
|---|---|---|
| Town01 세 장면 | 약 0.344 mm × 2.02 m | 매우 가는 띠. 경계 연결/근사 영향 가능성이 있지만 확정하지 않음 |
| C_track | 약 2.97 cm × 1.00 m | Town01보다 큰 잔여 형상. 별도 검증 필요 |

이 수치는 차량의 최대 침범 깊이가 아니라 **잔여 형상을 감싸는 직사각형 치수**입니다. 닫힌 내부 구멍에 속한 초과 면적은 모두 0이었습니다. 외부와 연결된 틈인지 실제 측면 초과인지는 이 검사만으로 확정되지 않습니다. 따라서 “구멍이니 무시해도 된다”는 결론을 내리지 않았습니다.

## 이후 진행 기준

1. 이번 합성 기준 경로는 연구 후보로 보존합니다. 원본 라벨을 교체하거나 승인된 정답으로 넣지 않습니다. 특히 AB는 목표점도 바꾸었습니다.
2. 기존 데이터와 체크포인트를 대상으로 모델 학습을 재개할 수 있습니다. 시작 전 현재 체크포인트·데이터 구성·원격 GPU 0 점유 상태를 확인해야 합니다. 이번 턴에서 학습을 실행한 것은 아닙니다.
3. 학습 결과는 고정된 미학습 직진·좌회전·우회전 평가와 기존 모델 비교로 판단합니다. 이미 평가에 사용한 장면을 학습 데이터로 돌려 넣지 않습니다.
4. 유망 후보만 로컬 CARLA 폐루프 검증으로 넘깁니다. 엄격한 차선·차체 안전 검증은 배포 승인과 구분해 유지합니다.

우선순위는 미세 검사 추가보다 **모델의 기본 주행 성능 개선**입니다. 새 기능 헤드나 실차 배포로 범위를 넓히지 않습니다. 전체 기능 완료 수는 이번 분석으로 늘지 않았습니다.
