## A. 주행 AE — 무엇을 바꿨나

기존 K1에서 전체 가중치를 초기화하고 15,000 step, batch 4, LR 3e-5로 이어 학습한다.
기존 TRAIN 2,787개·샘플링·모델 구조는 유지한다. AD는 같은 조건에서 원래 손실만 사용한 비교 자료다.

원래 손실에 두 항목을 추가했다.

1. **후보 선택:** TRAIN 정답과의 XY 평균 오차 + 0.2×속도 오차가 작은 후보에 높은 점수를 주도록
   soft target을 사용한다. 온도 0.5, 가중치 0.2. 정답 cost는 detach하여 후보를 악화시켜 순위를 속이는 직접 gradient를 막는다.
2. **잘하던 장면 보존:** 동결 K1이 TRAIN에서 선택한 궤적이 ADE <0.75m 및 속도 MAE <0.5m/s인 경우만
   기존 선택 후보의 XY·속도·점수 분포를 보존하는 항목을 더한다. 가중치 0.5.

좋은 장면을 보존하려는 설계이지 직진/정지 보존을 보장하는 것은 아니다. 별도 정지 DEV가 없고
현재 반복 관측한 Town03 DEV 665개에는 좌회전도 없다. 결과가 좋아도 승인하거나 배포하지 않는다.
손실의 두 변화를 함께 넣은 목표 지향 실험이며 각각의 인과 효과를 분리한 A/B는 아니다.

모델 구조·기능 head는 그대로이며 teacher만 동결하고 student 전체는 학습한다.
optimizer는 초기화한다. 후속 재현을 위해 최종 optimizer 상태는 checkpoint와 별도 파일로 보관한다.
학습 중 DEV 조기 종료/체크포인트 선택 없음. 완료 시 기존 K1 비교·strict gate를 자동 평가한다.
