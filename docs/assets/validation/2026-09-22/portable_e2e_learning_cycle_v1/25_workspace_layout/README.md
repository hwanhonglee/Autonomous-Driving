## 결과

16개 원본 디렉터리를 이동하고 디렉터리 inode 유지 확인, 데이터 삭제 없이 임시 호환 링크를 남겼습니다.

**레거시 제거는 아직 미완료: 16개 → 최종 목표 0개.** VS Code에서 숨김과 삭제는 다릅니다.
