## 지도: 새 장면을 추가하고 같은 평가 자료로 비교

- 기존 TRAIN 114장 → p03 경로 187장 추가 **301장** → p01 경로 196장 추가 **497장**.
- DEV 118장의 파일 바이트·목록·라벨은 그대로 유지했습니다. DEV를 학습에 넣지 않았습니다.
- 신규 p03/p01과 기존 DEV 위치 간 최소 거리는 각각 **184.2 m / 365.4 m**입니다.
- 기존 TRAIN과 신규 위치 간 최소 거리도 **212.6 m / 171.9 m**입니다. 위치 분리가 독립 Town 일반화를 보장하지는 않습니다.
- p03은 학습용 표지판 픽셀 0개, p01은 선택된 학습 프레임에 **56,637개**가 있어 표지판 보강을 실제로 수행했습니다.
  p01 전체 240프레임의 60,608개와 중복 위치를 제외한 TRAIN 픽셀 수는 다릅니다. 픽셀 수는 독립 객체 수가 아닙니다.
- 수집은 각각 240프레임, 이동 75.1 m / 79.1 m, 충돌 0회, live/replay 일치였습니다.
- 두 지도 수집은 빈 가상환경에서 신호등 무시 옵션을 명시적으로 사용했습니다. **제어 학습 자료로 사용하지 않습니다.**

학습 모델은 동일한 작은 RGB 의미 분할 구조(130,503개 파라미터)입니다.
각 실험은 같은 seed로 **새 초기화**, 2,000 optimizer step, batch 8, LR 3e-4, 640×360 입력입니다.
이전 체크포인트는 비교에만 사용하며 이어 학습한 것이 아닙니다. 학습 자료가 늘면서 TRAIN 기반 클래스 가중치도
다시 계산되므로 단순히 프레임 수만 바뀐 인과 실험이라고 주장하지 않습니다.
TRAIN 확대 crop은 유지하고 DEV 증강은 하지 않았습니다.

첫 추가 학습 AI v1은 전체 IoU와 차선을 개선했지만 표지판이 0%로 악화됐습니다.
그 결과를 확인하고 표지판이 있는 두 번째 경로를 추가하여 AI v2를 실행했습니다.
최종 수치는 [지도 비교표](mapping_comparison.md)에 기록합니다.
최종 AI v2는 AH 대비 native mIoU **55.24→60.12%**, 차선 **82.29→91.23%**,
표지판 **0.49→3.16%**입니다. 표지판·신호등은 여전히 낮고, 320×180에서는 차선 비퇴행도
AI v1 대비 실패하므로 모든 조건에서 개선됐다는 결론은 아닙니다.

## 주행: 우회전 자체는 했지만 좋은 학습 자료는 아님

처음에는 폴더 구조 정리 이후 실행기의 Python 패키지 문맥이 빠져 수집 전에 실패했습니다.
실행도 사전 검사와 같은 모듈 방식으로 바꾸고, 해당 오류 재발 검사를 포함한 관련 테스트 **82개**를 통과했습니다.
수집기 본체와 안전 기준은 변경하지 않았습니다. 두 실패 기록은 별도로 보존했습니다.

재수집에서는 **우회전 후 목표에 도착**, 경로 진행 75.18 m / 76.16 m, 충돌 0회, 차선 침범 센서 이벤트 0회였습니다.
이는 차량 전체가 목표 차로 내부에 있었다는 독립 검증이나 자체 모델의 회전 성공을 뜻하지 않습니다.
BasicAgent가 운전했고 자체 모델은 제어하지 않았습니다.

탈락 이유는 20 Hz 측정 속도의 급변입니다.

- 출발 가속 최대 **+4.06 m/s²**: 기존 decoder 기준 +2.9 초과.
- 정지 접근 감속 최소 **−16.51 m/s²**: 기존 decoder 기준 −2.9 초과.
- 카메라 기준 10 Hz에서도 감속 **−7.60 m/s²**, 두 구간이 기존 감속 검사에서 탈락했습니다.
- 947개 제어 명령 ACK는 성공했고 정렬 오류 0회였습니다. 명령 전달 성공과 물리 거동 품질은 별개입니다.
- 종단 구간에서 가속 페달과 브레이크가 번갈아 적용되고 제동 시 속도가 급감했습니다.
  원시 기록으로 확인한 관측이며, 타이어·수치 물리·제어기의 개별 인과 기여까지 분리한 것은 아닙니다.

## 다음 순서와 비용 범위

1. **주행 우선:** 출발 페달 전환과 종단 제동 진동을 별도 제어 A/B로 줄이고, 같은 물리/10 Hz 검사로 재수집합니다.
   이미 존재하는 개발용 정지 프로파일의 결과·제한을 검토해 검증된 부분을 재사용합니다. 검사를 통과시키려고 기준을 낮추지 않습니다.
   한 차례 원인 분리·수집·검사는 약 **30~90분의 연구 범위**이며 성공 보장 일정은 아닙니다.
2. 유효한 이동 회전 자료가 확보되면 기존 직진 자료와 함께 재학습합니다.
   기존 AH 실측은 15,000 step에 약 30분, 평가·회수 포함 **30~40분**입니다. 새 자료 규모에 따라 달라집니다.
   직진 유지와 회전 후보 선택 오차 감소를 함께 확인합니다.
3. 지도는 표지판/신호등 개선과 차선 비퇴행을 확인한 뒤, 사용하지 않은 Town·날씨 평가를 확장합니다.
   반복 확인한 현재 DEV 점수만으로 모델을 배포하지 않습니다. 10 Hz 통합 실행과 실차 전이는 별도 단계입니다.

토큰은 실행 전 정확하게 알 수 없으므로 사용량이나 비용을 실측인 것처럼 적지 않습니다.
후속 원인 분리·A/B·정리 한 묶음의 작업량은 대략 **1만~2만 토큰의 계획 범위**이며, 실패 원인/로그량에 따라 증가할 수 있습니다.
원격 GPU의 학습 시간과 대화 토큰 사용량은 같은 지표가 아닙니다.
