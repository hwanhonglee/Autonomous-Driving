# 지도 AH 후속 검사 — 인식 부족과 로컬 처리 시간

<!-- HH_260906 - Separate measured inference throughput from full-pipeline latency and mapping quality. -->

## 결론

**학습은 완료됐지만, 지도 인식 품질과 로컬 전체 10 Hz 모두 아직 충족했다고 볼 수 없습니다.**
새 학습을 무작정 반복하거나 이 모델을 주행 판단에 붙이지 않습니다.

| 항목 | AH 측정 결과 | 다음 우선 작업 |
|---|---:|---|
| 신호등 설치물 픽셀 precision / recall | 14.85% / 17.34% | 근접·다른 배경의 신호등 TRAIN 자료 보강 |
| 표지판 픽셀 precision / recall | 0.63% / 2.16% | 작은 표지판과 표지판이 아닌 배경을 함께 확보 |
| 노면 표시 픽셀 precision / recall | 82.91% / 99.10% | 과검출 확인, 해상도 변경 시 차선 보존 |
| 로컬 CPU 2스레드 추론 P50 / P95 | 103.01 ms / 105.07 ms | 유망 모델 확보 후 별도 가속 실행 경로·전체 지연 계측 |

precision은 해당 클래스로 예측한 픽셀 중 맞힌 비율이고, recall은 실제 해당 클래스 픽셀 중 찾은 비율입니다.
객체 개수 기준 검출률이나 신호등 상태 인식 성공률이 아닙니다.

정답 영역 크기별로 보면 1–4픽셀 신호등 영역의 픽셀 recall은 1.71%, 같은 크기의 표지판은 0%입니다.
65픽셀 이상 영역에서도 신호등 17.91%, 표지판 7.80%입니다. 작은 크기 문제만이 아니라 더 큰 영역에서도
인식이 부족합니다. 이 수치만으로 원인을 데이터·모델 중 하나로 확정하지 않습니다.
영역은 프레임별 8방향 연결 정답 픽셀 덩어리이며, 물리 객체나 추적 ID와 일치하지 않을 수 있습니다.
같은 객체의 반복 프레임을 독립 객체 수로 세지 않습니다.

## 로컬 처리 시간의 범위

현재 설치된 로컬 Torch 1.8.0a0, CPU 2스레드, 배치 1, 640×360 RGB, warmup 10회 후 50회입니다.
GPU는 사용하지 않았고 새 패키지도 설치하지 않았습니다. 원격에서 학습한 체크포인트와 모델 소스 SHA를
확인한 뒤 기존 로컬 Torch API에 맞춰 로드했습니다. 첫 진단 실행의 최신 Torch 전용 옵션 오류를 해결한
호환 처리이며 학습 가중치·모델 연산 정의를 바꾸지 않았습니다.

포함: 메모리 RGB 변환/정규화, 모델 forward, 클래스 argmax.
제외: 디스크 영상 해독, 카메라 전송, 동기화, ROS, 지도 누적, 주행 제어.
따라서 105.07 ms를 전체 파이프라인 지연으로 보거나 GPU 추론 속도로 해석하면 안 됩니다.
해상도를 낮추면 속도가 나아질 가능성은 있지만 이번 모델의 저해상도 차선 퇴행을 함께 해결해야 합니다.

## 다음 단계

1. TRAIN 전용 경로에서 가까운 신호등·표지판, 차선, 혼동 배경을 추가 수집합니다. DEV/TEST는 편입하지 않습니다.
2. 클래스 픽셀 수뿐 아니라 고유 경로·날씨·객체 크기·반복 프레임 중복을 집계해 데이터 구성을 확인합니다.
3. 같은 평가 조건에서 재학습 전후 클래스별 정확도와 기존 도로/차선 퇴행을 비교합니다.
4. 품질이 유망한 후보만 가속 추론과 전체 10 Hz 계측으로 넘깁니다. 정밀지도 누적·실차 승인은 별도입니다.

위 항목은 후속 계획이며 이번 문서 작성으로 신규 CARLA 자료를 수집했다는 뜻이 아닙니다.
