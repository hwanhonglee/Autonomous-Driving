# 주행 AM — 회전 중심 추종 개선, 저속 미래 궤적은 여전히 실패

<!-- HH_260906 - Separate a successful high-speed turn diagnostic from failed full-horizon data admission. -->

**같은 Town01 우회전 9 km/h에서 `base_link` 기준 제어와 횡방향 PID `K_P=1.70`을 결합하자 회전 중 2 m/s 이상 곡률 위반이 0개가 됐습니다.** [사전 선언](PLAN.md)의 중심선 오차 기준도 통과했습니다. 그러나 출발·목표 근처의 저속 위치 기반 곡률 위반은 전체 30개 *실제 100 ms 시점*에 남습니다. 따라서 **이번 회차도 학습 자료로 승인하지 않았고, 주행 모델 가중치를 갱신하지 않았습니다.** 주행자는 CARLA BasicAgent이며 자체 Portable E2E 모델이 아닙니다.

AM의 회전 중 경로 오차는 사전 기준 평균 ≤0.10m·최대 ≤0.30m를 만족합니다. AL보다 조금 증가했지만 AK보다 작습니다. 위 2m/s 진단은 **원래 6.4초 전체 계약의 대체가 아닙니다**. AM의 나머지 위반은 출발 저속 3개 시점과 목표 근처 27개 시점입니다. [원본 위치·yaw·조향의 저속 대조](low_speed_diagnosis.md)에 따르면 목표 근처 상당수는 미래 첫 점의 이동 방향/거리 계산에 민감하지만, 일부는 여러 창에서 반복됩니다. 따라서 수치 민감도만으로 모든 실패를 지울 수 없고 원본 미래 라벨을 지우거나 한계를 올릴 근거도 아닙니다.

AM의 [소유 실행 결과](../../../../../storage/experiments/training/2026-09-27/drive_control_am/lateral_kp_170/owner_result.json)는 종료 코드 0, 코드와 설치된 CARLA 제어 소스의 실행 전후 해시 일치, 수집 완료입니다. **3,846장 원본 JPEG 전수 디코딩**, 카메라/상태·명령 정렬 불일치 0, 충돌·차선 침범 센서 이벤트 각각 0, 물리 20 Hz와 카메라 10 Hz 속도 변화율 위반 0입니다. 차선 센서 0은 차량 몸체 전체가 차로 내부였다는 증거가 아닙니다. [원본 전체 감사](final_audit/summary.json)에는 AK/AL/AM 동일 계산과 raw SHA·모든 6.4초 미래 창이 있습니다. 571/575/576개 등 중첩 미래 *시작점* 수는 독립 사건 수가 아니므로 위 표는 고유 100 ms 시점을 사용했습니다.
