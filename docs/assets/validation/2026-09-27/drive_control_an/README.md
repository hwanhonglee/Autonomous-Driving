# 주행 AN — 목표 근처 곡률 초과 27→3시점, 전체 학습 계약은 여전히 실패

**같은 Town01 p03 9 km/h 우회전에서 목표 1 m 창의 정상 조향만 0으로 제한하자, 목표 근처의 서로 다른 100 ms 곡률 초과 시점이 AM 27개에서 AN 3개로 줄었습니다.** 회전 본구간의 추적·속도는 그대로였지만 출발 3개와 목표 근처 3개가 남아 **원래 6.4초 미래 궤적 계약은 실패**했습니다. 이번 것도 CARLA **BasicAgent** 주행입니다. Portable E2E 주행 모델 학습·가중치 갱신·모델 폐루프 운전이나 실차 승인이 아닙니다. [실행 전 선언](PLAN.md)의 한 변수와 원래 한계를 유지했습니다.

`실제 100 ms 시점`은 겹치는 6.4초 미래 창을 중복 제거한 수입니다. 미래 창의 시작점 127개나 위반 단계 354개를 서로 독립적인 사고로 세지 않았습니다. AN의 목표 근처 남은 초과는 episode tick 551·552·556이며 **모두 여러 미래 창에서 반복**됩니다. tick 556은 제동 전후 약 1.64 mm 이동의 방향 변화가 곡률 계산에서 122.99/m로 커진 경우입니다. 그 값은 AM의 최고값보다 높으므로 “전부 해결” 또는 “물리적으로 더 안전함”으로 해석하지 않습니다. 출발 초과 tick 53·54·59는 AM과 AN에서 값과 시점까지 동일합니다. [원본 위반점 비교 그림](curvature_witness_comparison.png)의 빨간선은 변경하지 않은 **0.2/m** 계약입니다.

AN의 적용 기록에서 측정 목표 창 안의 **71개 정상 명령 모두** `steer=0`이 됐습니다. 목표 진입 직후 속도 0.200492 m/s인 1개 명령은 사전 한계 0.20 m/s보다 높아서 변경하지 않았습니다. 회전 구간 적용 0개, AM과 AN의 회전 중심선 오차와 평균 속도는 같은 소수점 범위였습니다. 한 개의 동일 환경 A/B이므로 다른 맵·기상·속도에 일반화됐다는 뜻은 아닙니다. 저속 좌표의 정밀도와 `base_link`/차체 기준점 영향도 남아 있습니다.

## 검증 범위와 남은 일

<!-- HH_260906 - Preserve both the capture provenance and the original geometry failure. -->

[소유 실행 결과](../../../../../storage/experiments/training/2026-09-27/drive_control_an/goal_window_020_zero/owner_result.json)는 종료 코드 0, 수집 코드 15개와 설치된 CARLA `local_planner.py`·`controller.py`·`basic_agent.py` 3개의 실행 전후 해시 일치, CARLA 시작·종료 상태 PASS를 기록합니다. [원본 감사 요약](final_audit/summary.json)은 **3,846장 JPEG 전수 디코딩**, 카메라·상태/명령 정렬 불일치 0, 충돌/차선 침범 센서 이벤트 0, 20/10 Hz 속도 변화율 위반 0, 원래 6.4초 미래 창 576개 전체 계산을 확인합니다. 미래 속도·가감속·yaw 등 다른 검사 초과는 0이고 **XY 곡률만 6개 실제 시점에서 실패**합니다. 차선 센서 0은 차체 전체 차로 포함의 증거가 아닙니다. [감사 코드](../../../../../tools/e2e/audit_drive_control_aj.py)는 AM과 동일하고 `--campaign AN`은 제목 선택만 추가했습니다. 실패한 라벨을 제거하거나 한계를 올리지는 않았습니다.

다음 독립 변수 후보인 **AO 출발 조향 진단은 아직 구현·실행하지 않았습니다.** AN/AM 원본은 첫 BasicAgent 명령이 마지막 정지 준비 프레임에서 `steer≈+0.0681`로 나가고, 첫 주행 프레임부터 실제 앞바퀴 각이 약 `−0.0813 rad`이며, 속도 0인 채 약 **35개 20 Hz 시점** 동안 `−0.0824 rad` 부근을 유지함을 보여 줍니다. 첫 실제 이동 프레임은 약 0.098 m/s, 첫 100 ms 이동은 9 mm이며 출발 tick 53·54·59가 곡률을 초과합니다. 따라서 AO를 한다면 **마지막 준비→주행 첫 명령까지 포함하여**, 경로 진행 <1 m 및 측정 속도 <0.20 m/s에서만 정상 조향 출력을 0으로 유지하고 이후 원래 PID 명령으로 복귀시키는 *한 가지 변수*를 별도 사전 선언해야 합니다. 시작 시 이미 경로 중심에서 약 0.409 m 벗어나 있어 조향 지연이 오히려 CTE와 차로 위치를 악화시키거나 복귀 순간 큰 횡변화를 만들 수 있습니다. 적용 전 이 위험·긴급제동 비간섭·초기 경로 허용치·원래 전체 미래 계약을 고정해야 하며, 목표 근처 잔여 3개는 AO 범위 밖입니다. 단순히 “출발만 고치면 학습 가능”하다는 결론은 아닙니다.

Portable E2E 주행 모델은 이번에 변경되지 않았고, 주요 9개/세부 30개 기능 중 학습 모델의 폐루프 승인 수는 여전히 **0/30**입니다. 안전한 TRAIN 편입은 전체 미래 위반 0, 차체 차로 포함, 독립 경로·미사용 TEST 및 별도 편입 계약 뒤에만 검토합니다.
