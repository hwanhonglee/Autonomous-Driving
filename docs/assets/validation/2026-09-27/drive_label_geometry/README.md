# AN/AO 6.4초 미래 라벨 기하 진단 — speed+yaw 적분은 저속만 바꾸지 않는다

<!-- HH_260906 - Keep a retrospective shadow path separate from sealed BasicAgent labels, gates and training admission. -->

**결론:** 실측 속도와 차체 yaw를 100 ms마다 사다리꼴 적분한 가상 경로에서는 AN/AO의 기존 XY 곡률 초과가 모두 사라졌습니다. 그러나 **AO의 2 m/s 이상 회전 tick 295도 함께** `0.205732/m → 0.184868/m`로 내려갑니다. 따라서 “저속 위치 차분의 수치 문제만 해결하고 회전 문제는 그대로 남긴다”는 가설은 이 가상 경로의 곡률 결과와 맞지 않습니다. 원래 AO 회전 초과와 전체 **TRAIN 거절**은 그대로 유지합니다. 이 진단은 CARLA BasicAgent의 봉인된 결과를 읽기만 했으며 학습 모델, Autoware 제어, 차량 안전 검증이 아닙니다.

## 재현 범위와 계산

<!-- HH_260906 - Reproduce every frozen curvature value before comparing a hypothetical alternative path. -->

AN/AO 각각 봉인된 `states.jsonl`과 원래 `future.jsonl.gz`의 SHA256을 코드에 고정하고 실행 영수증의 완료·소스 불변·cleanup 상태를 확인했습니다. 각 회차 **576개 완전한 6.4초 창 × 64점 = 36,864점**을 모두 사용했습니다. 원래 감사의 100 ms 미래 시각에 대해 동일한 20 Hz 선형 보간, anchor 차체 좌표 변환, `0.1 mm` 이동 미만의 heading 미평가 규칙, 초기 heading 0, 곡률 계산을 적용했습니다. **원래 곡률값의 최대 재현 오차는 양쪽 모두 0**이고 모든 실패 플래그가 일치했습니다. 불완전 미래나 정지 tail을 완전 창으로 꾸미지 않았습니다.

가상 경로는 각 anchor의 원점에서 시작해, 양 끝점의 실측 평면 속도 크기 `v`와 차체 yaw `ψ`로 만든 `v[cos ψ, sin ψ]`를 **사다리꼴 적분**했습니다. 이는 **후축 속도가 차체 전방과 나란하다**는 무측면 미끄럼 가정입니다. 이 경로에 원래 곡률식과 **변경하지 않은 `>0.200001/m` 판정**을 다시 적용했습니다. 원본 라벨·유효 마스크·제어·게이트·데이터셋은 수정하지 않았습니다. 구간은 기존 원인 감사와 같은 episode 상대 100 ms tick 출발 `48–62`, 회전 `290–300`, 목표 근처 `505–558`이며 그 밖의 단계도 전수 검사했습니다.

| 곡률 초과의 서로 다른 실제 100 ms tick | AN 원본 XY | AN 가상 경로 | AO 원본 XY | AO 가상 경로 |
| --- | ---: | ---: | ---: | ---: |
| 출발 | 3 | 0 | 4 | 0 |
| 회전 | 0 | 0 | **1** | **0** |
| 목표 근처 | 3 | 0 | 5 | 0 |
| 그 밖 | 0 | 0 | 0 | 0 |
| **전체** | **6** | **0** | **10** | **0** |
| 중첩 창의 초과 단계 | 354 | 0 | 477 | 0 |

원본의 초과 단계 354/477개는 가상 경로에서 모두 **실제로 곡률 평가를 받고** 통과했습니다. 미평가로 숨겨진 원본 실패는 0개입니다. 양쪽 경로 모두 각 회차 4,674개 단계는 원래 규칙에 따라 미세 이동으로 곡률을 평가하지 않았으며 통과 판정으로 세지 않았습니다. 중첩 창의 단계 수는 독립 장면 수가 아닙니다.

## 가상 경로가 원본 위치와 얼마나 다른가

<!-- HH_260906 - State both local interval and accumulated horizon errors without turning a shadow result into replacement-label evidence. -->

| 원본 XY와 가상 XY의 거리 | AN | AO |
| --- | ---: | ---: |
| 전체 중첩 미래 점 평균 / 95백분위 | 6.87 / 18.52 cm | 8.04 / 19.04 cm |
| **6.4초 끝점** 평균 / 95백분위 / 최대 | **13.36 / 22.83 / 24.64 cm** | **15.63 / 22.87 / 24.67 cm** |
| 회전 tick 290–300의 100 ms **한 단계 이동 벡터** 평균 차이 | 3.83 mm | 4.66 mm |
| 회전 tick 290–300의 겹친 창 **누적 위치** 평균 차이 | 12.41 cm | 12.32 cm |

AO 회전 **tick 295**에서 원래 단계 이동 길이는 `211.25 mm`, 가상은 `214.66 mm`입니다. 원본 곡률 `0.205732/m`은 63개 중첩 창에서 초과하고, 가상 최대 `0.184868/m`는 모두 통과합니다. 이 tick을 포함한 64개 겹친 창의 가상 위치와 원본 위치 차이는 평균 **12.39 cm**, 최대 **19.63 cm**입니다. 즉 회전 통과는 동일한 궤적에 대한 계산 정정이라고 입증되지 않았습니다. 출발·정지뿐 아니라 회전의 감독 경로도 바꿉니다.

원본 `vx,vy`는 차체 좌표계 후축 속도 성분입니다. 회전 tick 290–300에서 `|atan2(vy,vx)|`의 중첩 점 평균은 AN **0.0574 rad (3.29°)**, AO **0.0550 rad (3.15°)**였습니다. 가상 경로는 이 관측 횡속도를 버리고 속도 크기를 차체 전방으로 놓습니다. 이는 회전의 점별 이동·장기 위치 차이에 기여할 수 있지만, 관측된 차이가 측면 미끄럼, 후축 기준점 변환, 속도/위치 샘플링 중 무엇에서 얼마나 왔는지는 이 회고 분석만으로 분리할 수 없습니다.

목표 마지막 **tick 556**에서도 AN 원본 `122.989/m` 대 가상 약 `0.000615/m`, AO 원본 `4.488/m` 대 가상 약 `0.000517/m`입니다. 수 mm 위치 차분에서 큰 곡률이 나오는 민감성은 확인되지만, 원본 XY가 단순 수치 잡음이었다는 증명은 아닙니다. 가상 경로가 목표 근처 초과만이 아니라 회전 초과까지 없앤 점과 위 위치 오차를 함께 보아야 합니다.

## 해석과 보존 경계

<!-- HH_260906 - A no-sideslip trajectory is a model assumption, not observed replacement truth or safety evidence. -->

이 비교는 **가상 라벨을 원래 라벨 대신 넣으면 원래 XY 곡률 게이트의 해당 항목을 수치상 통과할 수 있다**는 진단에 그칩니다. 가상 경로의 위치 충실도, 차로 전체 포함, 독립 경로 일반화, 모델 학습 영향은 검증하지 않았습니다. 더구나 가상 경로는 AO의 회전 실패 자체를 지우므로 “저속 수치 오류만 고친다”는 제한된 개입이 아닙니다. 원래 AN 6개·AO 10개 실패, AO 회전 비퇴행 실패, 사전 선언된 전체 6.4초 게이트와 **TRAIN 거절**을 바꾸지 않습니다. 별도 편입·안전 승인 근거로 사용하지 않습니다.

로컬에서 같은 결과를 보려면 저장소 루트에서 `python3 tools/e2e/audit_drive_label_geometry.py`를 실행합니다. 코드는 JSON을 **표준 출력에만** 내보내며 원본과 보고서에 쓰지 않습니다. `python3 -m pytest -q learning/tests/test_audit_drive_label_geometry.py`는 합성 기하 4개 검사를 실행합니다. 2026-09-27 실행에서는 4개 모두 통과했고, 실제 데이터 재현 검사 73,728점도 통과했습니다.

이번 재현 코드 SHA256은 `72723c4cf4fa795c5bd827015859f93526fc5c09dba8d02216b17a2f47376ca7`입니다. 입력 원본의 고정 SHA256과 검증 결과는 스크립트의 JSON 출력에도 포함됩니다.
