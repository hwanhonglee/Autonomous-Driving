# 지도 표지판 A/B 학습 결과: 재현율만 증가, 후보 미채택

<!-- HH_260906 - This is a pre-training research contract, not a newly trained or approved map model. -->

**실행 결과: 새 후보는 탈락입니다.** AI v2의 640×360 표지판 IoU **3.16%**보다 A/B 후보가 **3.00%**로 낮고, 표지판 정밀도·차선·신호등도 낮아졌습니다. PRO6000의 기존 개인 venv와 물리 GPU 0에서 **2,000 step 학습 및 같은 DEV 평가를 완료**했지만, 이 체크포인트를 채택하거나 배포하지 않습니다. 지도 생성이나 자체 모델 자율주행에 사용한 결과도 아닙니다.

AI v2의 TRAIN 497장에는 표지판이 프레임당 5–64픽셀인 장면 152장, 65픽셀 이상인 장면 121장, 없는 장면 224장이 있습니다. 반면 반복 확인한 DEV 118장 중 표지판이 있는 116장에서 **107장은 64픽셀 이하**, 이 가운데 **31장은 1–4픽셀**입니다. TRAIN에는 1–4픽셀 표지판 프레임이 없습니다. 이는 한 프레임 안의 *의미 라벨 픽셀 수*이며 객체 수나 실차 표지판 검출률이 아닙니다. 두 자료는 같은 Town·날씨이며 DEV를 여러 번 본 상태이므로 독립 TEST가 아닙니다.

## 후보 실험

`train_map_native_ah.py --small-sign-exposure`는 동일한 AI v2 TRAIN/DEV manifest 해시와 부모 체크포인트를 요구하고, 데이터 확장 옵션과 동시 사용을 거부합니다. 매 8장 학습 배치에서 TRAIN의 작은 표지판 3장, 큰 표지판 1장, 표지판 없는 장면 4장을 고정 비율로 뽑습니다. 동일 strata 안에서는 복원 가능한 seed로 중복 선택할 수 있습니다. 이는 작은 표지판 노출을 균등 추출의 30.6%에서 37.5%로 높이면서, **표지판 없는 배경의 비율도 45.1%에서 50%로 높여 오검출을 함께 겨냥**합니다. 큰 표지판 프레임 비율은 24.3%에서 12.5%로 낮춥니다.

모델 구조, RGB 입력, 2,000 step, batch 8, seed, optimizer, 기존 TRAIN crop, 클래스 가중치 계산, 평가 코드는 그대로 둡니다. 따라서 변경 요인은 프레임 샘플러 한 가지입니다. 단, 샘플된 배치의 실제 클래스 비율은 바뀌며 이는 바로 이 A/B의 효과입니다. 현재 TRAIN 히스토그램 기준 crop 전 기대 표지판 픽셀은 균등 선택 약 136.4개/장, 후보 약 77.0개/장입니다. crop이 표지판을 제거할 수도 있으므로 실제 optimizer 입력 수와는 다를 수 있습니다.

기존 AI v2와 **같은 미증강 DEV**로 표지판 IoU·정밀도·재현율, 7개 클래스 IoU, 320×180 축소 결과와 RGB/정답/예측 화면을 비교했습니다. 표지판 정밀도와 IoU가 동시에 개선되지 않고 차선도 후퇴했으므로 **후보를 탈락**시켰습니다. 반복 DEV를 보고 설계한 실험이라 여기서 좋아졌어도 미사용 Town/날씨 **독립 TEST와 시간·위치 중복 검사 전에는 배포할 수 없습니다.** 특히 TRAIN에 없는 1–4픽셀 표지판 문제를 이 샘플러만으로 해결했다고 주장할 수 없습니다.

실행 검증: 실제 TRAIN 배열 strata **152 / 121 / 224**, 고정 seed 첫 배치 재현성, 지도·증강·데이터 계약 검사 **48개 통과**. 원격의 승인된 물리 GPU 0은 실행 직전 유휴 상태였고 GPU 1·시스템 패키지·다른 작업은 변경하지 않았습니다. 학습 시간은 **76.74초**, 정상 종료 코드 0입니다. 원격에서 회수한 manifest·체크포인트·예측·소스 파일의 SHA256을 로컬과 대조했고, DEV 예측에서 재계산한 혼동행렬이 학습 요약과 일치합니다. 주행 제어는 변경하지 않았습니다.

나타내지 못한다는 측정 한계가 드러났습니다. 조각은 실제 객체 인스턴스로 검증되지 않았으며
기존 DEV 자료를 TRAIN으로 옮기거나 조건을 사후 변경하지 않았습니다.
**이번 실패 후보에 기능 head를 붙이거나 반복 DEV 점수만으로 채택하지 않습니다.**

이 A/B 후보는 평균 **17.92%**, 차선 **0.122%**, 표지판 **0.008%**였습니다(0.25 m 간격

도로·차선 표현이 다른 Town의 자료와 미사용 평가 경로를 확보하는 일이 우선입니다.
이 Town06 경로는 크기 문제를 보고 선택한 **탐색 자료**이지 봉인된 독립 TEST가 아닙니다.
