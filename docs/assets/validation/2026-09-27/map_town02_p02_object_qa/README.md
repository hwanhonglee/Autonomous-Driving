# Town02 p02 중·대형 표지판 객체 QA — 객체 관문 통과, TRAIN 미편입

<!-- HH_260906 - Separate the completed fixed object gate from failed tiny-sign and independent DEV gates. -->

**고정 객체 관문 판정: `PASS_NOT_ADMITTED`.** 사전 등록한 241개 성분·113개 원본 프레임을 모두 RGB/시맨틱으로 시각 검토했다. 전체 보존 태그 8 **58,074픽셀 중 55,171픽셀(95.0012%)**을 검토했고, 검토 픽셀 중 불명확한 것은 **366픽셀(0.6634%)**이다. RGB에 대응하는 서로 다른 물리 표지판 **4개**, 단일 확인 성분이 5px 이상인 보존 프레임 **111장**을 확인했다. 이 판정은 *중·대형 표지판 객체 QA*에만 해당하며, 데이터 편입·학습·모델 승인이 아니다.

| 사전 고정 기준 | 확인 결과 | 판정 |
| --- | ---: | --- |
| 보존 태그 8 픽셀 시각 검토 ≥95% | 55,171/58,074 = **95.0012%** | 통과 |
| 검토분 안 비표지판+불명 ≤5% | 366/55,171 = **0.6634%** (비표지판 0, 불명 366) | 통과 |
| 서로 다른 RGB 확인 물리 표지판 ≥3개 | **4개** | 통과 |
| 확인된 단일 성분 ≥5px 보존 프레임 ≥24장 | **111장** | 통과 |

검토되지 않은 **2,903픽셀**은 정상으로 간주하지 않았다. 기존 작은 표지판 1–4px 조건은 **0/232장으로 계속 실패**한다. 별도 [Town05 우회전 DEV 정찰](../map_town05_sign_dev_scout/README.md)도 보존 195장 중 5px 이상 표지판 가능 프레임 **0장**으로 독립 DEV 관문에 실패했다. 따라서 이 결과로 TRAIN 편입이나 표지판 D0/D1 학습 비교를 시작하지 않는다.

## 실제 시각 증거와 판정 경계

- [기계 성분 목록](component_inventory.json)은 보존 232장의 태그 8 전체 **58,074픽셀·8연결 성분 731개**와 고정 95% 큐 **241개 성분·113개 프레임**을 원본 해시에 연결한다. 크기순 큐와 분모는 검토 중 변경하지 않았다.
- [기존 31장 성분 시트](contact_sheets/contact_sheet_01.png)는 원본 시트 해상도로 검토했다. 이 시트의 **전체 화각 맥락 이미지는 320×180 축소본**이며, 옆의 개별 성분은 원본 픽셀에서 4배 최근접 확대했다. 원래 시트 제목의 “native full FOV” 표현은 부정확하다. 이를 보완한 [별도 38장 전체 화각 패널](native_fov_evidence/manifest.json)은 선택된 **113개 원본 프레임 전부**의 640×360 RGB·CARLA 시맨틱·분홍색 태그 8 오버레이를 **픽셀 크기 그대로** 표시한다. 매 프레임 원본 RGB PNG와 시맨틱 NPZ SHA256를 기록했고, 이미지 생성이나 모델 예측을 사용하지 않았다.
- [원래 수동 결정](manual_review_decisions.json)은 초기 시트 01–03·19의 32개 성분과 **불명 8개·366픽셀**을 그대로 보존한다. [추가 결정](manual_review_addendum.json)은 시트 04–18·20–31의 **209개 성분**과 모든 선택 원본 프레임의 시각 검토를 별도 기록한다. 이번 209개는 RGB 표지판과 대응했으나, 원래 불명 8개는 승격하지 않았다. [최종 점수](manual_review_score.json)는 두 결정 파일의 해시·중복 없음·각 시트 전체 판정·원본 프레임 목록을 검사한다.
- 같은 표지판의 연속 프레임과 기둥으로 나뉜 시맨틱 성분을 **새 물체로 중복 계수하지 않았다**. `S_EARLY_LEFT_BACK`≈(187.27, 283.82)m, `S_RIGHT_30`≈(196.07, 260.21)m, `S_LATER_LEFT_BACK`≈(187.45, 254.00)m, `S_LATE_RIGHT_RED_WHITE`≈(196.26, 169.31)m의 4개 군을 RGB와 [원본 깊이 기반 세계 좌표](world_geometry.json)로 교차 검토했다. 0017·0089·0090의 이미지 경계 조각과 좌측 뒷면의 분리 성분은 전후 프레임의 같은 실제 표지판에 대응한다. 뒷면을 표지판으로 확인한 것이 제한속도 문구를 읽었다는 뜻은 아니다.
- [초·중·말 전체 화각 도로/차선 예시](road_lane_native_fov.png) `0000/0120/0239`에서는 큰 도로면·노란 중심선 위치 어긋남이 보이지 않았다. **이 세 장은 전체 232장의 도로/차선 품질 보증이나 별도 편입 판정이 아니다.** 시맨틱은 CARLA 정답 센서이며 예측이 아니다. 2D 근접 추적 ID에 교환·혼합이 있으므로 그 ID만으로 객체 수를 판정하지 않았다.

## 읽기 전용 재현

저장소 루트에서 다음 명령은 저장된 JSON/PNG와 변경하지 않은 원본을 재계산·대조한다. CARLA·GPU·SSH·TEST·추론·학습을 사용하지 않는다.

```bash
python3 tools/e2e/audit_map_town02_p02_objects.py
python3 tools/e2e/audit_map_town02_p02_world_geometry.py
python3 tools/e2e/render_map_town02_p02_native_qa.py
python3 tools/e2e/score_map_town02_p02_manual_review.py
python3 tools/workspace_python.py -m pytest -- -q learning/tests/test_audit_map_town02_p02_objects.py
```

이 객체 관문은 원래 [사전 등록](PLAN.md)의 95%/5%/3개/24장 기준만 평가한다. 별도 작은 표지판·독립 양성 DEV·도로/차선 입학 심사와 잠긴 D0/D1 계획은 통과하지 않았다. Town04·Town07·Town15 held-out 및 Town06·Town10HD_Opt 예약 TEST는 열지 않았다.
