# Town02_Opt p02 표지판 원본 감사 — 소형 표지판 목표만 미달

<!-- HH_260906 - Separate the failed preregistered tiny-sign gate from possible future value at larger sign scales. -->

**결론: 사전 등록한 *소형 표지판* TRAIN 후보는 거부한다.** [실행 전 계획](PLAN.md)의 조건은 0.25m 위치 중복을 제거한 프레임에서 전체 640×360 화면의 CARLA `traffic_sign`(태그 8)이 **1–4픽셀인 장면 최소 24장**이었다. 재계산 결과는 **0/232장**이다. 수집 무결성은 통과했다. 중·대형 표지판 라벨은 실제로 있으므로 이 원본 *전체가 쓸모없다*는 판정은 아니다. 그러나 별도 목적·객체 정합성·독립 DEV를 정하지 않은 지금은 **어떤 TRAIN 데이터셋에도 편입하지 않았고 학습도 하지 않았다.**

| 프레임 전체 태그 8 픽셀 수 | 원본 240장 | 0.25m 보존 232장 |
| --- | ---: | ---: |
| 0 | 0 | 0 |
| **1–4: 사전 기준** | **0** | **0** |
| 5–64 | 149 | 149 |
| ≥65 | 91 | 83 |
| 태그 8 전체 픽셀 합계 | 62,106 | 58,074 |

보존 규칙은 각 차량 XY를 앞서 **보존한 모든** 위치와 비교하여 0.25m 이상 떨어진 경우에만 남긴다. 232장은 원본 무결성 최저치 120장을 넘었다. 위 구간은 **한 프레임의 태그 8 픽셀 합계**이지 1–4픽셀짜리 연결 성분·물체의 개수나 모델 검출률이 아니다. 이 기준을 뒤늦게 물체별 픽셀 기준으로 바꿔 합격시키지 않는다.

[전체 화각 원본 RGB·CARLA 시맨틱·태그 8 겹침](town02_p02_rgb_oracle_full_fov.png) · [프레임별 해시와 판정 JSON](summary.json)

그림의 세 행은 **원본 640×360 전체 화각**을 유지한다. 보존 프레임 `0109`는 전체 태그 8이 6픽셀이지만 원본 RGB에서 독립된 먼 표지판을 확언하기 어렵다. `0083`에서는 오른쪽의 큰 **30 km/h 원형 속도제한 표지판**과 큰 태그 8 영역이 같은 위치에 있고, 왼쪽 원형 표지의 라벨도 시각적으로 대응한다. `0239`에는 54픽셀 태그 8이 있으나 먼 작은 물체의 가독성까지 보장하지 않는다. 이 육안 확인은 **일부 큰 표지판**의 RGB/라벨 정합 근거일 뿐 전 프레임·모든 물체에 대한 검증이나 소형 표지판 유용성 증명은 아니다. 분홍색은 CARLA oracle 의미 라벨이고 학습 모델의 예측이 아니다.
