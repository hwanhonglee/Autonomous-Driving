# Town02_Opt 표지판 TRAIN 원본 정찰 감사

**결론: 표지판 보강용 TRAIN 후보 거부.** [실행 전 계획](PLAN.md)은 0.25m 보존 프레임 중 전체 640×360 화면의 CARLA `traffic_sign`(태그 8)이 1–4픽셀인 장면을 **24장 이상** 요구했다. 독립 재계산 결과는 **3/232장**이다. 수집 무결성 조건은 통과했지만, 작은 표지판 조건은 통과하지 못했다. 학습 자료 편입·모델 학습·예측 평가는 하지 않았다.

| 전체 프레임의 태그 8 픽셀 수 | 원본 240장 | 0.25m 보존 232장 |
| --- | ---: | ---: |
| 0 | 0 | 0 |
| 1–4 | 4 | **3** |
| 5–64 | 164 | 157 |
| ≥65 | 72 | 72 |
| 태그 8 픽셀 합계 | 16,596 | 16,544 |

보존 규칙은 각 Town02_Opt 프레임의 차량 XY를 이전에 **보존한 모든** XY와 비교해 0.25m 이상 떨어진 경우만 남긴다. 232장은 사전 최저치 120장을 넘는다. 1–4픽셀 보존 프레임은 `0006`, `0016`, `0018`이다. `0005`는 원본에서는 3픽셀이지만 위치 중복으로 빠진다. 픽셀 구간은 **프레임 전체 합계**이며, 연결된 작은 픽셀 조각 수나 표지판 물체 수가 아니다.

## 출처·품질과 화면 확인

`storage/experiments/training/2026-09-27/map_town02_sign_train_scout_epic_v1`의 소유 실행은 종료 코드 0, 보관 소스 13개 SHA256 일치, 고정 직진 p00 경로 SHA256 `520fc0236e32d0664bc125a15f45601e4ef020cf1e3f1db888332af0e188f08b` 일치다. 계획·시작·수집 요약과 CARLA 준비/캡처 후/종료 영수증의 월드는 모두 `Town02_Opt`이다. 화질은 Epic, 물리 제어는 CARLA BasicAgent, 신호등 무시 옵션은 명시되어 있다. 충돌 0, 저장 원본 재생과 라이브 지도 일치, 정리 오류 0, 종료 후 포트 해제를 확인했다. 신호 무시는 교통규칙 준수 근거가 아니다.

전방 RGB·시맨틱 240쌍을 모두 640×360으로 디코드하고, 기록 순서·10Hz 간격·깊이 및 카메라 행렬 형식도 검사했다. 그림의 `0190`에서는 왼쪽 길가의 큰 원형 표지판 윤곽과 자홍색 태그 8이 같은 위치에 있다. `0006`의 4픽셀 등 먼 표지는 원본 RGB에서 독립된 표지판 물체로 확언하기 어렵다. 따라서 정답의 픽셀 존재를 작은 표지판의 유용성이나 검출 성능으로 해석하지 않는다.

240프레임 동안 이동 거리는 94.30m이고 BasicAgent는 약 177.13m 경로의 목적지에 도달하지 않았다. 이 감사는 실제로 포착된 구간의 원본 정찰만 다룬다. CARLA 시맨틱은 정답이며 모델 예측이 아니다. `dataset_admitted=false`, `model_trained=false`, `hd_map_approved=false`를 유지한다.

같은 원본에서 다시 확인하려면 저장소 루트에서 `python3 tools/e2e/audit_map_town02_train_scout.py`를 실행한다. 스크립트는 원본을 읽기만 하고 공개된 JSON 바이트·PNG 픽셀을 다시 계산해 비교한다. `python3 -m pytest -q learning/tests/test_audit_map_town02_train_scout.py`는 픽셀 구간 경계, 0.25m 보존 규칙, 소유 영수증 실패 감지와 실제 거부 판정을 검사한다.
