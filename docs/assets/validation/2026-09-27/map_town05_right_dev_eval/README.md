# Town05_Opt 우회전 p00 지도 DEV: 도로·차선 진단만 완료

**결론:** 동결 지도 AI v2 A와 기존 미채택 후보 C를 동일한 Town05_Opt 우회전 p00 Epic 원본에 CPU로 적용했다. 0.25m 간격으로 보존한 **195장**에서 C의 도로 IoU는 A보다 **+33.833 pp**, 차선 표시 IoU는 **+69.157 pp** 높았다. 이는 한 ClearNoon 경로에서의 개발 진단이며 **C는 계속 미채택**이다. 기존 Town01 DEV 보호 관문 실패를 이 결과로 지우지 않는다.

[실행 전 고정 계획](PLAN.md)은 첫 추론 전에 원본 감사·경로·체크포인트·소스 해시, 주 분모, 지표, 전체 화각 프레임, 비승격 조건을 고정했다. [우회전 원본 감사](../map_town05_sign_dev_scout/README.md)는 Epic 640×360 RGB/semantic **240쌍 전수**, 보존 **195장**, 관측 주행 **78.61m**, 충돌 0, live/replay 일치, archive 13/13, owner 종료 0과 정리 완료를 확인했다. 이동과 목표 도착은 **CARLA BasicAgent**의 결과이지 학습 모델의 주행 성능이 아니다. 원본 감사 JSON SHA-256은 `201d9e3dc6a7ecff46da485682afcc73682cdb3d045b7579920d6b94670d5050`이며, 새 평가기는 실행 직전 전체 감사를 재계산해 정확히 일치함을 확인했다.

## 사전 지정 주 분모: 보존 195장

| 지표 | A: 동결 AI v2 | C: 미채택 후보 | C−A |
|---|---:|---:|---:|
| 도로 IoU | 61.017% | 94.850% | **+33.833 pp** |
| 도로 precision / recall | 82.545% / 70.056% | 97.183% / 97.531% | — |
| 도로 TP / FP / FN (픽셀) | 15,981,711 / 3,379,572 / 6,831,044 | 22,249,481 / 644,903 / 563,274 | — |
| 차선 표시 IoU | 6.158% | 75.315% | **+69.157 pp** |
| 차선 precision / recall | 21.420% / 7.955% | 81.480% / 90.870% | — |
| 차선 TP / FP / FN (픽셀) | 83,832 / 307,545 / 970,038 | 957,652 / 217,665 / 96,218 | — |
| 신호등 기구 IoU (참고) | 1.512% | 0.427% | −1.084 pp |
| 7클래스 평균 IoU (참고) | 24.257% | 44.846% | +20.590 pp |
| 전체 픽셀 정확도 (참고) | 70.194% | 89.753% | +19.559 pp |

행이 정답, 열이 예측인 7×7 혼동행렬에서 실제 도로를 보도로 예측한 픽셀은 A **4,567,901**, C **289,307**개였다. 실제 차선을 `other`로 예측한 픽셀은 A **530,968**, C **26,796**개였다. 원본 **240장 전체**에서도 도로/차선 IoU는 A **60.092%/7.139%**, C **94.095%/74.962%**로 같은 방향이다. 두 분모의 전체 클래스별 지표·정수 혼동행렬과 정확한 C−A 값은 [요약 JSON](summary.json)에 있다. 연속 프레임을 독립적인 195회 실험으로 보거나 통계적 유의성을 주장하지 않는다.

우회전 원본의 `traffic_sign` 정답은 보존 195장에 **57픽셀**, 보존 한 프레임 전체에서 최대 **3픽셀**이었다. [사전 sign-capable 기준](../map_town05_sign_dev_scout/PLAN.md)에 실패했으므로 **표지판 IoU·precision·recall·오검출은 모델 관문이나 순위에 사용하지 않았다**. 요약 JSON의 표지판 행은 7클래스 혼동행렬을 완전하게 보존하기 위한 부수 진단일 뿐, 표지판 개체 탐지율도 아니다. Town05 진단상 도로 ≥A−1 pp·차선 ≥A−2 pp 표식은 참이지만 `automatic_promotion=false`, `deployment_approved=false`, `sign_used_for_gate=false`다. C는 기존 Town01 DEV 차선·표지판 보호 실패로 미채택 상태를 유지한다. 이 결과는 정밀지도, learned-control 폐루프 주행, 실차, 봉인 TEST를 승인하지 않는다.

## 재현과 검증

[전용 평가기](../../../../../tools/e2e/evaluate_map_town05_right_dev.py)는 이전 [Town05 직진 평가기](../../../../../tools/e2e/evaluate_map_town05_dev.py)의 고정 7클래스/CPU 적재·혼동행렬 함수를 재사용하되 우회전 원본과 계획 SHA-256 `29608b3276a022a7dbdb762af44176d47ec113b4da058222066c3efc9b63d9c2`를 별도로 고정했다. 원본 RGB만 `float32/255`로 입력했고 CARLA semantic는 평가 정답에만 썼다. `CUDA_VISIBLE_DEVICES=''`, Torch CPU **2 thread**, GPU·CARLA·SSH·설치·새 학습 없이 240장×2모델을 평가했다. 추론·지표 계산에 **54.93초**가 걸렸다. 실행은 `python3 tools/workspace_python.py -m scripts.e2e.evaluate_map_town05_right_dev`에 위 환경 변수를 준 것이며, 재실행 시 기존 산출물 덮어쓰기를 거부한다.

[새 단위검사](../../../../../tools/e2e/test_evaluate_map_town05_right_dev.py) **5개 통과**: 계획 변조 실패 종료, 출력 덮어쓰기 금지, 도로·차선 포함 경계와 표지판 비관문, 사전 프레임, 전체 화각 픽셀 검사. 별도의 `--verify-only` 경로에서 [저장된 240장 양 모델 예측](predictions.npz)과 원본 oracle로 **240장/195장 모든 7×7 혼동행렬을 독립 재계산하여 정확히 일치**시켰고, 세 PNG의 네 native 패널 픽셀도 원본 RGB·oracle·저장 예측과 정확히 일치시켰다. 중간 화면은 육안으로도 확인했다. 산출물 해시는 [요약 JSON](summary.json)에 기록되어 있다.
