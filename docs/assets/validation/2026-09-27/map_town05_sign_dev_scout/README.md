# Town05_Opt 우회전 표지판 DEV 정찰 — 원본 합격, 표지판 자격 실패

<!-- HH_260906 - Keep physical source integrity separate from the failed preregistered sign DEV gate. -->

**결론: CARLA 원본 수집은 무결하나, 표지판 DEV 후보로는 거절한다.** [실행 전 계획](PLAN.md)의 Town05_Opt 우회전 p00·Epic·BasicAgent·240프레임 조건대로 한 차례 수집했다. 차량이 움직인 **78.61m** 구간에서 목표 지점에 도달했지만, 이것은 학습 모델의 주행 결과가 아니다. CARLA **BasicAgent**가 물리 차량을 움직였고 신호등 무시는 지도 정찰에 한정된다.

사전 기준은 **RGB에서 확인한 서로 다른 표지판 객체 ≥3개**와 **해당 확인 객체가 ≥5픽셀인 보존 프레임 ≥24장**이었다. 보존 원본의 *프레임 전체* 태그 8도 최대 3픽셀이므로, 어떤 개별 표지판 객체도 ≥5픽셀이 될 수 없다. 따라서 ≥5픽셀 객체가 가능한 보존 프레임은 **0/195장**, 자격을 만족할 수 있는 독립 객체의 상한도 **0개**다. 전체 240장 중 작은 표지판처럼 보이는 RGB 물체가 정확히 몇 개인지는 전수 개체 추적하지 않았고, **0개라는 주장을 하지 않는다**. 사전 기준 실패는 그 수에 관계없이 확정된다.

[원본 전체 화각 RGB·CARLA oracle·표지판 픽셀 오버레이](town05_right_rgb_oracle_full_fov.png)는 보존 첫 장 `0000`, 태그 8 최대 장 `0184`, 마지막 보존 장 `0203`을 원래 **640×360 화각** 그대로 보여준다. 마젠타는 CARLA 태그 8 픽셀이지 모델 예측이나 RGB로 확인된 표지판 객체가 아니다. [기계 판독 감사 JSON](summary.json)은 소유 문서·lifecycle·서버 로그·원본 240쌍의 SHA256, 깊이/시맨틱 해독과 보존 프레임 목록을 기록한다. [재현 감사 코드](../../../../../tools/e2e/audit_map_town05_sign_dev_scout.py)는 원본을 수정하지 않고 JSON·PNG를 재계산·대조한다.

동일 사이트의 [Town05 직진 DEV](../map_town05_dev_capture/README.md)와 이번 우회전은 독립된 두 사이트가 아니다. 직진은 도로·차선 DEV 진단용 원본이지만 표지판 크기 기준을 충족하지 않았고, 이번 우회전도 그 결함을 해결하지 못했다. **표지판 비퇴행 평가/모델 승격은 보류**한다. 다른 경로를 결과에 맞춰 즉석 선택하거나 이번 기준을 낮추지 않는다. 지도 TRAIN 편입·새 학습·모델 추론·Autoware 폐루프 주행·실차 및 정밀지도 승인은 실행하지 않았다.
