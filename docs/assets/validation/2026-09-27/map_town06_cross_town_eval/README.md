# Town06 지도 인식 교차-Town 평가 — 두 모델 모두 심각한 성능 저하

<!-- HH_260906 - A selected saved-scout evaluation is not a blind TEST, training admission or HD-map approval. -->

**결론:** Town01에서 학습한 지도 인식 AI v2와 이미 탈락한 표지판 샘플링 A/B를 Town06의 저장된 원본 RGB에 그대로 적용했습니다. 두 모델 모두 **도로·차선·표지판 인식이 크게 떨어졌습니다.** A/B는 표지판 IoU가 거의 0에서 아주 작게 증가했지만 차선과 전체 점수는 더 나빠졌습니다. 새 모델 학습, CARLA 재실행, 원격 접속, GPU 사용, 가중치 변경, 채택·배포는 없었습니다.

쉽게 말하면, **AI v2는 실제 표지판의 거의 전부를 놓쳤고**, 반대로 **표지판이라고 잘못 칠한 픽셀 대부분은 실제 차선 표시**였습니다. 작은 표지판을 더 자주 보여준 A/B만으로는 이 혼동을 고치지 못했습니다.

주요 수치는 출발 위치 중복을 줄이기 위해 [소유 수집 검증](../map_sign_town06_p06/README.md)과 같은 규칙(첫 프레임 이후 마지막 보존 차량 위치에서 0.25 m 이상)의 **232장**에서 계산했습니다. 원본 **240장** 전체의 혼동행렬도 [원본 요약](summary.json)에 별도로 보존했습니다.

| Town06 232장, 원본 640×360 | AI v2 | 탈락 A/B |
|---|---:|---:|
| 7개 클래스 평균 IoU | 20.68% | 17.92% |
| 전체 픽셀 정확도 | 71.25% | 59.83% |
| 도로 IoU | 57.24% | 39.86% |
| 차선 표시 IoU | 0.747% | 0.122% |
| 보도 IoU | 0.067% | 0.034% |
| 신호등 구조물 IoU | 0.00049% | 0% |
| 표지판 IoU | 0% | 0.008% |

표지판 정답은 보존 프레임 전체 **11,630픽셀**입니다. AI v2는 그중 **11,530픽셀(99.14%)을 `other`로** 예측했습니다. 반대로 AI v2가 표지판이라 예측한 **105,686픽셀 중 90,294픽셀(85.44%)은 실제 차선 표시**였습니다. AI v2의 올바른 표지판 픽셀은 0개입니다. 탈락 A/B는 25,410픽셀을 표지판으로 예측해 일부 맞혔으나, 그중 23,432픽셀(92.22%)은 실제 차선이며 IoU는 여전히 0.008% 수준입니다. 이 수치는 의미 분할의 픽셀 점수이며 표지판 개체 검출률이 아닙니다. 이 한 경로의 오류는 단순한 작은 물체 누락만으로 설명되지 않는 **교차-Town 클래스 혼동**을 보여줍니다. Town01에서 이미 확인한 A/B의 **표지판 정밀도·IoU·차선 퇴행**은 여기서 뒤집히지 않습니다.

그림의 네 패널은 모두 원본 **640×360 전체 화각**입니다: RGB 입력, CARLA oracle 의미 라벨, AI v2 예측, A/B 예측. 색으로 표시된 참값은 수집기의 CARLA 의미 센서에서 왔고 모델 입력에는 **RGB만** 사용했습니다. 화면에서 도로를 보도/기타로 넓게 잘못 칠하고 차선을 놓치는 차이가 보입니다.

실행 전에 소유 수집의 정상 종료·충돌 0·live/replay 일치·정리 상태, 원본 route SHA256 `e27e95cb...`, 소유 기록과 보관된 수집 소스 13개의 해시, 7개 클래스의 CARLA tag 표를 검사했습니다. AI v2 체크포인트 SHA256은 `ae489cd...`, 탈락 A/B는 `30c3c56...`로 고정했습니다. 로컬 Torch 1.8에는 `weights_only` 인자가 없어 **해시 확인을 마친 소유 체크포인트만 CPU로 읽었고**, 모델 구조와 130,503개 파라미터를 엄격하게 대조했습니다. 240장 두 모델 추론은 CPU 2 thread로 약 **60초**였습니다. 평가 규칙 단위 검사 등 관련 검사 **24개 통과**했습니다.

전처리 확인으로 AI v2를 원래 Town01 **DEV 118장**에서도 RGB `float32 / 255`, batch 8로 CPU 재실행했습니다. 보관된 GPU 예측 파일은 원래 요약 혼동행렬과 **정확히 일치**했으나, 로컬 Torch 1.8 CPU 재실행은 GPU 예측과 **27,187,200픽셀 중 2,055픽셀(0.00756%)**이 달랐고 혼동행렬 항목별 차이 절댓값의 합은 1,930입니다. 즉 **비트 단위 동일 재현은 아닙니다.** CPU 표지판 IoU는 3.1564%, 기존 보관값은 3.1569%로 근접합니다. 이 작은 백엔드 차이는 Town06에서 관찰한 수십 퍼센트포인트의 도로/전체 성능 저하를 설명하기 어렵지만, 그 원인을 독립적으로 증명하지도 않습니다.

이 경로는 표지판 크기 문제가 있어 **의도적으로 선택한 교차-Town 탐색 평가**입니다. 미리 봉인한 무작위 독립 TEST가 아니며 한 Town·한 경로·한 날씨의 상관된 프레임입니다. 수집 차량은 CARLA BasicAgent가 운전했고 신호등 무시 옵션을 사용했습니다. 결과는 자동 정밀지도·교통규칙·자체 모델 폐루프 주행 성능을 인증하지 않습니다. 다음 단계는 이 실패를 보존하고 Town·날씨·표지판 크기가 분리된 TRAIN/독립 TEST 자료를 사전 정의한 뒤 모델 일반화를 다시 개선·검증하는 것입니다. **Town06 장면을 검토한 뒤 곧바로 독립 TEST로 재명명하거나 모델 채택에 사용하지 않습니다.**
