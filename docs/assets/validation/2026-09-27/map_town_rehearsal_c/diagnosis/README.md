# 지도 후보 C 실패 진단: 차선과 표지판

<!-- HH_260906 - Diagnose frozen Town01 DEV predictions without opening the sealed Town07 holdout. -->

**결론:** C의 차선과 표지판 IoU 하락은 정답을 대량으로 새로 놓쳐서가 아니라 **잘못 칠한 픽셀(FP)이 늘어난 현상**과 더 잘 맞습니다. 지도 모델을 채택할 근거는 아직 없습니다. 이 진단은 이미 여러 번 본 Town01 DEV 118장만 다시 계산한 것이며 새로운 Town 일반화 성능이나 독립 TEST 결과가 아닙니다.

| 클래스 | A 정답 검출 TP | C 정답 검출 TP | A 오검출 FP | C 오검출 FP | A→C IoU |
|---|---:|---:|---:|---:|---:|
| 차선 표시 | 45,308 | 45,211 | 3,745 | **5,051** | 91.233% → **88.705%** |
| 표지판 | 1,262 | 1,232 | 37,061 | **51,386** | 3.157% → **2.269%** |

차선의 FP 증가분 **1,306픽셀** 중 후반부 프레임 80–117에서만 **2,106픽셀 증가**했습니다. 초기 구간에서는 FP가 감소해 전체 증가분을 일부 상쇄합니다. 특히 프레임 112–117의 차선 FP는 **75→704픽셀**입니다. 프레임 117의 [전체 화각 비교](../town01_dev_117_abc_full_fov.png)에서 C가 차선 부근에 추가한 노란 픽셀이 확인됩니다. 118장 중 프레임별 차선 IoU는 C가 A보다 65장 낮고 52장 높습니다.

표지판 FP 증가분은 **14,325픽셀**이며, 그중 정답 `other`를 표지판으로 칠한 증가분이 **14,203픽셀**입니다. 프레임 80–117에는 정답 표지판이 합계 142픽셀 있지만 A와 C가 모두 한 픽셀도 잡지 못했고, FP는 **33,341→42,453픽셀**입니다. GT 표지판 크기가 프레임당 1–9픽셀인 37장에서는 두 모델 모두 TP가 0입니다. 표지판 정밀도는 A 3.293%, C 2.341%로 모두 낮습니다. [프레임 059 전체 화각](../town01_dev_059_abc_full_fov.png)은 두 후보가 같은 RGB에서 어떻게 다른 영역을 표지판으로 표시하는지 보여줍니다. 실제 오인 물체의 종류는 이 숫자만으로 단정하지 않습니다.

## 학습 데이터와 연결되는 가설

고정 TRAIN 913장은 Town01 497장과 Town03 416장입니다. Town03의 차선 정답은 **2,546,611픽셀**, Town01은 **287,660픽셀**입니다. 반대로 표지판은 Town03 **140픽셀**, Town01 **67,794픽셀**입니다. C의 배치 8장은 Town01 7장, Town03 1장이지만, 원본 라벨의 프레임 평균으로 계산한 증강 전 기대 차선 양성 픽셀 중 Town03 비중은 **60.17%**입니다. 표지판 비중은 **0.035%**뿐입니다. 실제 최적화에는 무작위 crop·resize가 있으므로 이 수치를 실제 gradient 비중으로 해석하면 안 됩니다.

A와 C의 데이터별 계산 class weight도 차선 **1.4623→0.8016**, 표지판 **2.1720→2.6512**로 다릅니다. B와 C끼리는 loss 계약이 같고, C에서 달라진 요인은 TRAIN 프레임 추출 비율입니다. 따라서 **희소한 표지판 학습과 차선 노출 분포가 오검출에 영향을 줬을 가능성**은 있지만, 이 자료만으로 원인이라고 확정할 수 없습니다. 추가 실험 전에는 실제 표지판이 충분히 보이는 적격 TRAIN, 서로 다른 장면의 별도 DEV, 픽셀 라벨 품질을 먼저 확보하는 것이 타당합니다. 같은 Town01 DEV만 보고 가중치나 비율을 반복 고르면 과적합 위험이 큽니다.

## 재현 범위

[숫자 원본](metrics.json)은 고정 [DEV 라벨](../../../../../../storage/experiments/training/2026-09-27/map_generalization_town03_train_package_v1/dev.npz), [A 예측](../../../2026-09-26/dual_data_ai/results/mapping_ai_v2/dev_predictions.npz), [B 예측](../../map_generalization_train_results/remote_run/dev_predictions.npz), [C 예측](../remote_run_v2/dev_predictions.npz)을 같은 640×360 픽셀에서 비교한 결과입니다. 클래스 3=차선, 5=표지판; TP=정답과 예측 모두 해당 클래스, FP=정답은 다른 클래스이나 예측만 해당 클래스, FN=정답만 해당 클래스입니다. `IoU=TP/(TP+FP+FN)`. 입력 NPZ SHA-256과 세 모델의 저장된 혼동행렬 일치를 확인했습니다. `metrics.json`의 구간은 끝 프레임을 포함하고, 공간 좌표는 원본 이미지 기준입니다. Town07 데이터는 읽거나 평가하지 않았습니다.
