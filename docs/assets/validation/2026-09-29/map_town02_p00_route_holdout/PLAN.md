## 고정한 질문과 분할

- A: 기존 Town01 TRAIN 497장. B: **같은 순서의 Town01 497장 + Town02_Opt p00 보존 232장**. p00과 기존 D1 p02는 원본 경로·파일이 다르고 차량 중심 최소 거리가 197.040m이지만, 동일 Town의 조명·재질을 공유한다. 변경 요인은 232장 TRAIN 추가 하나다.
- 평가 1: 기존 Town02_Opt p02 **전체 232장 경로 보류**. 두 팔 모두 p02로 학습하지 않는다. p02는 과거 D1 학습과 분석에 이미 사용됐으므로 새 독립 DEV나 봉인 TEST가 아니라 내부 탐색 지표다.
- 평가 2: 고정 Town01 DEV 118장의 7클래스 혼동행렬·IoU. 이미 알려진 보호 지표이며 새 독립 장소가 아니다. Town05_Opt의 반복 DEV 결과로 seed·데이터·가중치·임계값을 고르지 않는다. 이번 한 쌍에서 Town05를 새 선택 지표로 사용하지 않는다.
- site 분할 원장의 승인된 독립 지도 DEV는 **0곳**이다. 이번 결과가 좋아도 기존 AI v2 자동 교체, HD-map 완성, Autoware 폐루프/실차 승인, 10 Hz 운용을 뜻하지 않는다.

## 동일 조건 및 1회 판정

두 팔은 기존 `MapPerception` 7클래스·640×360·scratch 초기화·seed `20260922`·AdamW 학습률 `3e-4`, weight decay `1e-4`·batch 8·각 2,000 step·TRAIN-only 동일 paired crop을 사용한다. `sqrt_frequency` 클래스 가중치는 **A의 Town01 TRAIN 497장만**으로 계산해 두 팔에 동일하게 적용한다. 모델·손실·증강·평가 입력과 소스 해시가 달라지면 실행을 중단한다. 원본 semantic ID 1과 24를 수작업 재라벨링하지 않는다.

사전 탐색 관문: p02 차선 IoU가 B−A **≥+2.0%p**, p02 도로 IoU가 **≥−1.0%p**, Town01 DEV의 도로·차선 IoU가 각각 **≥−0.5%p**여야 한다. 동시에 Town01 DEV의 다른 5개 클래스 중 하나라도 **−0.5%p 미만**이면 7클래스 보호 실패를 별도 명시한다. 전체 7×7 혼동행렬, 클래스 픽셀 수, 프레임별 IoU를 공개한다. 분모 0인 클래스는 조용히 PASS 처리하지 않고 `undefined`로 보고한다. 첫 한 seed가 통과해도 여러 seed·새 독립 DEV·봉인 TEST·지도 누적/주행 검증 없이 모델을 승격하지 않는다. 실패하면 같은 p02 결과를 본 뒤 이 실험의 기준·하이퍼파라미터를 바꿔 재시험하지 않는다.
