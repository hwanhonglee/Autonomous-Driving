## Actual limitations, not just missing status labels

1. **The current research architecture is a planning imitator with limited observable context.** `PerspectiveTrajectoryModel.forward` consumes the current six RGB images, calibration, ten ego-state rows and a provided dense 128-point route. The images have no temporal history; the GRU history is ego state, not tracked objects. Each ego row is bias, velocity/acceleration, yaw rate, steering and six maneuver bits—no release-clock, desired speed cap or explicit stop intent. This does not prove RGB cannot infer a traffic light; it means no explicit relevant-light/interaction representation or supervision is currently being learned. `Common10TorchDataset` supplies only XY/yaw/speed planning targets to the existing loss. [Model](../../../../learning/portable_e2e/model.py), [features](../../../../learning/portable_e2e/dataset.py), [tensor dataset](../../../../learning/portable_e2e/torch_dataset.py).
2. **The current 12 candidates are six DRIVE plus six STOP, not 12 safety hypotheses.** `_decode_physical_v1` uses route direction and bounded accelerations; its recurrent lower speed clamp can block an inward correction gradient. The active directional pair tests that precise training derivative without changing forward behavior. Current STOPMIX logits use the fused context only; they do not inspect generated geometry. Nevertheless, a new selector architecture is not the minimum next experiment: October frozen-head phase weighting failed to improve the real stall, and older candidate-aware scorer campaigns were also not promoted. There is no collision, lane-body clearance, red-light or jerk term in `trajectory_loss`. [Loss](../../../../learning/portable_e2e/losses.py).
3. **Coverage and supervision semantics have already mattered more than extra duration.** Masking only 105 source-owned warmup anchors, retaining their history and all driving/STOP records, changed W0's 20 s progress from 4.23 m to W1's 29.76 m. W1's 150 s run achieved about 200.51 m net, but stopped roughly 9.77 m short; raw-lane bodies/sweeps stayed inside while 17/2,999 conservative sweeps failed the 10 cm inset (minimum raw sweep clearance 0.078149 m). The frozen TRAIN probes contain only 18 immediate-start and 16 moving-band 1.5–2.5 m/s anchors, not 34 independent episodes or a sustained-cruise cohort. The original 200 STOP/hold probes remain, including 50 whose futures cross imposed tail; they must not be relabeled as genuine traffic stops. [Probe scope](selector_phase_ab/WARMUP_TRAIN_PROBE_REPORT.md), [actual body evidence](selector_phase_ab/W1_RECORDED_BODY_LANE_AUDIT.md).
4. **Longer fitting did not repair generalization.** W2 verified all 11,996 updates, the exact first-block W1 tensor state and 27-source closure, yet worsened all nine frozen 6.4 s DEV metrics. Starts stayed 15/18 oracle agreement, with early-speed error worse on 13/18; STOP agreement improved 179/200 to188/200. Both remained 6/9 absolute gates. These are mixed in-sample gains and known-DEV regression, not justification for another duration sweep. [Independent complete comparison](warmup_supervision_ab/w2_duration_v1/README.md).

## Next capability and map work, after that narrow experiment

**Traffic/interaction is the next genuine capability increment, not another scalar speed score.** Once basic moving/stop collection is trustworthy, collect a bounded TRAIN-only same-corridor stop/go scenario with relevant-light state, line geometry, action cause and actual stop/restart future. Paired signal phases should distinguish scene-required stops from arbitrary collector waiting; masks cover full history/future boundaries and missing labels remain unavailable. First expose those labels through a versioned dataset/head/loss contract, then compare the unchanged planner against one signal/stop-intent auxiliary task on the same admitted records. Do not feed oracle light state as a deploy-time feature or import protected Town03/CTrack labels. ACC and pedestrian prediction subsequently need temporal visual/actor-motion support; reverse parking additionally needs a signed-motion output/controller contract. These are material architecture/data changes, not capabilities unlocked by running the current trajectory loss longer.

**Mapping remains parallel and separate.** The current `MapContextRecovery` is an RGB-only seven-class image segmenter with a dilated residual context branch. The classes include traffic-light *fixture*, not red/green state. Mapping then projects learned pixels using **CARLA oracle depth and pose**; it does not yet learn camera-only depth/localization, lane topology or a complete HD map, and its output is not an input to the driving planner. Photometric training improved CTrack STRAIGHT road IoU27.68→41.01%, but 43.37% of road pixels still became sidewalk. Fixed three-frame projection showed mixed lane-cell results (LEFT9.690→6.641%, STRAIGHT11.074→11.268%). CPU2 forward+argmax p95 around130 ms is not end-to-end10 Hz. [Full image results](map_photometric_endpoints/RESULTS.md), [fixed projection results](map_photometric_projection/README.md).
