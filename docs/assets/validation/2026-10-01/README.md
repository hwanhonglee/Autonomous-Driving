[다음 주행 품질 관문](selector_phase_ab/DRIVING_NEXT_QUALITY_GATE.md)의 고정8회 ABBA 중 첫 [v1 선언](selector_phase_ab/TOWN07_THROTTLE_ISOLATION_IMPLEMENTATION.md)과 [v2 선언](selector_phase_ab/TOWN07_THROTTLE_ISOLATION_V2_WITHDRAWN.md)은 사전검토 결함으로 실행 금지했다. 이를 원본70프레임으로 교정한 [별도 v3 계획](selector_phase_ab/TOWN07_THROTTLE_ISOLATION_V3.md)은 합성시험17개를 통과했지만, 로컬 여유 공간이5 GiB 보존선+128 MiB보다 부족해 실제 CARLA 계측은 차단됐다. 기존2,787개 자료에 단순 재학습을 더하는 것은 현재 근거로는 보류한다.
2. **지도 인식 개선을 전체 경로 누적에서 확인:** 새 경로 비교의 학습·4장면 2,880개 예측·663,552,000픽셀 재집계를 완료했다. 별도 기존350장 검산도 완료했다. 두 C-track 경로의 전체240장씩을 순서대로 누적한[6개 지도·8개 PNG 및 독립 재계산](map_geometry_full_projection/README.md)도 완료했다. 깊이/좌표 투영·confidence0.5·0.2m 격자는 바꾸지 않았다. [차선 누락 집계](map_geometry_full_projection/lane_evidence_diagnosis_v1/DIAGNOSIS.md)에서 채택된 차선 증거 자체가 없는 셀이 많았다. 이어 [원본480프레임 픽셀 대조](map_geometry_full_projection/lane_raw_pixel_attribution_v1/REPORT.md)로 그 셀의 정답 차선 픽셀을 모델이 주로 도로로 분류했음을 확인했다. [TRAIN 원본480장 검산과 새 손실 학습 관문](map_lane_candidate_gate/README.md)은 차선 픽셀230,589개 중132,718개가 완전한3×3 내부가 아님을 확인했지만, 실제 선 폭이나 오분류 원인은 확정하지 않았다. 과거 차선 손실2배 실험은 정해진 관문에 실패했고 [기존 자료 재고](map_lane_candidate_gate/EXISTING_DEV_INVENTORY.md)와 [설치 지도·역할 후보 점검](map_lane_candidate_gate/NEW_SITE_FEASIBILITY.md)에서도 당장 사용 가능한 새 독립 검증 장소가0/2이므로 GPU 재학습은 현재 보류한다. 다음 한정 입력 보강인 [Town01 p02/p04 같은 틱 OFF/ON 쌍 수집](map_paired_p02_p04/PLAN.md)의 실행기·감사기·단위시험16개는 준비됐지만, **시작 시 6GiB 여유 조건** 때문에 실제 수집은 아직 하지 않았다. 이는 CARLA 깊이·위치를 사용하는 보조 지도 연구이며 카메라 단독 정밀지도 완성이 아니다. [이전 대표3장 투영 결과·한계](map_photometric_projection/README.md)도 그대로 보존한다.
3. **새 저속 순항 자료의 엄격한 재검증:** [미리 지정한 40–120m 과제](town07_low_speed_moving_train_PLAN.md)는 실제 수집을 마쳤다. 선택 영상327개·32.6초, 선택 창의 기하·영상·ACK 필요조건과 전체 JPEG4,188개 검사는 통과했다. 다만 [원본 V3 QA 결과](town07_low_speed_moving_v3_qa_v1/summary.json)는 선언된 선택적 물리 모듈이 실행 소스 보관본에 없어서 중단됐고, 별도 원본 진단은 제어 속도 참조점 비교와 미래 검사 코드 오류도 드러냈다. **327개는 아직 TRAIN에 넣지 않는다.** 결함을 고친 [새 V4 소스·감사 규약](town07_low_speed_moving_V4_QA_PROTOCOL.md)은 계획17개/전체21개 실행 소스 및 외부 CARLA 소스8개를 동결하고 합성 검사6개를 통과했지만, 시작에 필요한 약5.91GB보다 가용 공간이 적어 실제 V4 수집은 실행하지 않았다. V4의 40–120m 창은 현재 실제 정체 지점15–25m를 직접 학습하는 자료가 아니라는 한계도 유지한다. 별도로 [10–30m 4km/h 카메라 없는 예비 실험](town07_low_speed_10_30_native_pilot_v1/PLAN.md)의 계획을 고정하고 독립 검토 결함 3개를 보완해 합성 시험9개를 통과했다. 시작 사전점검은 로컬 여유5.098GB < 필요5.503GB라 차단됐고, **CARLA 새 실행·학습 데이터 승인은 없다**. 기존 실패 자료를 잘라 합격시키지 않는다. [W0/W1 중복 입력 원격 백업 후 승인된 로컬 삭제](storage_protection/exact_inputs_backup_v1/README.md)는 완료했다.
4. 새 데이터가 통과하면 주행 데이터 A/B를 실행한다. [9월 29일 기존 계획](../2026-09-29/drive_new_turn_data_ab/PLAN.md)은 다른 부모 모델을 쓰므로 이번 AH 비교와 혼동하지 않는다. 미통과 정답을 편입하거나 물리 기준을 낮추지 않는다.
