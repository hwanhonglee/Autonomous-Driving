# 가속도 학습 A/B 뒤 실제 주행 비교 — 실행 전 고정

<!-- HH_261001 - Freeze both candidate-control trials before seeing their outputs; preserve every failure. -->

이 문서는 새 A/B 학습이 진행 중이고 두 후보의 최종 출력이나 실제 주행 결과를 아직 확인하지 않은 상태에서 고정했다. [학습 조건](INITIAL_ACCELERATION_AB_PLAN.md)은 별도이며 변경하지 않는다.

## 같은 조건에서 두 모델 모두 운전시킨다

- A `A_ah_continuation`, B `B_preclamp_acceleration` 각각 최종 3,000-step 가중치 한 개. 부모 AH와 새 후보의 SHA256을 구분한다.
- 순서 A → B, 각 1회. 결과가 나쁜 후보를 생략하거나 좋을 때까지 자동 반복하지 않는다. 실행 기반 결함이 있으면 별도 버전·실패 원본을 남긴다.
- 기존 AH v2와 같은 Town07 직진 TRAIN 경로, seed 0, ClearNoon, Epic, 6카메라·보정·영상 전처리, 상태 20Hz·카메라 10Hz.
- 총 20초, 초기 정지 예열 1.2초, 속도 상한 9km/h. 실제 차량 형상에서 추종 제어기 구성. 0.3초 속도 미리보기·제어 gain·조향 규칙 변경 없음.
- 최초 센서 이력/출발 확보 후 모델로 한 방향 전환. 전문가 초기 명령·비교용 제안·긴급 제동·실제 모델 명령을 각각 기록한다.
- 100ms 추론 기한·50ms 입력 시간차·물리 궤적 검사·1m 경로 오차 중단 조건을 유지한다. 거절된 최고 점수 후보를 다른 후보로 몰래 바꾸지 않는다.
- 서로 다른 소유 CARLA 인스턴스를 순차 시작·종료한다. 다른 테스트나 공유 프로세스를 건드리지 않는다.

## 반드시 함께 보고할 값

1. 실제 모델 제어 ACK 수, 원본 카메라/상태/후보 수, 소스 일치와 종료 증거.
2. 진행 거리, 속도 곡선, 마지막 연속 정지 시간, 가까운 미래 0.1/0.3/0.5초 속도와 후보 선택.
3. 충돌/차선 센서 이벤트, 최대 경로 중심 오차, 긴급 정지 이유와 개입 수, 지연 p50/p95/최대.
4. 같은 조건의 A 대 B 및 부모 AH v2(15.22m 진행, 마지막 약 9.25초 정지)와의 차이. 차량 중심 전체 20초 GIF·PNG에 실패 구간도 포함한다.
5. 별도의 고정 Town03 오프라인 9개 지표와 물리 형상 검사. 반복 사용한 연구 DEV이며 독립 일반화 점수는 아니다.

핵심 가설은 B가 A보다 중간 정지를 줄이면서 실제 진행 거리를 늘리는가다. 충돌·침범·안전 개입이나 차로 오차 악화를 빼고 거리만 좋아졌다고 성공이라 하지 않는다. 차선 센서 이벤트 0과 전체 차체 포함 검증을 혼동하지 않는다.

이 시험은 210m 전체 경로를 완료할 수 없는 짧은 예산이다. 따라서 `DIAGNOSTIC_BUDGET_REACHED`를 목표 도달로 세지 않는다. 단일 저속 시험에서 좋아져도 기능 완료, 30km/h, Autoware 통합, 실차 승인을 하지 않는다. 결과가 좋으면 출발·주행·종점 정지를 포함하는 더 긴 검증으로 확장한다.
