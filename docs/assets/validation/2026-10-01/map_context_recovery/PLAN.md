# 지도 모델: 기존 인식 보존과 넓은 영상 문맥 비교

<!-- HH_261001 - Preregister a new architecture comparison, not a rerun or promotion of the failed p00 trial. -->

질문은 기존 소형 모델이 좁은 주변 픽셀에 의존하는 한계를 줄이면 차선/도로 인식과 기존 장소 성능을 함께 개선할 수 있는지다. 신규 클래스나 주행 기능을 추가하는 실험은 아니다. 지난 p00 B의 실패 판정과 원본은 그대로 보존한다.

- 공통 시작: 9월 29일 p00 B의 2,000-step 체크포인트 `04614038b3d77a38f79b5a043c995b78ef6ee1d64537575fb2903c261ea5a746`.
- A: 원래 7클래스 MapPerception 추가 학습. B: 같은 가중치에 quarter-resolution dilation 2/4/8 잔차 문맥 블록만 추가. 마지막 투영을 0으로 초기화하여 최초 출력이 A와 정확히 같은지 TRAIN 영상으로 검사한다.
- 동일 TRAIN 729장(Town01 497 + Town02 p00 232), 동일 640×360, batch 8, 추가 **10,000 step씩**, seed 20261001. 같은 순서의 표본·aligned crop, 기존 Town01 TRAIN 기반 클래스 가중치, fresh AdamW lr 3e-5/weight decay 1e-4, clip 5.0. 학습률·seed·체크포인트 선택 탐색은 하지 않는다.
- 두 팔의 최종 체크포인트를 먼저 저장한 뒤 Town01 DEV 118장과 p02 232장만 고정 평가한다. 두 평가 경로는 과거 노출된 연구용 자료이며 독립 DEV/TEST가 아니다. 새 결과를 보고 중간 epoch를 고르거나 같은 설정을 조절해 반복하지 않는다.
- 기존 p00 A를 공통 기준으로 기존 다섯 관문을 **그대로** 계산한다: p02 차선 +2pp 이상, p02 도로 -1pp 이내, Town01 도로/차선/전 클래스 각각 -0.5pp 이내. 새로운 A 대 B 차이도 별도 표시한다. 통과해도 독립 검증 없이 자동 채택하지 않는다.
- 체크포인트, 모든 학습 이력, 표본 순서 해시, 7×7 혼동행렬, 전체 평가 예측을 보존한다. 효과가 없거나 퇴행하면 그대로 기록한다.

실행은 PRO6000 개인 venv·개인 소스/결과 폴더, 물리 GPU 0 UUID 고정·idle 및 lease 확인 후 순차 진행한다. 설치·GPU 1·재부팅·기존 작업 종료는 없다. 기존 데이터 재사용이므로 새 영상 전송은 없다. 기존 팔은 약 6분, 문맥 팔은 약 8–15분의 순수 학습을 예상하지만 실측으로 갱신한다. 학습 시간 증가는 구조 비교 양쪽에 동일하게 적용하며, 더 오래 학습했다고 성능 향상을 가정하지 않는다.
