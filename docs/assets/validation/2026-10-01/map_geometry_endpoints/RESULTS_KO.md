# 새 경로 자료 학습 결과 — 도로는 개선, 전체 지도 완성은 아님

<!-- HH_261001 - Explain the exact paired comparison and preserve every regression and fixed panel. -->

**CTrack 직진 도로 IoU는 이번 대조군 62.47%에서 새 경로 후보 72.33%로 개선됐습니다.** 좌회전 개선은 작고, 일부 기존 학습 장면과 Town02 holdout 항목은 나빠졌습니다. 따라서 “모든 클래스 개선”, “HD-map 완성” 또는 모델 승격으로 해석하지 않습니다.

## 무엇을 비교했나

- **Control / 대조군:** 공통 기존 자료에 추가되는 480개 학습 슬롯에서, 기존 Town01 FALSE 자료를 다시 사용했습니다.
- **Geometry / 새 경로 후보:** 같은 480개 슬롯에, 사용하지 않았던 Town01 p02·p04 경로의 전체 480장을 사용했습니다. 실패한 CTrack이나 보호 DEV를 TRAIN에 넣지 않았습니다.
- 두 모델은 같은 원래 부모, 구조·7클래스·가중치·손실·표본/크롭 순서·공통 TRUE 광도 증강으로 각각 **10,000 step / 80,000 노출**을 실제 학습했습니다. 새 경로는 FALSE 후처리 영상입니다. 새 Town·날씨·TRUE 촬영을 추가한 실험은 아닙니다.

이전 photometric 모델의 CTrack 직진 도로 IoU **41.01%는 이번 대조군이 아닙니다.** 이번에는 양팔의 표본 구성과 기존 자료 반복량도 이전 실험과 달라졌습니다. 따라서 41.01→72.33% 전체 차이를 새 경로 덕분이라고 주장할 수 없습니다. 이번의 일치된 비교는 **62.47→72.33%, +9.85%p**입니다. 과거 모델 대비 모든 픽셀·클래스 차이는 별도 항목으로 [전체 JSON](RESULTS.json)에 보존했습니다.

## 사전 고정한 네 장면 전량 결과

아래 값은 **Control → Geometry IoU(%)**입니다. FALSE/TRUE는 같은 원본 프레임의 RGB 후처리 OFF/ON이며, 두 조건의 semantic 정답은 같습니다. 각 장면·조건마다 240장을 전부 사용했습니다.

| 장면 / RGB 조건 | 도로 | 보도 | 차선 표시 |
|---|---:|---:|---:|
| CTrack LEFT / TRUE | 88.7866 → 89.0940 | 48.5072 → 48.9423 | 26.9345 → 28.0283 |
| CTrack STRAIGHT / TRUE | 62.4749 → 72.3295 | 9.9894 → 13.9235 | 39.3014 → 39.4205 |
| Town01 p01 TRAIN / FALSE | 99.9075 → 99.8984 | 98.9618 → 98.8048 | 99.3633 → 99.0664 |
| Town01 p01 TRAIN / TRUE | 99.2015 → 99.2159 | 96.2409 → 96.2742 | 83.0192 → 83.4446 |
| Town02 p00 TRAIN / FALSE | 99.8894 → 99.8909 | 98.6585 → 98.5992 | 99.2374 → 99.0728 |
| Town02 p00 TRAIN / TRUE | 99.2893 → 99.2972 | 96.5289 → 96.5519 | 85.8281 → 85.6936 |

CTrack에서 실제 도로를 보도로 잘못 분류한 비율은 LEFT **3.24→0.89%**, STRAIGHT **24.48→16.91%**였습니다. 다른 오류와 오탐이 남기 때문에, 이 감소율 자체가 도로 IoU 증가량은 아닙니다. 정답이 없는 CTrack 신호등 시설물·표지판·기둥 클래스의 IoU는 계속 `null`이며 오탐은 제외하지 않았습니다.

기존 장면의 약점도 보존했습니다. 예를 들어 Town01 FALSE의 신호등 시설물은 **75.28→71.38%**, 기둥은 **73.60→70.30%**로 내려갔습니다. 모든 7클래스의 정답 픽셀 수, 오탐, 혼동행렬, 조건별 지연은 [전체 영문 표](RESULTS.md)에 있습니다. TRAIN 영상 재검사는 일반화 검증이 아닙니다.

## 고정 PNG 12장 검토

각 장면의 **000·119·239 전부**를 확인했습니다. RGB·정답·두 모델 결과는 자르거나 축소해 저장하지 않았으며, 독립 검산은 72개의 640×360 하위 패널 모든 픽셀을 확인했습니다.

- CTrack LEFT: 도로의 큰 윤곽은 두 모델 모두 잡지만, 000의 얇은 흰색/점선과 차선 가장자리가 부족합니다. 119·239에서도 연석 주변 분류가 거칠고 식생·시설물 오탐이 남습니다.
- CTrack STRAIGHT: 000·119에서 그림자와 겹치는 넓은 도로 구역을 보도로 잘못 칠하는 현상이 남습니다. 후보가 일부를 복구하지만 해결하지 못했습니다. 노란 중앙선이 보이는 곳에서도 흰색 가장자리선은 빠집니다. 이것은 고정 영상의 관찰이지 그림자가 유일한 원인이라는 증명은 아닙니다.
- Town01 p01: FALSE는 도로·보도 윤곽이 정답과 가깝습니다. TRUE 119의 강한 밝기와 작은 시설물 주변에서는 여전히 기둥/표지판 경계와 오탐이 불안정합니다. 후보가 모든 요소를 개선하지는 않습니다.
- Town02 p00: 두 조건 모두 큰 도로 윤곽은 비슷하나, 000·119의 나무/원거리 시설물 주변에 기둥 같은 오탐이 보입니다. 239 교차로 경계와 작은 신호등 부근도 정답과 완전히 같지 않습니다.

모든 원본 해상도 PNG 링크는 [장면별 결과](RESULTS.md)에 있습니다. 유리한 한 장만 골라 결론 내리지 않았습니다.

## 기존 DEV/holdout은 별도

이미 사용된 **Town01 DEV 118장 + Town02 p02 holdout 232장**의 원래 평가도 별도로 독립 재집계했습니다. 이번 도구가 그 350장을 다시 추론하거나 TRAIN에 넣지는 않았습니다.

Town01 DEV의 7클래스 IoU는 모두 올랐지만, Town02 holdout은 섞인 결과입니다. 도로 **98.7990→98.5906%**, 보도 **94.2188→93.1704%**, 기둥 **41.8362→39.9904%**, other **95.4252→94.8108%**는 하락했습니다. 반대로 차선 **97.5411→98.5349%**, 신호등 시설물 **31.1085→36.3946%**, 표지판 **70.8670→74.3141%**는 상승했습니다. 알려진 holdout 재사용이므로 독립 인증은 아닙니다.

## 완료 범위와 남은 일

네 장면 모두 추론 완료 및 독립 재집계 PASS: **2,880개 예측 / 663,552,000픽셀**, 별도 known350 검산 **161,280,000픽셀**입니다. 네 장면 산출물은 **24,297,045바이트**로 30MiB 제한 안이며, 원본·체크포인트·동결 코드 해시가 끝까지 일치했습니다. 모델 품질 통과가 아니라 증거 무결성 PASS입니다.

CPU 2스레드 forward+argmax p95는 약 **120.8–143.2ms**였습니다. 첫 차가운 추론을 포함한 측정이며, 초기 평가와 별도 CPU 재검산의 동시 작업 가능성도 있어 단독 장비 벤치마크로 취급하지 않습니다. 이 결과만으로 전체 파이프라인 10Hz를 주장하지 않습니다.

이번 결과는 RGB 의미분할입니다. 새 BEV 누적 결과, 카메라만으로 학습한 깊이·위치, 연결된 차선 지도, 전체 주행 기능이나 실차 성능을 뜻하지 않습니다. CTrack은 계속 EVAL 전용이고, LEFT의 원래 owner FAIL도 유지합니다. 다음 단계는 별도 사전 계획과 검토를 거친 전체 프레임 지도 누적 확인이며, 임계값 변경이나 새 학습을 이번 결과에 끼워 넣지 않습니다.
