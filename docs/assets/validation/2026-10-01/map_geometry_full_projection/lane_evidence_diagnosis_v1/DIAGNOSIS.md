# HH_261001 — 차선 셀 증거 누락/누적 투표 분해

완료된 최종 수치 격자6개만 읽은 사후 진단입니다. 새 추론·GPU·시뮬레이터·임계값/융합 변경은 없습니다.

| 경로 / 모델 | 기준 차선 셀 | (a) 학습 관측 없음 | (b) 관측 있으나 채택된 차선 증거 없음 | (c) 차선 증거 있으나 우세 라벨에 패함 | (d) 차선 우세 |
| --- | ---: | ---: | ---: | ---: | ---: |
| ctrack_left / control | 1375 | 175 | 989 | 89 | 122 |
| ctrack_left / geometry | 1375 | 116 | 1048 | 77 | 134 |
| ctrack_straight / control | 1172 | 116 | 785 | 24 | 247 |
| ctrack_straight / geometry | 1172 | 79 | 801 | 19 | 273 |

각 행의(a)+(b)+(c)+(d)는 분모와 정확히 같습니다. 가장 큰 항목은(b)입니다. 현재 차선 누락 중(a)+(b)의 비율:

- ctrack_left / control: 1164/1253 = 92.90%.
- ctrack_left / geometry: 1164/1241 = 93.80%.
- ctrack_straight / control: 901/925 = 97.41%.
- ctrack_straight / geometry: 880/899 = 97.89%.

따라서 **이미 채택된 차선 증거가 투표에서 밀리는 현상보다, 해당 기준 셀에 채택된 차선 증거가 없는 경우가 대부분**입니다. 이는 원본 영상의 인식 실패를 확정하지 않습니다. confidence≥0.5, stride3, 깊이0.1~40m의 엄격한 범위와0.2m 양자화가 모두 개입합니다. 최종 격자만으로 분류·낮은 확신·샘플링·투영 위치 중 원인을 분리할 수 없습니다.

우세 라벨은 관측 프레임 수가 아닌 confidence_sum의 최댓값입니다. 정확한 동률이면 label_order에 저장된 최초 삽입 라벨이 이깁니다. 이 네 비교에서 차선이 패한 confidence_sum 동률은 모두0개입니다.

## 희귀 라벨을 한 번이라도 관측하면 승격하는 경우의 위험

격자를 바꾸지 않고 존재 집합만 센 가정입니다. 기준은 동일한 oracle 우세 라벨이며 물리적 차선의 절대 진실이 아닙니다.

| 경로 / 모델 | 현재 TP / FP | 차선 증거 있는 셀 전부를 차선으로 부를 때 TP / FP | 추가 TP / 추가 FP | FP 중 oracle 보조 차선 증거 있음 / 전혀 없음 |
| --- | ---: | ---: | ---: | ---: |
| ctrack_left / control | 122 / 40 | 211 / 433 | 89 / 393 | 399 / 34 |
| ctrack_left / geometry | 134 / 60 | 211 / 445 | 77 / 385 | 404 / 41 |
| ctrack_straight / control | 247 / 58 | 271 / 670 | 24 / 612 | 545 / 125 |
| ctrack_straight / geometry | 273 / 76 | 292 / 707 | 19 / 631 | 560 / 147 |

단순 희귀 라벨 승격은 위 표처럼 추가 TP보다 많은 기준 FP를 늘릴 수 있습니다. 일부 FP 셀에는 oracle 보조 차선 증거도 있으므로 모두 허구 차선이라고 단정할 수는 없습니다. 이 수치로 새 임계값·융합 정책을 선택하거나 지도 승인을 주장하지 않습니다.

입력 요약·6개NPZ·원래 융합/투영 소스 SHA256, 복원된 snapshot 일치, 각 범주 셀 좌표 집합 해시와 분자/분모는 result.json에 있습니다. LEFT의 원래 owner FAIL 및 원래 live replay 불가는 그대로 보존됩니다.
