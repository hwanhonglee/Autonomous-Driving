# 동일 데이터 광도 증강 A/B 결과

<!-- HH_261001 - Summarize all fixed comparisons without promotion or independent-validation claims. -->

동일한 TRUE RGB 학습 데이터·모델·1만 스텝에서 회색 혼합/밝기 증강만 추가했습니다.
새 대조군은 이전 Appearance 모델과 가중치가 동일하며, 비교한 **331,776,000개 예측 픽셀도 모두 일치**했습니다.

| CTrack | 도로 IoU | 차선 IoU | 보도 IoU |
| --- | ---: | ---: | ---: |
| LEFT | 78.04 → 88.64% | 21.09 → 27.28% | 29.10 → 51.14% |
| STRAIGHT | 27.68 → 41.01% | 26.93 → 38.20% | 5.81 → 6.79% |

개선은 확인됐지만 완성은 아닙니다. STRAIGHT에서 실제 도로의 **43.37%가 여전히 보도로 오분류**됩니다(이전 66.30%). 고정 영상에서도 흰색 가장자리 차선 누락과 나무/시설물 오탐이 남았습니다.

학습에 사용한 TRUE 영상에서는 도로 IoU가 Town01 99.39%, Town02 99.49%인 반면 외부 STRAIGHT는 41.01%입니다. 이는 학습 영상 재현과 외부 일반화의 차이이며, TRAIN 점수를 검증 성능으로 해석하면 안 됩니다. 기존 조명 DEV/holdout 결과도 혼재합니다. 예를 들어 Town02 차선은 97.80 → 96.83%로 하락했습니다.

네 시나리오 전체 **2,880개 예측·663,552,000픽셀** 독립 재집계 PASS. 별도로 기존 DEV/holdout **161,280,000픽셀**도 PASS입니다. 고정 0/119/239의 **12개 PNG·72개 원본 크기 패널**을 모두 확인했습니다. 누락·성능 기반 프레임 선택은 없습니다.

CTrack은 계속 EVAL 전용이고, 학습·모델 승격·HD-map 완성·주행 성공을 주장하지 않습니다. LEFT의 원래 owner FAIL 및 당시 live-map 일치 확인 불가 기록도 유지합니다.
