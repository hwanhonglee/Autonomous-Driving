# 새 주행 모델의 저속 미래 궤적 공동 학습 결과

<!-- HH_261001 - Report actual completed updates, known-scene regression and the remaining live-control gate. -->

**새 모델을 GPU 0에서 추가 3,000회 실제 학습했다.** 학습 구간의 경로 오차는 줄었지만 기존 다른 장면의 점수는 악화됐다. 따라서 범용 주행 모델로 채택하지 않고 저속 직진 연구 후보로 유지한다.

## 어떤 모델을 어떻게 학습했는가

기존 W1 모델의 이름을 바꾼 것이 아니다. 새 V2는 5시점의 6카메라 영상에서 공간 특징을 유지하고, 과거 차량 상태와 현재 안내 경로를 함께 사용한다. 신경망이 공간상의 경로 곡률과 선호 속도를 내놓으면, 별도 시간 계산부가 6.4초 미래 경로와 속도를 만든다.

초기 공간 출력 학습 200회에 이어 이번에는 **실제 미래 위치와 속도 정답을 함께 사용한 학습**을 했다. 원래 327개 입력과 미래 정답 20,928개는 검사된 V4 전문가 순항 구간에서 가져왔다. 정답을 추론 입력에 넣거나 정답을 잘라 기준에 맞추지 않았다. 정차·출발 의도 헤드는 아직 학습하지 않았고 이번 과제는 공개된 저속 순항 조건이다.

| 실제 학습량 | 값 |
| --- | ---: |
| 모델 파라미터 | 2,729,703개 |
| 추가 가중치 업데이트 | 3,000회 |
| 배치 크기 | 4 |
| 학습 노출 | 12,000개 |
| 고유 입력 앵커 | 327개 |
| 고유 주행 에피소드 | **1개** |
| 같은 입력의 노출 회전수 | 약 36.70회 |
| 학습과 중간 평가 기록 시간 | 약 10분 4초 |

노출 12,000개는 새로운 주행 12,000개를 의미하지 않는다. 한 경로의 자료를 반복한 것이다. 독립 경로·회전·정차를 포함한 본 학습은 별도 데이터가 필요하다.

## 개선과 퇴행

TRAIN은 학습에 쓴 자료다. 이 표의 경로 오차는 **327개 전체 TRAIN**에 대한 평균이며 일반화 성능이 아니다. 기존 DEV는 이전에도 사용한 다른 장면 8개로, 새 독립 TEST가 아니다.

| 측정 항목 | 시작 | 3,000회 후 | 해석 |
| --- | ---: | ---: | --- |
| TRAIN 6.4초 평균 경로 오차 | 0.203m | **0.072m** | 학습 구간 개선 |
| TRAIN 마지막 위치 오차 | 0.517m | **0.182m** | 학습 구간 개선 |
| TRAIN 실제 순간 속도 오차 | 0.0157m/s | 0.0175m/s | 소폭 악화 |
| 기존 DEV8 공간 출력 손실 | 0.2763 | 1.8058 | **악화** |

![실제 3000회 학습과 별도 평가](actual_joint_training_and_regression.png)

마지막 행은 위치 오차가 아니라 곡률과 선호 속도의 손실이다. 새 데이터는 약 9km/h 순항 한 구간이므로 기존 다양한 속도·회전 장면을 유지하는지 추가로 확인해야 한다. 이번 결과는 한 구간만 반복하면 다른 상황의 성능도 좋아진다는 증거가 아니다. 이후 본 학습에서는 회전·정차·기존 자료의 균형과 독립 평가를 포함한다.

## 첫 학습 실패는 어떻게 처리했는가

첫 공동 학습은 CUDA의 결정론적 선형 보간 역전파를 지원하지 않아 **첫 가중치 업데이트 전** 실패했다. [원래 실패 기록](../../../../../storage/experiments/training/2026-10-01/temporal_v2_low_speed_joint_v1/failure_receipt.json)을 보존했다.

이후 새 버전에서 동일한 선형 보간 가중치를 행렬 곱으로 계산했다. 실제 GPU 0에서 순전파·역전파와 전체 시간 계산부를 검사했고 반복 결과가 같았다. 기존 계산식·학습기 파일을 덮어쓰거나 결정론 조건을 해제하지 않았다. CPU와 GPU의 유한 정밀도 차이도 선언된 허용 범위 안이었다.

## 실제 제어까지 남은 일

최종 가중치를 데이터 전용 NPZ로 로컬에 전달하고, 원격 소스 54개의 해시와 텐서 형태를 대조해 로딩에 성공했다. 로컬에 패키지를 설치하지 않았다.

전체 크기의 카메라 입력으로 입력 처리·신경망·시간 계산부·경로 검사·PI 제어까지 측정했을 때, 기존 실행 방식은 20회 중 1회가 원래 100ms 제한을 넘었다. 합격으로 처리하지 않았다. 실제 원본의 변경 불가능한 보관을 확인하는 새 실행 버전으로 반복 해시 비용을 줄이고, 입력·출력 등가성을 검사한다. 그 후 실제 CARLA에서 제어와 수신 확인을 계측한다.

이번 학습은 **모델 완성·기능 승인·30km/h·실차 운행 성공이 아니다.** 주행 9개 영역·30개 하위 기능의 승인 수는 0/30이다. 기존 모델의 PI 제어에서 확인된 [실제 순항 개선](../town07_w1_pi_control_results_v1/README.md)과도 구분한다.
