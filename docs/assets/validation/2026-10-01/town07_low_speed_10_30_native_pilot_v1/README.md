# Town07 정체 구간의 저속 주행 예비 시험 결과

<!-- HH_261001 - Report the complete fixed-window pilot without implying learned driving or data admission. -->

**같은 경로의 10–30m 구간을 약 4km/h로 연속 주행할 수 있었다.** 새로 실행한 전문가 제어 예비 시험은 고정된 구간의 속도·가감속 기준을 통과했다. 이제 이 구간의 학습용 카메라 자료를 별도로 수집할 근거가 생겼다. 자체 모델의 주행 성공이나 학습 데이터 승인은 아니다.

## 실제 결과

| 항목 | 측정값 | 의미 |
| --- | ---: | --- |
| 10–30m 연속 기록 | 370개 상태·18.45초 | 해당 구간의 모든 20Hz 상태를 사용했고 유리한 부분만 자르지 않음 |
| 구간 실제 속도 | 1.071–1.116m/s | 약 3.86–4.02km/h이며 고정 기준 0.7–1.5m/s 충족 |
| 진입·종료 경계를 포함한 최대 속도 변화율 | 0.907m/s² | 구간 기준 2.9m/s² 이내 |
| 구간 최대 경로 중심 오차 | 0.0177m | 약 1.77cm. 차체 전체의 차선 여유를 증명하는 값은 아님 |
| 전체 기록과 명령 확인 | 상태 651개·ACK 654개 | 준비·출발·구간 종료 기록을 보존 |
| 모델·카메라·학습 | 모두 0회 | CARLA BasicAgent를 사용한 물리적 주행 가능성 시험 |

전체 실행의 최대 속도 변화율은 **4.072m/s²**였다. 진행도 약 0.323m의 출발 순간이며, 선택한 10–30m 밖이다. 사전에 정한 전체 긴급 한계 8m/s² 이내여서 이번 **저속 순항 가능성** 판정은 통과했지만, 출발까지 포함한 승차감 합격으로 바꾸어 말하지 않는다. 이 예외도 원본 판정과 그림에 남겼다.

![준비와 출발부터 고정 구간 종료까지의 실제 속도와 가감속](results_v1/native_pilot_speed_rate_progress.png)

초록색 영역은 선택한 10–30m 구간이다. 이 그림은 실제 상태 그래프이며 카메라 영상이나 Autoware 화면이 아니다.

## 기록과 한계

실행 종료 파일의 원본 재계산은 PASS이며, 계획·실행 소스 해시 일치, 명령 순서와 실제 제어·프레임 연결, 소유 프로세스 종료와 포트 해제를 확인했다. 별도의 읽기 전용 검토에서도 세계좌표 속도·원본 위치·경로 투영과 전체 명령을 다시 계산해 같은 결과를 얻었다. 선언한 로컬 소스22개를 포함한 소유자 보관 소스66개와 외부 에이전트5개의 해시도 일치했다. 마지막 기록의 충돌·차선 센서 사건 수는 각각 0이다. 센서의 비동기 전달 한계가 있으므로 차체 접촉 부재의 독립 증명이라고 해석하지 않는다.

차체와 연속 이동 중 차선 여유, 10Hz 6카메라 동기화, 10장 이력, 6.4초 실제 미래 정답은 이번 시험에서 검증하지 않았다. 단일 Town07 직선 결과이며 좌우 회전·다른 맵·30km/h·실차로 일반화하지 않는다.

## 다음 작업

현재 자체 모델의 급정지 원인을 찾기 위해 **같은 W1 가중치의 정상 제동 A/B**를 먼저 비교한다. 별도로 이 예비 시험의 설정을 이용한 **새 10Hz 6카메라 수집 계획**을 만든다. 해당 자료가 전체 영상·미래 정답·차체 여유·소스 출처 검사를 통과하면 GPU0의 주행 학습에 편입한다. 출발 자료는 위 가감속 예외를 해결하거나 별도의 유효 자료로 확보해야 한다.

주행은 9개 영역·30개 하위 기능 중 기본 주행 5개를 위한 복구 단계이며 승인 수는 0/30이다. 지도 모델은 별도 트랙이다. 이 순항 가능성 통과를 새 기능 승인으로 세지 않는다.
