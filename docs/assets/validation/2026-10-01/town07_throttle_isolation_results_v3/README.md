# Town07 작은 스로틀과 큰 스로틀의 실제 계측 결과

<!-- HH_261001 - Distinguish measured throttle response from model improvement and censored outcomes. -->

**작은 스로틀만으로 기존 급정지가 재현되지는 않았다. 큰 스로틀을 계속 주는 방법도 채택하지 않는다.** 고정한 8회를 모두 실행했으며, A 4회는 3초 계측을 마쳤고 B 4회는 약 1초에 과속 보호 한계로 중단됐다. 이 시험에서 모델을 학습하거나 모델 성능을 올렸다는 결론은 없다.

## 무엇을 비교했나

Town07 같은 직선 경로의 16m와 25m 위치에서 각각 A → B → B → A 순서로 실행했다. 먼저 전문가 제어로 해당 위치에 도착한 뒤, 조향과 브레이크를 0으로 두고 스로틀만 A=0.01 또는 B=0.20으로 고정했다. 계획은 각 3초이며, 속도 2.7m/s 초과 등 기존 보호 조건을 그대로 적용했다. 진입 속도는 약 2.4m/s, 즉 약 9km/h였다.

이는 **CARLA 차량의 저속 물리 반응을 분리하는 시험**이다. 자체 모델이나 Autoware가 주행한 시험은 아니다. 카메라 수집·모델 호출·학습은 모두 0회다. 실제 모델이 정지하던 더 낮은 속도와 작은 제동의 조합은 이 시험에 포함되지 않았다.

## 실제 측정값

| 위치 | 팔과 반복 수 | 진입 속도 | 실제 관측 시간 | 마지막 속도 | 관측 구간 순진행 | 종료 이유 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| 16m | A 2회 | 2.484m/s | 3.00초 | 1.598m/s | 5.991m | 계획한 계측 완료 |
| 16m | B 2회 | 2.484m/s | 1.00초 | 2.703m/s | 2.559m | 2.7m/s 과속 한계 |
| 25m | A 2회 | 2.422m/s | 3.00초 | 1.510m/s | 5.963m | 계획한 계측 완료 |
| 25m | B 2회 | 2.422m/s | 1.05초 | 2.703m/s | 2.683m | 2.7m/s 과속 한계 |

같은 위치에서 반복한 각 팔의 속도·진행 수치는 동일했다. A의 가장 큰 순간 감속은 약 −1.85m/s²이며, 모든 팔의 **관측 구간**에서 −8m/s²보다 급한 속도 감소와 속력 0.05m/s 이하 진입은 없었다. B의 중단 이후는 측정하지 않았으므로 3초 결과는 알 수 없다. 위의 서로 다른 길이의 관측 구간을 완주 성능으로 비교하면 안 된다.

![Town07 실제 속도와 스로틀 계측 그래프](audit_v2/native_vx_throttle.png)

위 PNG는 원본 20Hz 상태와 실제 명령 확인값으로 그린 그래프다. 차량 화면이나 카메라 촬영 이미지는 아니다. 주황색 선의 끝에서 측정이 중단됐으며, 그 뒤를 보간하거나 3초 결과로 채우지 않았다.

## 독립 검산 결과

원본 차량 상태 2,742개와 명령 ACK 2,758개를 다시 계산했다. 8회 모두 원본 속도·위치 재구성, 경로 투영, 20Hz 시간 간격, 명령과 관측 프레임 연결, 계획·소스 보관 해시가 일치했다. 회차마다 로컬 소스 66개와 외부 CARLA 에이전트 소스 5개를 대조했다. 모든 소유 실행은 정리 오류 없이 끝났으며 사용 포트를 해제했다.

B의 원래 종료 파일에는 `worker_identity_matches=false`가 있다. 독립 대조에서 계획과 회차 식별은 맞았다. 원래 실행기의 이 필드는 **완료 요약의 존재까지 요구**하므로, 보호 한계로 중단돼 요약이 없는 B에서 false가 된 것이다. 원본 파일은 수정하지 않았고, 독립 분석에서는 원본 식별 일치와 이 완료 필드를 구분했다.

ACK는 명령 전달·프레임 정렬의 근거이지 바퀴 토크나 접촉 물리의 독립 측정은 아니다. 기록된 진입 상태가 같아도 차량 내부 물리 상태까지 동일했다고 증명하지 않는다. 충돌·차선 센서의 이벤트 전달 지연 가능성도 남는다. 위치별 2회 반복으로 모든 맵의 안전성과 일반화를 입증하지 않는다.

## 이 결과로 바뀌는 다음 순서

1. **단순 스로틀 하한 추가는 보류한다.** B는 보호 한계를 넘었고 원래 급정지 원인을 해결했다는 증거가 없다.
2. **4km/h 전문가 예비 시험으로 정체 구간 10–30m의 연속 저속 주행 가능성을 확인한다.** 성공하더라도 카메라·미래 정답·차체 여유 검증 없이 학습 자료로 편입하지 않는다.
3. **같은 W1 가중치를 유지한 제어 A/B를 준비한다.** A는 기존 제어, B는 양수 이동 목표에서의 정상 제동만 제거한다. 정지 목표와 긴급 정지 권한은 보존한다. 이는 원인 판별 후보이며 아직 채택하거나 모델 개선이라고 세지 않는다.
4. 유효한 저속·회전 자료와 새 구조의 학습 입력 계약이 갖춰지면 GPU0에서 데이터 A/B와 공간 경로·속도 분리 모델 학습을 진행한다. 실패 자료를 잘라 합격시키거나 기준을 낮추지 않는다.

현재는 전체 주행 9개 영역·30개 하위 기능 중 직진·좌회전·우회전·종점 정지·속도 추종 5개를 위한 기본 주행 복구 단계다. 이번 시험은 주로 **속도 추종과 급감속 원인**을 다룬다. 승인 기능 수는 여전히 0/30이다.
