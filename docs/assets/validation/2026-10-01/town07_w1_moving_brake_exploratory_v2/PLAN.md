# Town07 같은 모델의 정상 제동 비교 계획

<!-- HH_261001 - Predeclare a bounded exploratory controller comparison without promoting either arm. -->

목표는 **학습 모델이 이동을 지시하는데 작은 정상 제동이 급정지에 기여하는지** 실제로 확인하는 것이다. 모델을 다시 학습하거나 조향·스로틀 이득을 동시에 바꾸지 않는다. 첫 버전의 JSON 자료형 검사 오류를 수정한 별도 v2이며, 원본 실패 기록은 보존한다.

## 고정할 비교 조건

| 항목 | A | B |
| --- | --- | --- |
| 모델 | 동일 W1 가중치 | 동일 W1 가중치 |
| 이동 목표가 0.05m/s보다 큰 경우 | 기존 정상 제어 | 기존 정상 제어에서 브레이크만 0 |
| 이동 목표가 0.05m/s 이하인 경우 | 기존 정지 제어 | 동일한 기존 정지 제어 |
| 긴급 제동·전문가 안전 개입·기한 초과 처리 | 기존 권한 유지 | 동일한 권한 유지 |
| 조향·스로틀 이득·후보 선택·0.3초 속도 참조 | 기존 값 | 동일한 기존 값 |

Town07 같은 직진 경로, Prius, ClearNoon, 같은 센서 위치·화각·영상 설정, 20Hz 물리와10Hz6카메라를 사용한다. 전문가가 출발을 돕고, 속도0.5m/s 초과·10장 상태 이력·동일 카메라 프레임 조건이 갖춰지면 모델로 전환한다. 각20초의 **총 기록 시간**에는 준비와 전문가 출발도 포함된다. 모델 단독20초를 뜻하지 않는다.

실제 세계좌표 평면 속도가2.7m/s를 넘으면 위반 원본을 남긴 뒤 기존 예외 정리의 전체 제동과 종료를 사용한다. 기존 경로 중심 오차1m 한계, 센서 사건·긴급 권한, 모델 후보의 물리 검사도 유지한다. 목표 경로 전체는 약210m라 이20초 비교의 미완주를 완주로 바꾸어 세지 않는다.

## 반복 수와 자원

디스크 보존선5GiB를 유지한다. 각 팔의 예약은256MiB, 쌍 전체 추가 여유는64MiB이며 시작 필요 여유는5,972,688,896B다. 정확한 모델 입력 tensor는10번째 정책 호출마다 보관하고, 해당 별도 디렉터리의128MiB 상한을 검사한다. 전체 JPEG·원본 차량 상태·명령·예측은 보존한다. 시작과 기록 중 공간을 확인하고 부족하면 실패 원본을 유지한다.

순서는 A1 → B1, 각1회다. 4회ABBA의 반복 확인이 아닌 **탐색 비교**이며, 시간 순서와 한 번씩의 변동 가능성이 남는다. A가 운동 결과에 실패해도 소스와 소유권 정리가 깨끗하면 B를 원래 순서대로 실행하되, 기반 실행 오류가 있으면 비교를 중단한다. 자동 재시도와 출력 덮어쓰기는 없다. 실행 소스·가중치·지도·경로는 별도 사전 선언에서 해시로 고정한다.

## 결과에서 반드시 구분할 것

같은 총 기록 구간의 진행 거리, 실제 속도, 이동 후 첫 정지 시각, 저속·정지 누적 시간, 급감속과 실제 제동, 모델 입력/추론/명령 ACK, 차체와 이동 중 차선 여유, 종료·소스 검사를 보고한다. 보호 중단으로 구간이 짧으면 부분 관측을20초 결과로 채우지 않는다. 원본 카메라와 차량 중심 경로 그림은 계측 그래프와 구분한다.

개선이 관측되더라도 바로 승격하지 않는다. 후속 반복·회전·목표 정차·같은 조건의 퇴행 검사로 확인한다. 작은 정상 제동 제거는 정차 목표의 학습이나 교통규칙 이해를 대신하지 않는다. 모델 가중치 업데이트는0회이며 전체 승인 기능 수는0/30으로 유지한다.
