# Town07 — 작은 제동을 줄이니 급정지는 줄었지만, 순항은 아직 실패

<!-- HH_261001 - Report a measured tradeoff without promoting a one-pair controller experiment. -->

**실제 같은 W1 모델로 A/B를 실행했다. B에서는 급감속 2회가 0회로 줄었지만, 이동거리는 27.02m에서 23.31m로 줄었다.** 제동을 손보면 일부 현상이 달라질 수 있다는 근거는 얻었다. 그러나 계속 속도를 유지하며 잘 달리는 모델이 된 것은 아니다. B를 기본 설정으로 채택하지 않는다.

## 무엇을 비교했나

A는 기존 제어다. B는 모델의 가까운 미래 목표속도가 0.05m/s보다 클 때 **일반 주행 브레이크만 0**으로 바꿨다. 조향·스로틀 이득·후보 선택·가중치는 그대로이며, 정지 목표·긴급 제동 권한도 유지했다. B에서 이 변경은 서로 다른 추론 67개, 실제 수신 확인된 명령 134개에 적용됐다.

Town07 같은 직진 경로·Prius·ClearNoon·센서 보정·10Hz 6카메라·20Hz 물리 조건이다. 준비와 전문가 출발 후 모델이 제어했다. 각 팔은 **총 20초 기록**이며 준비/전문가 구간을 포함한다. 약210m 경로의 완주 시험이나 30km/h 시험이 아니다. A→B 각1회인 탐색 비교이며 ABBA 반복 시험이 아니다.

## 왜 아직 모델 개선 완료가 아닌가

**1. 작은 제동의 영향이 의심되는 구간을 찾았다.** A의 첫 정지 직전 목표속도는0.863m/s로 양수였고, 수신된 제동은0.001977이었다. 이후50ms에 실제 속도가0.866→0.001m/s로 떨어졌다. 큰 정지 유지 제동과 near-zero 목표는 그 뒤에 나왔다. 최악의 다른 급감속도 양수 목표1.448m/s와 일반 제동0.071616에서 발생했다. B는 이번 관측에서 같은 종류의 급감속이 없었다. 다만 반복·동일 내부 물리 상태가 보장되지 않아 제동 단독 원인 확정은 아니다.

**2. 모델의 저속화는 남아 있다.** B의 마지막 목표속도는0.1296m/s까지 낮아졌다. 실제 속도가 목표보다 높아 스로틀은0이었고, 일반 제동을 지워도 차는 관성 주행하며 느려졌다. B의0.3초 참조에서는 near-zero 목표가 없었지만 전체 예측 미래에 속도0인 점이 포함된 선택 궤적은62/183개였다. “모델의 zero-speed 문제를 없앴다”고 말할 수 없다.

**3. 경로 위치와 속도 예측의 불일치도 남아 있다.** 별도9개 수학 기준으로 선택 궤적을 검사하면 A111/183개, B110/183개가 한 가지 이상 위반했다. 예측 점 간 속도·곡률·횡가속도 등이 문제다. 현재 runtime gate 통과와 이 별도 전체 미래 검사는 같은 검사가 아니다. 이 숫자는 실제 차체가111회 침범했다는 뜻도 아니다. 실제 기록 차체/이동 검사는 두 팔 모두 침범0이다. B도 출발 가속도 예외가 남아 전체 QA 합격이 아니다.

각1회이며 모델 전환 시점의 B−A 차이는 속도+0.03185m/s, 경로 위치+0.00261m, yaw−0.00159rad다. 최초 생성 상태는 같지만 전환 상태·이력·내부 변속/접촉 상태까지 같다고 증명하지 못한다. B의 제동 변경은 이후 입력 영상·차량 상태와 모델 출력도 바꿀 수 있다. 같은 입력에 두 출력을 적용한 오프라인 비교와 구분한다.

## 다음에 실제 성능을 올리기 위해 할 일

1. **제어 확인:** 이번 결과를 근거로 조건을 새로 고정한 반복 비교를 준비한다. 작은 이동 제동을 없애는 안뿐 아니라 목표 정차·회전·속도 유지의 퇴행을 검사한다. 기존20초 한 쌍을 복제해 반복 수를 늘리지 않는다.
2. **자료 확보:** 앞서4km/h 전문가가 통과한10–30m 구간을 별도10Hz6카메라·상태 이력·6.4초 미래 정답으로 수집한다. 저속 유지와 감속 후 재가속, 출발/정차의 적격 자료가 필요하다. 이 모델 실패 출력은 전문가 정답으로 쓰지 않는다.
3. **새 구조 구현/학습:** [재설계의 공간·연속 영상 모델](../../../../portable-e2e-redesign-2026-10-01.md)을 구현하고 위치/속도 일관성·기울기·기존 ABI를 검증한다. 적격 episode/경로 분할 뒤 데이터 효과와 구조 효과를 따로 실제 학습·폐루프로 비교한다. 기존 자료로 짧은 학습만 반복하지 않는다.

현재9개 상위 영역·30개 하위 기능 중 **직진·좌/우회전·종점 정지·목표속도 추종5개를 향한 복구 단계**다. 이번에는 직진에서 급정지/속도 제어를 판별했다. 새 가중치 업데이트0회, 승인0/30, 지도 모델 변경0회다. PRO6000 새 학습을 이 시험에서 시작하지 않았다. 지도는 별도 인식·누적 트랙을 유지한다.

로컬 공간은 마지막 확인에서5,772,140,544B, 약5.38GiB다. 짧은 이번 비교가 가능했다는 것과 본 학습용30episode 수집 공간이 충분하다는 것은 다르다. 기존 추산30–50GB 확보와 원격 개인 폴더 전송 계획이 필요하다. 새 구조 첫 구현/배선은1–3작업일, 30episode 수집/QA도1–3일 이상 예상하며 실측으로 갱신한다. 제안된 새 구조 screening GPU0 예산18시간은 **아직 사용한 학습 시간도 예약도 아니다**. 크레딧 잔액/확정 토큰 사용량은 조회하지 못한다.
