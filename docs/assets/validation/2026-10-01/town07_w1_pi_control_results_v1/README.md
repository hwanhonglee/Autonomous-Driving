# 저속 직진에서 속도 제어를 바꾼 실제 주행 결과

<!-- HH_261001 - Explain one measured cruise improvement without relabelling it as complete feature approval. -->

**차량이 자꾸 멈추던 현상은 이번 짧은 시험에서 개선됐다.** 같은 W1 신경망을 사용하고, 모델이 내놓은 경로와 목표속도를 실제 페달 명령으로 바꾸는 부분만 변경했다. 개선안은 모델이 실제로 제어한 구간에서 약 43.92m를 주행했고 정지 관측이 없었다. 사전에 정한 20초 순항 예비 성능 기준을 통과했다.

이것은 전문가의 수동 주행도, Autoware VAD 주행도 아니다. 기록에 공개된 짧은 전문가 출발 이후 **우리 학습 모델의 경로를 따라 제어한 CARLA 주행**이다. 다만 전체 경로를 완주하지 않았고, 마지막 종료 검사도 실패했다. 따라서 공식 기능 승인이나 실차 운행 성공으로 세지 않는다.

## 무엇을 바꿨는가

기존 제어는 현재속도가 목표속도에 가까워지면 페달을 낮췄다. 개선안의 PI 제어는 그동안 쌓인 속도 오차도 함께 반영한다. 차량을 계속 움직이는 데 필요한 페달을 유지하는 데 도움이 될 수 있다. 이번 결과가 그 가능성을 보여주지만, 모든 지도·속도에서 원인을 확정한 것은 아니다.

신경망 가중치, 원래 12개 경로 후보, 후보 선택, 조향, 정지·비상정지 분기는 그대로 유지했다. 임의의 최소 스로틀을 넣거나 모델 속도를 강제로 바꾸지 않았다. 이번 제어 비교 자체의 학습 업데이트는 **0회**다. 별도로 진행한 V2 모델 학습과 혼동하지 않는다.

## 실제 수치

각 시험은 총 20초를 기록했고, 공개된 출발 뒤 학습 제어의 효과를 관측한 구간은 약 18.25초다. 동일 경로의 각 1회이며 시작 상태가 완전히 같지 않다.

| 확인 항목 | 기존 제어 | PI 제어 |
| --- | ---: | ---: |
| 학습 제어 구간 진행거리 | 23.64m | **43.92m** |
| 마지막 전진 속도 | 1.14m/s | **2.50m/s 약 9km/h** |
| 정지에 가까운 관측 | 41개 | **0개** |
| 중심 경로 오차 p95 | 0.030m | 0.116m |
| 최대 중심 경로 오차 | 0.032m | 0.122m |
| 충돌과 차선 이벤트 | 0개 | 0개 |
| 실제 차체와 이동 영역의 10cm 안전 영역 침범 | 0개 | 0개 |
| 실제 신경망 계산 | 183회 | 183회 |
| 학습 제어 명령 수신 확인 | 366개 | 366개 |
| 20초 순항 예비 기준 | 진행거리 부족 | **통과** |

차량 중심 경로 오차는 PI 쪽이 커졌지만 사전 기준인 p95 0.35m·최대 0.75m 안이다. 실제 차체 400개와 두 관측 사이의 이동 영역 399개도 모두 검사했다. PI 쪽의 최소 여유는 차선에서 10cm를 제외한 뒤에도 약 0.346m였다.

명령 366개 중 다음 관측으로 효과를 대조할 수 있는 것은 365개다. 마지막 명령 뒤에는 추가 관측이 없으므로 이를 만들어 넣지 않았다. 신경망과 제어 계산은 최대 약 39.1ms였지만, 카메라 수신부터 명령 수신 확인까지의 전체 10Hz 지연을 증명하는 값은 아니다.

## 아직 해결했다고 말할 수 없는 것

PI 시험의 종료 직후 원래 포트 검사에서 `Address already in use`가 나왔다. 원래 실패 결과는 보존했고 별도 후속 확인과 더 긴 자연 해제 대기를 준비했다. 주행 수치가 개선됐다고 이 실패를 지우지 않는다.

현재 모델은 일부 예측 경로의 위치와 속도 일관성에도 문제가 남아 있다. 이번 차체 검사 통과가 모든 예측 후보의 품질 통과를 의미하지 않는다. 30km/h, 회전, 목표 정차, 독립 지도, 장애물 대응은 이번 시험의 검증 범위가 아니다. 9개 영역·30개 하위 기능의 공식 승인 수는 여전히 **0/30**이다.

다음은 조건을 미리 정한 **45초 직진 3회 반복**이다. 동시에 별도 V2 모델의 실제 미래 궤적 공동 학습을 완료하고, 그 모델도 실제 센서 이력과 차량 제어에 연결해 확인한다. 반복 실패도 분모에서 빼지 않는다.
