# 주행 모델 개선 — 대기 정답을 분리하니 다시 움직임

<!-- HH_261001 - Report measured improvement without treating a short TRAIN-route run as feature approval. -->

**개선은 있었습니다. 하지만 아직 잘 달리는 모델로 승인할 단계는 아닙니다.**

같은 20초·Town07 직진·9km/h 상한 시험에서, 기존 방식으로 학습한 W0는
4.23m 뒤 멈췄고, 강제 대기 정답을 분리한 W1은 29.76m 진행했습니다.
W1도 중간에 속도가 떨어지고 잠시 정지했습니다. 마지막에 다시 달렸다는
뜻이지, 20초 내내 매끄럽게 달렸다는 뜻은 아닙니다.

## 무엇을 학습에서 바꿨나

차량을 외부 코드가 억지로 대기시키는 준비 구간과, 차량이 스스로 멈춰야 하는
상황은 다릅니다. 이전 데이터는 둘 다 주행 정답으로 사용했습니다.
이번 W1은 원본과 이력을 삭제하지 않고, 확인된 **준비 구간 105개 정답의
학습 손실만 제외**했습니다. 기존 관측 정지/유지 정답 200개는 그대로 뒀습니다.
이 200개 중 50개의 미래 구간은 수집 종료용 강제 정지 구간과 겹칩니다.
따라서 모두 교통신호나 정상 목적지 정지를 학습한 자료라고 해석하지 않습니다.

두 모델 모두 같은 AH 가중치에서 시작하여 전체 모델을 학습했습니다.
구조·제어기·정답 궤적·손실 종류는 바꾸지 않았습니다. 각각 3,000개 배치를
예약했으며, 모두 준비 구간인 한 배치를 양쪽에서 동일하게 제외해 실제
가중치 업데이트는 **2,999회씩**입니다. 순수 학습 시간은 합계 약 13분 7초입니다.

ADE/FDE/속도 오차는 4.17m / 11.36m / 1.69m/s입니다. 준비 구간 정답 수정이
모든 문제를 해결한 것은 아니며, 후보를 자동 승격하지 않았습니다.

## 추가 150초 시험 — 200m까지 갔지만 마지막 9.77m는 실패

<!-- HH_261001 - Preserve the longer-run failure and distinguish raw lane containment from inset certification. -->

이것은 새로운 A/B가 아니라 같은 W1의 더 긴 단일 시험입니다. 원래 20초
결과를 덮어쓰지 않았고, 물리적 초기 상태/진행 궤적이 완전히 같지는 않습니다.

| 검사 | 결과 |
| --- | --- |
| 전체 경로 / 실제 순 진행 | 210.60m / **200.51m** |
| 최종 남은 경로 | **9.77m**, 목표 도달 실패 |
| 모델 제어 / 외부 출발 / 비상 개입 명령 | 2,966 / 11 / 0 |
| 추론 / 실제 6카메라 묶음 | 1,483 / 1,500 |
| 모델 제어 중 속력 0.5m/s 이하 | 52.75초, 마지막 연속 39.25초 포함 |
| 최대 경로 중심 오차 | 0.468m |
| 충돌 / 차선 센서 이벤트 | 0 / 0 |
| 실제 기록 위치의 차체 / 보수적 위치 사이 외곽 | 원래 차로 밖 면적 0 / 0 |
| 차선에서 10cm 여유 | 기록 위치는 통과, 보수적 위치 사이 검사 17구간 **미달** |

마지막 ‘속력 0.05m/s 이하 연속 시간’은 0.15초에 불과하지만, 미세 속도 진동으로
조건이 끊긴 숫자입니다. 실제 진행은 약 111초 이후 멈췄습니다. 좋은 숫자만
사용하지 않으며, 마지막 39.25초의 저속 상태와 9.77m 미완주를 실패로 남깁니다.
10cm 여유 검사의 최저 보수적 여유는 7.81cm입니다. 실제 침범이 관찰되었다는
뜻은 아니지만, 요구한 안전 여유를 보장하지 못한 것입니다.

원래 TRAIN 전문가 기록은 경로 끝 210.60m까지 도달했습니다. 이번 조기 정지가
정답의 정상 종점과 일치한다고 해석할 수 없습니다. 종점 가까이에서 모델은
가까운 미래 속도 0, 먼 미래 가속을 반복 예측했고, 외부 전문가는 계속 전진을
제안했습니다. 단순 카메라 지연으로 모델 제어가 끊긴 경우와 구별됩니다.

## 이어진 학습 — 횟수만 늘리면 해결되나?

W2는 같은 학습을 4배, **11,996회 업데이트**까지 진행했습니다. 첫 2,999회
가중치가 W1과 정확히 일치하는 것도 확인했습니다. 정지/유지 학습 표본의
정답 후보 일치는 179/200→188/200으로 높아졌지만, 별도 알려진 검증 경로의
오차 9개는 모두 커졌습니다. 그래서 W2를 더 좋은 주행 모델로 채택하지 않습니다.

보관된 W1 주행 입력 149개를 넣으면, 가까운 미래 속도 0 선택은 40→14개로
줄었습니다. 그러나 이는 주로 후보 선택 변화이고 **W2가 실제로 다시 달렸다는
시험은 아직 아닙니다.** 기존 오차의 악화와 이 제한적인 변화 둘 다 남깁니다.
