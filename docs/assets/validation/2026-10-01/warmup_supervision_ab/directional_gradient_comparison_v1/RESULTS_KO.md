# 재출발 학습 수정 — 개선은 확인, 실제 주행 합격은 아직

<!-- HH_261001 - Lead with measured gains and regressions, separating offline predictions from actual driving. -->

> **후속 실제 주행 결과:** 이 문서의 A/B는 오프라인 평가 시점 기록이다. 이후
> [Town07 실제 20초 A/B](../../selector_phase_ab/directional_live_pair_v1/README.md)를
> 각각 완료했다. B의 순진행은 A보다 0.30m 짧고 첫 실측 정지도 0.20초 빨랐다.
> 따라서 아래 오프라인 개선을 실제 재출발 성능 개선으로 해석하거나 B를 승격하지 않는다.

**이번에는 개선이 있었습니다.** 같은 데이터·같은 학습 횟수에서 학습 중의
속도 0 경계 처리만 바꿨고, 알려진 검증 경로의 오차 9개 중 8개가 줄었습니다.
다만 우회전 합격 기준에는 여전히 못 미칩니다. 새 B 모델을 실제로 주행시킨
결과는 아직 없으므로 기존 모델 대신 채택하지 않았습니다.

## 얼마나 좋아졌나

| 같은 조건에서 비교한 항목 | 기존 방식 A | 수정 방식 B |
| --- | ---: | ---: |
| 우회전 평균 위치 오차 — 작을수록 좋음 | 4.17m | **3.76m** |
| 우회전 마지막 위치 오차 | 11.36m | **11.16m** |
| 직진 평균 위치 오차 | 0.320m | **0.228m** |
| 직진 마지막 위치 오차 | **0.426m** | 0.597m — 악화 |
| 같은 보관 입력149개에서 가까운 미래 속도0 예측 | 40개 | **6개** |
| 제어기가 정지로 취급하는 0.05m/s 이하 예측 | 40개 | **8개** |

마지막 두 줄은 **실제 정지 횟수가 아니라 같은 과거 입력에 대한 예측**입니다.
반복·상관된 입력이므로 149번 독립 주행한 것도 아닙니다. 모델이 다시 달리려는
출력을 더 자주 만든다는 근거는 되지만, 실제로 완주하거나 안전하게 회전했다는
뜻은 아닙니다.

## 나빠진 부분도 남아 있다

- 직진의 마지막 위치 오차가 커졌습니다.
- 출발 학습 표본18개의 초기 속도 오차도 0.249→0.252m/s로 조금 커졌습니다.
- 주행 초반의 보관 입력 하나에서는 기존 0.572m/s 전진 예측이 **0으로 바뀌어
  제동을 제안**했습니다. 따라서 전체 정지 예측이 줄었다고 모든 장면이 좋아진
  것은 아닙니다.
- 기존 절대 품질 검사는 양쪽 모두 6/9입니다. 이 수치는 **자율주행 기능
  6개 합격**이라는 뜻이 아닙니다. 기능별 승인 수는 여전히0/30입니다.

## 실제로 한 작업과 바로 다음

두 모델 모두 같은 AH 가중치에서 시작해 **2,999회씩 실제 업데이트**했습니다.
순수 학습은 합계13분35초입니다. 비교군 A가 기존 W1 가중치와 완전히 일치하는지
확인했고, 추론 모델 구조·기존 제어기·속도 상한·안전 기준은 바꾸지 않았습니다.

다음은 같은 Town07·9km/h 상한·20초에서 **A와 B를 각각 실제로 제어**하는
비교입니다. 진행 거리뿐 아니라 초반 제동, 재출발, 정지 시간, 차체 여유까지
확인해야 합니다. 새 촬영은 로컬 공간 조건 때문에 보류 중이고, 이전 입력 원본의
검증된 서버 백업까지 준비했습니다. 원본 삭제나 안전 기준 완화로 우회하지 않습니다.

그다음에는 부족한 유효 저속 순항 데이터를 보강합니다. 새 기능 헤드나 더 많은
학습 횟수만으로 현재 문제가 해결됐다고 처리하지 않습니다.
