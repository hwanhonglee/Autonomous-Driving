# 속도 제한만 바꾸면 해결될까? — 거리는 늘었지만 반복 정지는 남음

<!-- HH_261001 - Separate a speed-cap setting from actual attained speed and learned functional success. -->

같은 W1 모델로 20초씩 비교했습니다. 두 시험 모두 외부 전문가의 목표 속도는
30km/h이며, 모델 추종기의 상한만 9 또는 30km/h입니다. 원래 시험의 전문가
목표는 9km/h였으므로, 그 결과를 이번 비교의 기준값으로 섞지 않았습니다.

| 실제 측정 | 9km/h 상한 C9 | 30km/h 상한 C30 |
| --- | ---: | ---: |
| 진행 거리 | 24.97m | 33.40m |
| 실제 최고 속도 | 8.39km/h | **14.38km/h** |
| 모델 제어 중 속력 0.5m/s 이하 | 3.65초 | 4.05초 |
| 마지막 연속 속력 0.5m/s 이하 | 0초 | 1.25초 |
| 최대 경로 중심 오차 | 0.087m | 0.153m |
| 실제 모델 ACK / 비상 개입 | 366 / 0 | 366 / 0 |
| 충돌 / 차선 센서 이벤트 | 0 / 0 | 0 / 0 |
| 10cm 차체·보수적 위치 사이 여유 검사 | 통과 | 통과 |

**30km/h 주행 성공이 아닙니다.** 상한은 30이지만 모델이 낸 속도와 실제 도달
속도는 그보다 낮았고, 두 시험 모두 반복 감속·정지가 남았습니다. 상한만 풀어
해결할 수 있다는 근거는 얻지 못했습니다. 더 긴 거리·다른 맵·회전 검증도 아닙니다.

각 조건에서 400개 상태·200개 6카메라 묶음·183개 모델 추론을 보존했습니다.
두 조건은 모델/원본 소스/경로/수집 설정/제어기 계수가 같으며 상한만 다름을
[검증 결과](pair_report.json)에 기록했습니다. 신체 외곽 검사는 기록 시점과
보수적으로 계산한 위치 사이 외곽에 대한 것이며 연속 실제 움직임 전체의 증명은 아닙니다.
