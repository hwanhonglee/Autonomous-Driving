# 지도 인식 추가 학습: 오검출은 줄었지만 표지 누락이 늘어 미채택

<!-- HH_261002 - Publish the completed fixed-endpoint GPU0 sampler comparison with the failed recall guard and unchanged feature counts. -->

서버 **물리 GPU 0**에서 두 모델을 각각 **추가 4,000회 학습하고 평가까지 완료**했다. 현재 이 작업은 실행 중이 아니다. 배경을 표지로 잘못 읽는 픽셀은 줄었지만, 진짜 표지를 놓치는 비율도 늘어 새 모델을 교체하지 않는다. 전체 비교 조건은 **19/20 통과, 종합 FAIL**이다.

이것은 RGB에서 도로·차선·표지 등 7개 종류를 구분하는 지도 인식 모델이다. 신호 상태, 세계 좌표, 차선 연결 관계, 온라인·주행 기록 누적을 포함한 자동 정밀지도 생성 완료가 아니다. 주행 기능 승인도 **메인 0/9·하위 0/30**을 유지한다.

## 무엇을 비교했나

두 모델 모두 기존 10,000회 학습한 같은 대조군 가중치에서 시작했다. 네트워크 245,831개 파라미터, 손실, 학습률, 고정 crop과 TRAIN 1,209개는 같다. 각 모델은 새 AdamW로 4,000회·32,000회 자료 노출을 수행했으며 최종 누적 계보는 14,000회다. 노출 횟수는 독립적인 주행이나 새 데이터 개수가 아니다.

| 모델 | 한 batch의 8개 자료 구성 | 추가 학습 시간 |
| --- | --- | ---: |
| 일반 복습 대조군 | 전체 TRAIN에서 8개 | 약 272초 |
| 오인식 배경 중심 후보 | 전체 4개 + 작은 표지 1개 + 큰 표지 1개 + 오인식 배경 2개 | 약 270초 |

오인식 배경은 **TRAIN에서만** 기존 모델의 실제 예측과 정답을 비교해 정했다. 작은 표지 391개·큰 표지 193개·오인식 배경 145개를 사용하며 전체 TRAIN도 빠짐없이 복습한다. 표지가 crop에 남도록 다시 뽑거나 정답을 바꾸지 않았다. DEV·holdout은 optimizer에 넣지 않았다.

두 고정 최종 모델을 저장한 뒤 기존 평가 Town01 118장·Town02 232장, 총 350장 전체를 비교했다. 이미 사용한 평가 지역이므로 새 독립 지역 검증은 아니다.

## 실제 개선과 퇴행

| 기존 Town01 평가의 표지 지표 | 시작 모델 | 일반 복습 | 오인식 배경 중심 |
| --- | ---: | ---: | ---: |
| Precision: 표지라고 읽은 픽셀 중 실제 표지 비율 | 6.682% | 6.191% | **7.164%** |
| Recall: 실제 표지 픽셀을 찾아낸 비율 | 63.808% | 60.480% | **59.657%** |
| 배경을 표지로 잘못 읽은 픽셀 | 25,548 | 26,283 | **22,311** |
| 표지 IoU | 6.438% | 5.951% | 6.833% |

후보의 배경 오인식은 시작 모델보다 약 **12.7% 감소**했다. 그러나 recall은 **4.151%p 하락**해 사전에 선언한 최대 2%p 하락 기준을 넘었다. 높은 precision도 여전히 약 7%여서 충분한 표지 인식이라고 볼 수 없다.

Town02 표지 IoU는 시작 모델 75.321% → 일반 복습 71.473% → 후보 74.955%다. 후보는 시작 모델 대비 0.367%p 하락으로 1%p 보존 기준을 만족했다. 두 지역의 도로·차선·신호등 인식 보존도 통과했지만, 표지 누락 문제를 상쇄하지 않는다.

## 검산과 다음 개선

원격 결과 43개 파일·약 23.9MB를 새 로컬 결과 폴더로 복사하고 **모든 SHA 일치**를 확인했다. 독립 검토에서도 3모델 × 2지역의 7×7 혼동행렬 전체와 20개 판정이 원 결과와 일치했다. 기존 가중치·실패 결과·데이터는 덮거나 삭제하지 않았다.

현재 후보는 작은 표지를 평균 약 23.46회 노출하는 반면 일반 복습은 약 26.47회 노출한다. 배경 복습을 늘렸다고 작은 표지 복습까지 늘어난 것은 아니다. 다음 후보는 **전체 4 + 작은 표지 2 + 큰 표지 1 + 오인식 배경 1**로 표지 복습을 보강하는 비교를 준비한다. 이것은 이번 recall 하락 원인의 증명도, 다음 성능 향상의 보장도 아니다. 기존 20개 비교 기준을 유지하며 이미 본 평가 지역에 맞춘 연구라는 한계를 공개한다.
