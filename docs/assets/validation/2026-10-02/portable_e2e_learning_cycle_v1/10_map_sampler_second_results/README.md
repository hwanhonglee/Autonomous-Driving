# 지도 추가 학습의 표지 인식 결과와 다음 교정

작은 표지 영상의 복습을 늘려 두 모델을 각각 추가 4,000회 학습하고 평가했다. Town02에서는 개선됐지만 Town01에서는 더 많은 표지를 놓쳤다. 새 후보는 **15/20 통과·종합 FAIL, 미채택**이며 GPU 학습은 종료 상태다. 다음은 실제 학습 crop에 표지 정답이 남았는지 확인하는 CPU 검사다.

PRO6000 물리 GPU 0·기존 개인 `venvs/py312`만 사용했다. 같은 10,000회 시작 모델에서 각 4,000회·32,000개 노출을 수행했다. 앞선 실패 후보에서 이어 학습한 것이 아니다. 두 팔의 학습 시간은 270.8초·269.1초, 합계 약 9분이다. 네트워크 245,831개 파라미터·손실·학습률·crop 순서·FALSE 영상 조건은 같다.

## 실제 개선과 퇴행

일반 복습은 전체 TRAIN에서 8개, 앞선 후보는 전체 4 + 작은 표지 1 + 큰 표지 1 + 오인식 배경 2였다. 이번 후보는 전체 4 + 작은 표지 2 + 큰 표지 1 + 오인식 배경 1이다. TRAIN 1,209개를 사용하며 DEV·holdout은 optimizer에 넣지 않았다. 두 최종 모델 저장 후 기존 Town01 118장·Town02 232장 전체를 평가했다.

| Town01 표지 지표 | 시작 모델 | 일반 복습 | 앞선 배경 중심 | 이번 작은 표지 중심 |
| --- | ---: | ---: | ---: | ---: |
| Precision | 6.682% | 6.191% | 7.164% | 5.403% |
| Recall | 63.808% | 60.480% | 59.657% | 51.424% |
| IoU | 6.438% | 5.951% | 6.833% | 5.141% |
| 배경을 표지로 잘못 읽은 픽셀 | 25,548 | 26,283 | 22,311 | 26,033 |

Precision은 표지라고 읽은 픽셀 중 진짜 표지 비율, recall은 실제 표지를 찾아낸 비율, IoU는 정답과 예측의 겹침 정도다. 이번 recall은 시작 모델보다 **12.384%p 하락**했다. Town02 표지 IoU의 75.321→76.191% 개선으로 Town01 퇴행을 상쇄하지 않는다. 실패 5개는 Town01 precision·recall의 시작 모델 및 대조군 비교 4개와 시작 모델 대비 배경 오인식 감소 1개다.

두 실험의 일반 복습 대조군은 전체 숫자 가중치·학습 노출·두 지역 저장 예측이 정확히 재현됐다. 비교 도중 기준 모델이 바뀐 결과는 아니다. 하지만 복습 비율이 퇴행을 일으킨 세부 원인은 아직 확정하지 않았다.

## 다음 학습 전에 확인할 것

작은 표지가 있는 장면의 노출은 9,160→13,160개로 늘었다. 그러나 그 장면을 자른 crop에도 표지가 남았다는 뜻은 아니다. 네 개 실제 학습군의 32,000개씩, 총 128,000개 노출에서 crop 후 표지 픽셀을 세고 원본 지역별로 비교한다. 실제 학습 환경과 같은 현재 원격 개인 venv에서 CPU로 검사하며 자료·crop·정답은 바꾸지 않는다. 아직 crop이 원인이라고 단정하지 않는다.

그 결과로 표지 노출을 교정할지, 영상 문맥을 더 보는 구조와 추가 장면이 필요한지 결정한다. 원인 없이 복습 비율만 다시 바꾸는 학습은 보류한다. 이미 본 평가 지역에 맞춘 탐색이며 신규 독립 장소는 0개다. 7분류 인식은 자동 정밀지도 완료가 아니고, 주행 정식 검증도 메인 0/9·하위 0/30을 유지한다.
