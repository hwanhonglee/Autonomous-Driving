# 목적지 정차가 학습 가능한 궤적인지 검사한 결과

<!-- HH_261002 - Separate physical stopping, causal terminal delivery, necessary decoder bounds, and unchanged source denials. -->

교사 차량은 목적지 약 1m 앞에서 멈췄다. 하지만 **모델에 바로 학습시킬 자료는 아니다.** 준비된 정차 표현의 필요 조건은 적용 가능한 672개 시점 중 669개를 통과했고, 정지 직전 3개는 미달했다. 기존 원자료의 미래 궤적 실패 149개와 조향 요청 불일치도 남아 학습 금지를 유지한다.

이번 작업은 로컬 CPU로 실제 기록을 검사한 것이다. 학습·새 CARLA 실행·신경망 자율 정차 시험이 아니다. 주행 정식 완료는 메인 0/9·하위 0/30이다.

## 네 가지 결과를 구분해서 보기

| 확인한 것 | 실제 결과 | 의미 |
| --- | --- | --- |
| 교사 차량 정지 | 속도 0 이후 정차와 130개 후속 상태에서 정지 유지 | 교사가 멈춤. 모델 정차 성공은 아님. |
| 원자료 품질 | 조향 요청 일치 실패·미래 궤적 149개 시점 실패 | 현재 자료는 학습 금지. |
| 현재 종점 정보 전달 | 선택된 카메라 1,665개 시점 연속 검사에서 거부 없음 | 현재 위치와 원래 경로로 종점 전달 가능. 실행기 연결은 미완료. |
| 정차 표현의 필요 조건 | 적용 가능한 672개 중 669개 통과·3개 HOLD 미달 | 전체 궤적 생성 성공은 아님. 정지 직전 표현 교정 필요. |

전체 1,665개 시점·106,560개 미래 점을 보존했다. 617개는 정차 분기의 적용 대상이 아니고, 376개는 실제 정지점이 현재 제공 경로 범위 밖이다. 이 993개를 물리적 정지 실패로 세지 않는다. 적용 가능한 672개와 원자료 품질 실패 149개는 서로 다른 판단이다.

## 실제 위치와 속도에 남은 불일치

한 HOLD 시점은 아주 작은 재가속으로 비가속 조건을 만족하지 못했다. 두 시점은 기록된 속도로 계산한 첫 100ms 이동 거리가 실제 정지까지 남은 이동 거리보다 컸다. 속도나 위치를 임의로 0으로 만들지 않는다.

첫 HOLD 상태는 선택된 카메라 시점보다 앞선 20Hz 상태다. 이때 실제 위치를 따라 정지까지 누적한 거리는 약 **0.448mm**, 현재 디코더의 첫 100ms 표현은 약 **1.958mm**다. 카메라 시점 검사에 포함되지 않은 이 첫 상태도 따로 확인했다. 계측·시간·표현 정의를 더 확인해야 한다는 증거이지 CARLA 내부 물리 원인의 확정은 아니다.

카메라 시점의 현재 경로 위치는 두 번 아주 작게 감소했지만 기존 허용 범위 안이었다. 20Hz 전체 3,564개 상태에서는 감소가 10번, 그중 5번은 기존 허용 범위를 넘었다. 최대 감소는 0.305mm다. 저장된 단조 증가 진행값으로 실제 위치의 감소를 숨기지 않았다.

## 다음 개선과 학습 순서

같은 경로의 마지막 직선 감속·정차 구간에서 미세한 정상 조향을 제거하는 새 비교를 준비한다. 원래 전체 경로는 완전한 직선이 아니므로 출발·주행의 조향은 유지한다. 목표·속도·제동·안전 기준과 실패 기록을 바꾸지 않는다. 개선 여부는 새 실제 기록 전량으로 판단한다.

동시에 첫 100ms와 실제 종점 도착을 표현하는 디코더를 교정한다. 경로 범위는 원래 목적지·현재 관측만으로 제공하고, 미래 정지 거리는 정답으로만 사용한다. 정상 정답 확보 → 전체 궤적 표현 가능성 → 기존 직진·회전과 정차 혼합 학습 → 모델의 실제 목표 정차 순서다. 실패 구간 삭제·정지 곡률 0 조작·기준 완화는 하지 않는다.
