# 지도 모델이 실제로 본 표지 정답: 전량 검사 결과

<!-- HH_261002 - Explain the complete effective-target census, its limitations and the next loss-only hypothesis without changing frozen evidence. -->

**작은 표지 복습은 실제 학습 정답에서도 늘었다. 그런데 성능은 좋아지지 않았다.** 작은 표지의 crop·resize 후 정답 픽셀은 **281,972→404,689, 43.52% 증가**했다. 따라서 “추가한 작은 표지가 전부 잘려서 학습되지 않았다”는 설명은 맞지 않는다. 성능 하락의 원인이 확정된 것은 아니며, [두 번째 후보의 15/20 통과·종합 FAIL·미채택](../10_map_sampler_second_results/README.md)은 그대로 유지한다.

## 무엇을 확인했나

완료된 두 실험의 대조군·후보군, 총 **4개 군 × 32,000회 = 128,000회** 실제 학습 노출을 전부 검사했다. 같은 TRAIN 영상을 반복한 횟수이지 새 영상·새 장소 128,000개가 아니다. 기록된 영상 번호와 crop을 그대로 재생해 실제 정답 픽셀을 셌다. 영상·정답·crop·학습 순서는 바꾸지 않았다.

PRO6000 개인 venv의 **CPU 검사 83.48초**로 완료했다. 모델 추론·GPU·가중치 업데이트·DEV/holdout 영상 열기는 없었다. 1,209개 TRAIN 슬롯과 첫 읽기 입력 SHA 171개를 보존하고 전후 일치를 확인했다. 두 실험의 일반 복습 대조군도 같은 결과로 재현됐다.

## 작은 표지는 실제로 얼마나 남았나

| 실제 후보군 학습 노출 | 앞선 배경 중심 후보 | 작은 표지 중심 후보 |
| --- | ---: | ---: |
| 원본에 작은 표지가 있는 영상 노출 | 9,160회 | 13,160회 |
| crop·resize 뒤 작은 표지 정답 픽셀 | 281,972 | **404,689 (+43.52%)** |
| 작은 표지가 crop에서 완전히 사라진 노출 | 522회 / 5.70% | 732회 / 5.56% |
| 큰 표지 정답 픽셀 | 2,812,255 | 2,812,570 |
| 모든 표지 정답 픽셀 | 3,094,227 | 3,217,259 (+3.98%) |

추가한 작은 표지 픽셀은 대부분 남았다. 다만 새 후보에서도 **큰 표지가 전체 표지 픽셀의 87.42%**를 차지한다. 픽셀 수가 많은 큰 표지와 작은 표지 영상이 손실함수에 같은 방식으로 기여하는지도 따로 봐야 한다. 이 수치만으로 퇴행의 원인이나 개선 효과를 증명하지 않는다.

## 어떤 지역의 정답이 많았나

| TRAIN 원본 그룹 | 원본 슬롯 | 표지가 있는 슬롯 | 작은 표지 중심 후보의 실제 표지 픽셀 |
| --- | ---: | ---: | ---: |
| 기존 Town01 | 497 | 273 | 2,516,964 |
| 기존 Town02 | 232 | 232 | 623,533 |
| 추가 Town01 p02 FALSE | 240 | 51 | 50,123 |
| 추가 Town01 p04 FALSE | 240 | 28 | 26,639 |

p02·p04의 표지 있는 영상은 각각 20.14%·21.80%의 노출에서 crop이 표지를 완전히 제외했다. 이 두 그룹의 실제 표지 픽셀은 합쳐 전체의 2.39%다. **추가 장면 480개를 넣었다는 것과 작은 표지 정답 기여가 충분하다는 것은 다르다.** 이번 전량 검사에서 crop에는 표지가 남았지만 resize 때문에 추가로 0픽셀이 된 사례는 네 군 모두 0회였다.

작은 표지·큰 표지·오인식 배경 세 원본 집합은 서로 겹치지 않으며 합계 729슬롯이다. 나머지 일반 배경 480슬롯도 버리지 않았다. 지역별 집계와 표지 크기별 집계는 같은 노출을 다른 관점으로 센 것이므로 서로 더해 새 자료 수로 세지 않는다.

## 이제 무엇을 바꾸려 하나

현재 모델은 RGB에서 도로·차선·표지 등 **기존 7분류**를 예측한다. 손실은 클래스 가중치를 적용한 픽셀 평균이다. 새 후보의 표지 픽셀은 전체 정답 픽셀의 약 **0.04364%**, 고정 클래스 가중치를 곱한 전체 픽셀 질량의 약 **0.6501%**다. 뒤 수치는 전 노출 합계이며 실제 배치별 손실이나 gradient 비율을 뜻하지 않는다.

다음은 **복습 순서·영상·crop·모델을 같게 두고 손실함수 한 가지만 바꾸는 비교 코드 준비**다. 기존 7분류 손실은 유지하고, 실제 표지 정답을 영상·원본 그룹별로 평균해 작은 표지의 기여와 배경 오인식을 함께 다루는 보조 손실을 검토한다. 실제 물체 ID가 없으므로 물체마다 균등 학습했다고 부르지 않는다. 코드는 아직 학습 결과가 아니며, **이 검사 이후 새 GPU 학습은 실행하지 않았다.**

양쪽 최종 결과에서 기존 7분류 전체와 Town01 표지 precision·recall·IoU, 배경 오인식을 함께 비교한다. 이미 본 평가 350장에 따른 탐색이지 신규 독립 장소 검증은 아니다. 7분류 인식은 정밀지도 자동 생성 완료가 아니며, 정식 주행 기능 **메인 0/9·하위 0/30**도 바뀌지 않는다.
