# 정차 제어는 해결했고, 학습 궤적은 아직 미달입니다

<!-- HH_261002 - Explain the actual V7 control improvement and retained future-quality failure without editing publication or raw evidence. -->

**차량은 잘 멈췄습니다. 하지만 이 자료로 모델을 학습할 단계는 아닙니다.** 정상 감속·정차 중 조향을 0으로 바꾸자 이전 요청 조향과 실제 적용값의 불일치는 해결됐습니다. 교사 주행의 기존 16개 검사는 모두 통과했습니다. 이후 실제 미래 궤적 검사에서 158개 창이 미달해 자료는 학습에 넣지 않습니다.

| 확인한 것 | 실제 결과 | 뜻 |
| --- | --- | --- |
| 목적지 정차 | 약 210m 주행, 목표 0.999m 앞에서 정차, 이후 정확한 속도 0을 **8.05초** 기록 | 교사는 실제로 멈춤 |
| 정상 제어 적용 | 3,410개 정상 명령, 감속 570회·정차 유지 40회, 엄격한 ACK 검사 통과 | v6의 조향 불일치 해결 |
| 전체 가감속 | −1.981~+2.474m/s², 기존 ±2.9 기준 위반 0회 | 출발·정차·후속 기록까지 확인 |
| 충돌·침범·차체 여유 | 기존 검사 통과, 10cm 여유 유지 | 짧은 좋은 구간만 선택하지 않음 |
| 실제 미래 궤적 | 1,665개 창·106,560개 점 전부 검사, **158개 창 미달** | 저속 궤적 품질은 미해결 |
| 모델 학습·기능 승인 | 이 자료의 학습 0회, 메인 **0/9**, 하위 **0/30** | 신경망 정차 성공이 아님 |

원본은 20Hz 상태 3,564개·10Hz 6카메라 묶음 1,782개·ACK 3,568개·JPEG 10,692개입니다. 선언한 정차 유지 조건은 **속도 0.05m/s 이하로 2초**이며, 이 구간 진입부터 계속 정확한 0이었다는 뜻은 아닙니다. 처음 HOLD 속도는 0.039195m/s이고 0.45초 뒤 정확한 0에 도달했습니다. 정차 유지 구간의 마지막 1.55초와 뒤의 6.5초, 총 8.05초가 모두 정확한 속도 0입니다. 후속 130개 상태도 보존했습니다. 소유 프로세스 종료와 전용 TCP/UDP 포트 해제를 확인했습니다.

## 다음 순서

v6의 149개 궤적 미달 창보다 v7의 158개가 좋아졌다고 주장하지 않습니다. 정차 제어와 궤적 품질은 서로 다른 문제였습니다. 다음은 실제 위반을 겹친 창 수가 아니라 원래 프레임쌍으로 구분하고, 저속 위치 변화·속도 기록·종점 표현의 일관성을 확인하는 것입니다. 같은 교사 시험을 무작정 반복하거나 곡률을 0으로 바꿔 통과시키지 않습니다.

정상 자료가 검증되면 목적지 인식 궤적 표현과 기존 모델의 정차 출력을 연결하고, 기존 직진·회전 자료와 함께 PRO6000 GPU0에서 학습합니다. 로컬 CARLA의 실제 모델 주행으로 퇴행을 확인한 뒤 다른 경로와 30km/h로 확대합니다. 지도 모델의 손실 교정·A/B 학습은 별도로 이어갑니다.
