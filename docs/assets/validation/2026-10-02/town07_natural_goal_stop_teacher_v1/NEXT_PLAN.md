| 설정 | 완료된 실패 기준 | 새 제안 |
|---|---:|---:|
| 정상 brake cap | 0.10 | 0.01 |
| 경로 거리 기반 목표 감속 | 1.5 m/s² | 0.2 m/s² |
| 순항 / 목표 버퍼 / 목표 오차 | 2.4 m/s / 0.75 m / 1 m | 동일 |
| 실제 정지 / 유지 / 후속 문맥 | 0.05 m/s / 2초 / 6.5초 | 동일 |
| 실제 물리 ±2.9 및 runtime +3/−6 | 검사 | 동일, 완화하지 않음 |

2.4 m/s에서 새 목표 감속 식은 목표 버퍼를 포함해 약 **15.15 m** 남았을 때 감속 목표가
내려가기 시작합니다. 기존은 약 2.67 m입니다. 이는 기존 `GoalStopGovernor` 식
`sqrt(2*a*max(remaining-.75,0))`의 **설정 계산**이지 실제 차량 제동 거리의 보증이 아닙니다.
작은 브레이크의 실제 감속이 부족하면 지나칠 수 있고, 저속 급정지가 여전히 나타날 수도 있습니다.
과거 고정 brake 0.02에서도 실패했으므로 새 0.01은 실제 계측이 필요한 미검증 값입니다.

최소 구현은 기존 governor를 다시 쓰고 **설정 두 개만 새 버전으로 명시**합니다.
새 `town07_natural_goal_stop_task_v2_20261002.py`,
`collect_town07_natural_goal_stop_v2_20261002.py`,
`run_owned_town07_natural_goal_stop_v2_20261002.py`에서 기존 v1 바이트를 수정하지 않고
새 schema/profile/출력 경로를 사용하고, 비교를 위해 기존과 동일한 seed를 유지합니다. 일반 planner 제안은 새 정상 brake cap까지
제한하되 원 BasicAgent 위험 대응의 최종 emergency return은 바꾸지 않습니다.
actual float32 cap readback은 정확한 roundtrip 상한으로 검사하고 관측값은 보정하지 않습니다.

동일 Town07 경로·날씨·카메라·수동 1단·초기화·20/10 Hz·소유 ACK·차체 여유·140초 상한을
유지합니다. 이는 **두 설정을 함께 바꾼 교정 비교**이므로 각 설정 하나의 인과 효과를 분리했다고

시간 초과·목표 지나침·정지 미완료·물리 한계 초과는 모두 실패이며 성공 구간만 잘라 학습하지 않습니다.
