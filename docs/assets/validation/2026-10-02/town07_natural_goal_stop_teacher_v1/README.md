## 왜 급정지했나요?

**정지 후 꼬리 구간으로 너무 일찍 넘어가서 브레이크 1을 준 것은 아닙니다.**
아래 급감속은 전부 아직 `driving` 중이고, 실제 제어·다음 제어·ACK의 브레이크는 계속 약 **0.1**입니다.
스로틀은 0, 수동 1단이며 목표 속도를 순항 속도로 덮어쓰지 않았습니다.

전체 2,092개를 살펴본 결과 **주행 1,938개의 현재 적용 브레이크 중 0.101 초과는 0개**입니다.
준비 24개와 정지 후 130개에는 예정대로 brake 1이 있으므로 전체 상태에서 0개라는 뜻은 아닙니다.
마지막 주행 프레임 3717은 실제 40간격/2초 완료·속도 0 뒤 다음 명령으로 brake 1을 요청했고,
첫 정지 후 프레임 3718에서 적용됐습니다. 이것은 3676~3677 급감속의 원인이 아닙니다.

현재 확정할 수 있는 것은 **정상 브레이크 0.1을 계속 적용하던 저속 구간에서 실제 급감속이 났다**는 점입니다.
차량 물리 내부의 어떤 로직이 원인인지는 이 기록만으로 확정하지 않습니다.
과거 고정 brake 0.02~0.12에서도 저속 급감속이 있었으므로, 값만 줄이면 해결된다고 보장하지 않습니다.

원 진단기의 `event-defined membership changed` 오류도 남겼습니다. 원 수집 실패가 결과에
`moving_task_capture_or_cleanup_failed`를 표시했는데 단독 사건 재생은 그 예외 실패 표시를
생성하지 않아서 생긴 **추가 진단 오류**입니다. 이 오류를 고쳐도 원 급감속 FAIL이 PASS가 되지는 않습니다.
동결된 코드나 원본 결과는 변경하지 않았습니다.
