## 보존할 것과 비교할 것

기존 복귀·직진·legacy TRAIN을 복습하면서, 원래 모델이 내던 **곡률과 선호 속도**가 지나치게 변하는 것에 벌점을 준다. 기준 모델은 동결하고 gradient를 전달하지 않는다. 새 좌·우회전 정답도 원래 다섯 영역 학습에 함께 들어간다.

각 영역에서 학습 전에 고른 32개 시점, 총 160개를 시작 모델·대조군·후보에 동일하게 적용한다. 실제 정답 곡률·속도 오차와 움직이는 네 영역의 미래 위치 평균/마지막 오차·속도 오차를 비교한다. **모두 TRAIN 재평가**다. 보존 벌점이 줄더라도 정답 오차나 실제 운전이 나빠지면 채택 근거로 쓰지 않는다.

## 실제 결과 — 복습 효과는 일부 있지만 퇴행은 해결되지 않음

모든 숫자는 실행 전에 고정한 **TRAIN 160개 시점(영역별 32개)의 재평가**다. 독립 주행 평가가 아니다. 평균 위치 오차는 실제 정답 궤적과 비교한 ADE이며 작을수록 좋다.

**판단:** 보존 벌점은 일부 출력 변화와 위치 오차를 줄였지만, 시작 모델의 직진 성능을 보존하지 못했다. 이 후보를 주행에 투입하거나 더 긴 학습으로 자동 확대하지 않았다. 다음 가중치 실험은 곡률·속도·공유 특징의 영역 간 충돌을 먼저 측정하고, 실제 정답과 기존 주행 회귀 조건을 함께 지키는 구조 또는 학습 분리를 검토해야 한다. 이번 결과만으로 최적 벌점 계수나 새로운 구조를 결정하지 않는다.

서버의 전체 45개 결과 파일(24,849,680바이트)을 로컬에 복사한 뒤 목록·크기·SHA를 모두 검증했다. [ROOT의 독립 최종 감사](../../../../../../storage/experiments/plans/2026-10-04/temporal_retention_pair_pilot_v2/ROOT_remote_endpoint_audit.json), [전체 복사 검증](../../../../../../storage/experiments/plans/2026-10-04/temporal_retention_pair_pilot_v2/ROOT_verified_local_mirror.json)을 보존했다. 대조군 1,000회 가중치는 직전 균형 학습의 1,000회 가중치와 **바이트 단위로 같아**, 원래 학습을 재현하면서 보존 벌점의 차이를 비교했음을 확인했다.

현재 주행 모델은 CNN 영상 특징, 카메라 시계열·자세·차량 상태·내비게이션을 합치는 attention, 경로/속도 출력으로 구성된 자체 모델이다. 이번 실험은 101개 상태 텐서 중 **54개(2,277,827개 학습 파라미터)**를 업데이트하고 영상 입력부·일부 보조 출력 등 **47개를 동결**한다. 동결 head도 공유 특징이 바뀌면 출력이 달라질 수 있어, 가중치 동일성만으로 기능 보존을 주장하지 않는다. 새 신호/장애물 기능은 별도 데이터·학습 범위·실제 동작 검증이 필요하다.

최초 예상 20~30분에 대해 두 실제 fit 합계는 22.31분이었다. 이것은 소규모 학습 방법 비교 시간이지 기능 완성에 필요한 총 기간이 아니다. [전체 목표·실제 로컬 시험·다음 순서](../../README.md)를 참고한다.
