## 현재 상태

**루트 `data → storage/assets` 링크를 검증 후 제거했습니다. 루트 16개 중 12개 제거, 4개 남았습니다.**
남은 것은 `scripts`, `portable_e2e`, `artifacts`, `datasets`입니다. 전체 링크 정리는 아직 끝나지 않았습니다.
[제거·검사·복구 대상 기록](asset_alias_retirement_20260924.json)을 보존했습니다.

## 수정한 내용

- 지도·모델·라이브러리·잠금 파일의 현재 기본 위치를 `storage/assets/`로 전환했습니다.
- 지도 내부 링크 9개가 루트 `data`를 거치지 않고 실제 파일을 가리키도록 바꿨습니다.
  변경 전후에 같은 원본 파일(inode)을 가리키는지 확인했습니다.
- 녹화 설정의 모델 파일 경로 4개도 전환했습니다. ONNX·모델 파라미터 파일의 기대 SHA는 그대로입니다.
- 과거 지도 준비 기록의 JSON은 수정하지 않았습니다. 읽는 쪽에서 이 저장소의 이전 절대 경로를 해석합니다.
- 테스트의 실제 소스 조회 경로 31개 파일과 분석 도구의 내부 조회를 수정했습니다.
  테스트 기대치를 모델 성능에 맞춰 낮추거나 과거 소스 SHA를 새 값으로 바꾸지 않았습니다.
- 검사 중 소유한 실행 잠금을 자식 검사에도 전달합니다. 실제 실행의 잠금 검사를 끄지 않았습니다.

원본 데이터·checkpoint·과거 원시 결과를 삭제하거나 새 학습·SSH·패키지 설치를 실행하지 않았습니다.

최종 제거 도구가 위 검사를 모두 마친 뒤 제거를 확정했습니다.

중간 검사와 최종 검사의 통과 수는 중복되므로 합산하지 않습니다.

최종 근거는 위 로그 폴더의 `data_retirement_final/` 안에 있습니다.
`pytest.log`, `launch.log`, `runtime.log`, `document_links.log`, `map_admission.log`,
`source_snapshot.json`을 별도로 남겼습니다. 지도 계획은 실행 준비 조회용이며 주행을 시작하지 않았습니다.

## 남은 작업

`scripts`, `portable_e2e`, `artifacts`, `datasets`의 파일시스템 링크 제거는 아직 확정하지 않았습니다.

| 남은 링크 | 해결해야 할 실제 의존성 |
|---|---|
| `scripts` | Shell 실행·소스 로딩·하위 Python 실행의 이전 경로 |
| `portable_e2e` | 과거 분석기가 직접 여는 모델·학습 소스와 고정 SHA 검증 |
| `artifacts` | 원본 기록 안의 절대 경로와 재현 도구의 파일 조회 |
| `datasets` | 자료 경로뿐 아니라 결과가 학습 데이터에 쓰이지 못하도록 하는 보호 경계 |

Python 이름 `scripts.e2e`의 명시적 호환 처리는 파일시스템 링크와 별개로 남아 있습니다.
이전 기록의 과학적 실패 20개에 대해서는 [9월 23일 상세 분류](link_cleanup_20260923.md)를 참조하세요.
